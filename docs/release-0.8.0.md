# Dustweave · 织尘 0.8.0

## 简体中文

- 同步九个内置工具的连接、交接和语言协作改进。
- 钓鱼、领地和抽抽乐在缺少网络回执时进入恢复状态，核对当前游戏状态后继续，避免永久等待和重复消耗。
- 改善装备助手、连连看和 SECRET VISION 的组件切换恢复，以及本地设置保存可靠性。
- 使用正式版本号；仓库和发行页保持私有，不包含外部插件实现。

| 版本 | 运行环境 |
| --- | --- |
| Portable | 包含 .NET 8 桌面运行时 |
| Lite | 需要 .NET Desktop Runtime 8 x64 |

两版功能相同，支持简体中文、繁體中文与 English。请完整解压，关闭旧日常窗口后运行 BD2DailyAssistant.exe；沿用原账号和设置。界面更新不要求重启游戏。

## English

- Updated connection, handoff and language integration across all nine built-in tools.
- Fishing, Territory and Infinite Gacha reconcile current game state after missing responses, keeping recovery visible without permanently disabling automation or repeating resource consumption.
- Improved component handoff recovery in Equipment Assistant, Sichuan and SECRET VISION, plus reliable local settings saves.
- Uses a stable version number. The repository and release remain private; external plugin implementations are not included.

| Edition | Runtime requirement |
| --- | --- |
| Portable | .NET 8 Desktop Runtime included |
| Lite | .NET Desktop Runtime 8 x64 required |

Both editions support Simplified Chinese, Traditional Chinese and English. Extract the complete archive, close the old daily assistant and run BD2DailyAssistant.exe. Existing accounts and settings are retained. Updating the interface does not require restarting the game.
