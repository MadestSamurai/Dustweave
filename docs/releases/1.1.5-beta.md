# Dustweave · 织尘 1.1.5-beta

## 中文

- 修复从跑商设置直接读取商店失败的问题。现在会先准备所需连接，不必先运行公会签到等日常；停止过旧队列也不会阻止手动读取。
- 修复商店尚未生成购买记录时，把正常剩余商品误判为数据缺失的问题。
- 新增「购买零收益商品（金币成就）」，默认关闭、按账号保存。在盈利计划之外使用剩余预算，额外采购折扣后买价等于120%卖价的商品，不分摊砍价费。计划会列出额外数量和垫资，实际药耗仍计入账目，卖出仍等待高价日。
- 修复免费抽取首次预览及旧的未提交预览记录导致的卡点；继续前重新确认免费次数，不重复提交结果未知的抽取。
- 修复周收集切图过程中操作界面短暂消失后无法接续的问题。界面恢复后重新识别当前位置和出口，并限制恢复次数。
- 诊断包补充独立跑商读取、切图恢复和路线状态，便于区分连接、界面等待与实际移动问题。

**如果自动更新失败，可能需要手动下载完整软件包。** 关闭旧版，将完整包解压到新目录后运行；不要混放不同版本。账号和设置保留在原用户数据目录。

| 分发包 | 运行环境 | 适合 |
| --- | --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时 | 首次使用或未安装运行时 |
| **Lite** | 需 .NET 8 Desktop Runtime x64 | 已安装运行时，下载更小 |

## English

- Fixes reading the shop directly from trade settings. The required connection is prepared automatically, without running another daily task first. A stopped queue no longer blocks an explicit read.
- Fixes missing initial purchase records being mistaken for incomplete shop stock.
- Adds **Include break-even resales (gold achievements)**, off by default and saved per account. Spare funds can buy extra goods whose discounted buy price equals their 120% sale price. The bargaining fee is excluded from this strategy; actual pill costs and funding remain in the ledger. Extra quantities are listed, and sales still wait for premium-price days.
- Fixes initial free-draw previews and stale, unsubmitted preview records. Free counts are checked again before continuing; draws with unknown outcomes are not resubmitted.
- Weekly collection can resume after the field interface briefly disappears during travel. It checks the current map and reacquires the exit after recovery, with bounded retries.
- Diagnostic exports include standalone trade reads, field recovery and route state to distinguish connection, interface and movement issues.

**If automatic updating fails, download the full package manually.** Close the old app and extract into a new folder without mixing versions. Accounts and settings remain in their user-data directory.

| Package | Runtime | Best for |
| --- | --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime | First-time users or systems without the runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 | Systems with the runtime; smaller download |
