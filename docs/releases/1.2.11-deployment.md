# Dustweave 1.2.11 publication

Published on 2026-10-13 (UTC+8) as a normal GitHub release and through the signed domestic differential OTA channel.

- Tag `v1.2.11`, packaged source `d2b35152ae162bc01ec185a6b84299feab12662c`.
- Build workflow `38390707799` and publication workflow `38391776307` passed. The publication workflow verified the tagged source, candidate provenance, package boundaries and asset hashes before publishing. Remote asset lengths and SHA-256 digests match the locally tested archives.
- The wave-50 goal uses the offline annealing-optimized policy. UI and bilingual release notes identify its origin. Runtime execution uses the frozen lightweight policy, not online annealing. The highest-tier summon goal retains its existing logic.
- Port verification covered 368 cases and 1,466,835 decisions, with zero decision differences, zero outcome differences and zero illegal actions. All 306 wins in that comparison set were preserved. This selected equivalence set does not estimate a live win rate.
- Validation passed 3,612 synthetic checks in 82 groups, 155 native read paths, 14 unified component compilations, both Portable/Lite UI and language checks, and all ten packaged tool UI checks.
- The first completed package attempt detected an obsolete UI smoke assertion requiring the old opening policy. The smoke fixture was corrected to test the legacy summon goal separately and explicitly assert the selected annealed cultivation and boss-pursuit policies. No production timeout or runtime strategy was relaxed. Only the smoke/demo method and its source-manifest hash differed from the fully tested native/runtime inputs; that exact diff and reused evidence are recorded in package provenance. Both final binaries were rebuilt, all packaged tool UI checks reran, and source/client/archive integrity checks passed. Original failed evidence is retained.
- The actual 1.2.10 updater passed both differential upgrades, failed-start rollback and interrupted-transaction recovery. These tests used isolated data and normal window-close retries, without operating the game.
- Signed OTA operation `bb09879bb7fe4ed6bda0869805a4cc17` completed. Public signature, feed bytes, immutable cache headers, HTTP ranges, both patch downloads and reconstructed application hashes passed; neither flavor used a full-package fallback or changed its baseline installation.
- Direct deltas are available from 1.2.10, 1.2.9 and 1.2.8. From 1.2.10: Portable 19,982,911 bytes; Lite 635,610 bytes.
