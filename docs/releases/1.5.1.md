# Dustweave 1.5.1

- 修复公会签到在页面加载时误报失败的问题。已领取奖励的结果弹窗可正常关闭，随后继续日常；接续时不会重复领取。
- 修复 1.5.0 部分功能提示找不到流程或数据文件的问题，包括周收集地图选择、日常规则、免费抽取和跑商料理列表。
- 启动页的短暂读取异常不再中断已确认账号的正常连接，实际登录与操作异常仍会提示。

1.5.0 用户可在软件内检查更新。1.4 及更早版本请手动下载完整包，退出旧版后解压到新目录；账号与设置会沿用。请保留 `Dustweave.exe` 旁的 `app` 文件夹。

如果更新无法应用，请从本页附件或[夸克网盘](https://pan.quark.cn/s/0ee553c60c0d?pwd=5AgC)下载完整包，提取码 **5AgC**。Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime x64。

## 繁體中文

- 修復公會簽到在頁面載入時誤報失敗，以及獎勵結果視窗阻擋後續日常的問題。
- 修復週收集地圖、日常規則、免費抽取與跑商料理清單找不到檔案的問題。
- 啟動頁的短暫讀取異常不再中斷已確認帳號的正常連線。

1.5.0 可在軟體內檢查更新；1.4 與更早版本需手動下載完整套件並解壓縮至新目錄。請保留 `app` 資料夾。無法套用更新時，請從附件或上述網盤重新下載。

## English

- Fixed guild attendance failing during loading and reward dialogs blocking subsequent daily tasks. Resuming preserves confirmed attendance.
- Fixed missing packaged files for weekly map selection, daily rules, free draws and trading recipe lists.
- Temporary startup-page read errors no longer invalidate an already verified account connection.

Users of 1.5.0 can update in the application. Users of 1.4 or earlier must download the complete package into a new folder; accounts and settings are retained. Keep the `app` folder beside `Dustweave.exe`. If an update cannot be applied, download the complete package from the release assets or Quark above. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime x64.
