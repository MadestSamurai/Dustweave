# Dustweave · 织尘 1.0.9-beta

## 中文

- 今日任务增加账号选择，查看各自计划和记录；各账号的本次勾选分别保留，后台刷新不会切走。
- 隔离批量完成或停止后，每个账号提供“选择任务”入口。
- 查看计划不会切换游戏账号；明确执行后才切换并核对身份，再运行勾选环节、补跑或接续。
- 包含插件首次导入检查优化，减少无缓存时的等待和超时。
- 游戏路径设置遇到短暂文件占用时自动重试，持续无法保存时保留原配置并报错。

**如果自动更新失败，可能需要手动下载完整软件包。** 关闭旧版，将完整包解压到新目录运行，勿混放不同版本。已有账号和设置保留。

| 分发包 | 运行环境 |
| --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时 |
| **Lite** | 需 .NET 8 Desktop Runtime x64 |

## English

- Choose an account in Today to view its plan and history. Task selections are kept separately and background refresh preserves the selected account.
- Each account in a finished or stopped isolated batch has a **Choose tasks** action.
- Browsing does not switch game accounts. An explicit run switches and verifies the selected account before running, retrying or resuming tasks.
- Includes improved first-time plugin checks to reduce cold-import waits and timeouts.
- Retries brief file contention when saving the game location. Persistent failures preserve the original settings and remain visible.

**If automatic updating fails, you may need to download the complete application package manually.** Close the old app and extract into a new folder without mixing versions. Accounts and settings are retained.

| Package | Runtime |
| --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 |
