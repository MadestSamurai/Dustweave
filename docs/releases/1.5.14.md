# Dustweave 1.5.14

## 简体中文 
- 死魂之盘新增性能限制和每关搜索规模设置。高性能保留原有计算能力；第四关默认搜索 10,000 次，其他关默认 3,000 次，可分别调整。
- 死魂之盘优先显示“继续游戏进度”，保留“从第一关开始”；求解设置自动保存，下次求解生效。
- 活动战斗支持绑定游戏中的预设槽位，每次执行前重新应用该槽位；槽位为空时使用现有阵容。
- 完善战术教材插件引导，明确安装并启用后会在日常列表中增加周任务选项，并修复设置在深色主题下的文字显示。
- 改善任务、账号、插件和软件设置页面的操作与状态提示，统一继续进度、重新执行等用词，合并相邻重复提示。
- 修复部分繁中和英文界面遗漏翻译或使用错误文案的问题，统一繁中用词；诊断导出包含界面文字异常记录。
- 为卡带列表、快捷菜单等页面打开操作增加有限重试，减少短暂加载导致的周收集中断；不会重复提交战斗、购买或领取操作。

## 繁體中文 
- 死魂之盤新增效能限制與每關搜尋規模設定。高效能保留原有計算能力；第四關預設搜尋 10,000 次，其他關預設 3,000 次，可分別調整。
- 死魂之盤優先顯示「繼續遊戲進度」，保留「從第一關開始」；求解設定自動儲存，下次求解生效。
- 活動戰鬥支援綁定遊戲中的預設欄位，每次執行前重新套用該欄位；欄位為空時使用現有陣容。
- 完善戰術教材外掛引導，明確說明安裝並啟用後會在日常清單增加週任務選項，並修復深色主題下的設定文字顯示。
- 改善任務、帳號、外掛與軟體設定頁面的操作及狀態提示，統一繼續進度、重新執行等用詞，合併相鄰重複提示。
- 修復部分繁中與英文介面缺少翻譯或使用錯誤文案的問題，統一繁中用詞；診斷匯出包含介面文字異常紀錄。
- 為卡帶清單、快捷選單等頁面開啟操作加入有限重試，減少短暫載入造成的週收集中斷；不會重複提交戰鬥、購買或領取操作。

## English 
- Adds performance limits and per-dungeon search sizes to Soul challenges. High performance retains the original computing capacity. Dungeon four starts at 10,000 candidate attempts; the other dungeons start at 3,000, with individual controls.
- Makes Resume game progress the primary Soul action while keeping Start all five available. Search settings save automatically and apply to the next search.
- Event battles can use a selected in-game preset slot. Its current contents are applied before each run; an empty slot preserves the existing team.
- Clarifies that installing and enabling the Tactical textbook plugin adds a weekly task to the daily list, and fixes settings text in the dark theme.
- Improves controls and status messages across tasks, accounts, plugins and app settings. Clarifies resume and rerun wording and combines adjacent duplicate messages.
- Fixes missing or incorrect Traditional Chinese and English interface text, standardizes Traditional Chinese wording, and includes interface-text errors in diagnostic exports.
- Adds bounded retries when opening cartridge lists, shortcut menus and similar pages to reduce weekly collection interruptions during brief loading delays. Battles, purchases and claims are not resubmitted by these retries.
