# Dustweave 1.4.9

- **内置音游**：源码迁入 `src/Rhythm`，使用织尘的主题、语言和控件。窗口先显示，再后台准备连接；加载时可取消或关闭，失败后可重试。开启自动演奏仍需用户点击。
- **设置与日志**：保留随机偏移、时间校准和原有谱面演奏逻辑。有效旧设置自动沿用，已知旧日志并入织尘诊断及清理，组件缓存继续统一管理。原音游仓库归档，后续维护集中到 Dustweave。
- **周任务恢复**：修复关闭卡带列表时，短暂读取不到账号状态就中断合并周任务的问题。只在回执明确证明操作未执行时，重新核对账号和页面后有限重试；不重复结果不明或消耗资源的操作。
- **诊断补充**：保留拒绝操作时的实际回执和现场，帮助区分短暂状态延迟和其他连接错误。

- **Integrated Rhythm:** source moves to `src/Rhythm`, sharing the host's styling, language, controls and automation ownership. The window renders before connection preparation, with cancellation and retry. Playback still requires an explicit start.
- **Storage:** preserves jitter, calibration and chart execution. Valid legacy settings are imported, known logs join host diagnostics and retention, and component caches remain centrally managed. The standalone repository is archived.
- **Weekly recovery:** re-observes account identity and the current page after a definitely unsent navigation rejection, with bounded retries. Uncertain or consuming actions are not replayed.
- **Diagnostics:** includes the actual native rejection receipt and observed state.

Portable 自带运行库；Lite 需要 .NET Desktop Runtime 8 x64。使用 GitHub Release 的完整 ZIP，或从支持的版本通过软件内 OTA 更新。若更新失败，请下载完整包解压后启动。
