## Changes and upgrade notice

The launcher accepts an elevated desktop when the Windows user and logon session match, and launches with the caller's existing token. Ordinary desktops retain the existing desktop-shell route. No Windows configuration changes or forced elevation are introduced.

The updater no longer treats a missing fallback plugin directory as an installed incompatible plugin. Missing, disabled or unloadable plugins cannot block the base update; enabled usable plugins retain target-host compatibility checks. The selection is resolved afresh, preserving explicit no-plugin mode and the existing parameterless API.

Both Chinese and English release notes prominently explain that **automatic-update failures may require manually downloading the complete application archive**. The old plugin warning occurs before the installer is started, so the updated helper cannot fix that old UI check in place. Affected users should close the old app, extract the full Portable or Lite package into a new directory and run it. Existing accounts and settings remain in their user-data directory; no plugin installation is required.
