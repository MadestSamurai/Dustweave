# Dustweave 1.4.0 delivery

Published on 2026-10-16 (Asia/Hong_Kong) as a normal [GitHub release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.4.0). **Domestic layout-2 OTA is live.** See the [bilingual release notes](1.4.0.md) for the changes and download instructions.

## Source and packaged verification

- Source/tag: `58683bf1334f7365b6c5e584156428cb69e875fd`.
- **4,685 checks / 104 groups** passed on the final source. The earlier focused trade checks covered 259 checks in four groups, including favorites-only bargaining/closing, missing or corrupt optimizer history, confirmed purchases, insufficient funds and uncertain purchases.
- Both actual Portable and Lite packages passed the full packaging gates, source/input integrity, distribution boundaries, languages, hosted sessions and UI checks. The new tool-preparation checks passed **116 checks per edition**, covering three languages, both themes, cancellation, retry, closing, shared ownership, an already-shown window and the larger five-potion option. Result, draw and task dialogs were checked in all six language/theme combinations; rendered screenshots were inspected.
- Preliminary candidates were rejected for compact account-list spacing and equipment-tool preparation waiting at background dispatcher priority. The final source preserves three account rows at the minimum window size, starts preparation after layout without the starvation-prone wait, and handles delayed decoration of an already-shown tool exactly once. Failure evidence remains available; failed candidates were not distributed.
- [Source CI](https://github.com/MadestSamurai/Dustweave/actions/runs/38851846831) and the [release workflow](https://github.com/MadestSamurai/Dustweave/actions/runs/38853600311) passed. GitHub Actions verified the tagged source, uploaded package identities, hashes and distribution boundary, then published the normal release.
- Both public GitHub archives were downloaded in byte ranges, reassembled and SHA-256 verified. No game was started, connected to or operated during this release validation. Installed client assemblies were read only for compatibility compilation; they are not distributed.
