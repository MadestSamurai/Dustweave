# Dustweave · 织尘 1.2.4

## 中文

- 修复游戏已明确拒绝的拾取记录持续阻塞周收集；步行收集会逐个检查探查状态，并有限次恢复已知的天赋未激活提示。
- 修复旧游戏进程留下的跨日镜中记录阻塞新任务；仍检查当前战斗状态和剩余次数。
- 中断的偷窃仅影响偷窃环节，不再连带阻塞周收集及 NPC 任务的其他天赋操作。
- 补充传送窗口的返回路径，诊断导出优先保留最新队列、地图进度和 NPC 任务信息。

如果自动更新失败，请手动下载完整软件包并解压到新目录。账号和设置保存在系统用户目录。

## English

- Explicitly rejected pickups no longer keep weekly collection blocked. Walking collection checks the research talent before each pickup and can recover known inactive-talent prompts with bounded retries.
- Historical Mirror records from a previous game process and day no longer block new tasks. Current battles and remaining tickets are still checked.
- Interrupted theft affects only theft, allowing unrelated collection and NPC talent actions to continue.
- Adds a return path from the waypoint screen. Diagnostic exports prioritize the latest queue, map progress and NPC task evidence.

If automatic updating fails, download the full package and extract it to a new directory. Accounts and settings remain in the system user directory.

| Package | Runtime |
| --- | --- |
| Portable | Includes the .NET 8 desktop runtime |
| Lite | Requires .NET 8 Desktop Runtime x64 |
