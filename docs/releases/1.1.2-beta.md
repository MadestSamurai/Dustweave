# Dustweave · 织尘 1.1.2-beta

## 中文

- 修复控制程序仍在运行，却因进程访问权限受限被误判为“原控制窗口已退出”，导致重新连接仍失败的问题。
- 连接检查改为只申请所需的最小权限；真正退出、进程身份变化和无法读取分别处理，保留自动操作的停止保护。
- 一键诊断包补充连接切换、控制进程检查、队列初始化和轮转日志，帮助准确定位中断原因。
- 导出优先保留关键错误；过大的文本日志保留末尾并注明截断，摘要区分当前连接状态与历史操作失败。账号凭据和插件实现不进入导出包。

**如果自动更新失败，可能需要手动下载完整软件包。** 关闭旧版，将完整包解压到新目录后运行；不要混放不同版本。账号和设置保留在原用户数据目录。

| 分发包 | 运行环境 | 适合 |
| --- | --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时 | 首次使用或未安装运行时 |
| **Lite** | 需 .NET 8 Desktop Runtime x64 | 已安装运行时，下载更小 |

## English

- Fixes repeated connection failures when restricted process access incorrectly reported a running controller as having exited.
- Uses only the process access needed for the check, distinguishing actual exit, changed process identity and unreadable state while preserving automation stop safeguards.
- Diagnostic exports now include connection transitions, controller checks, queue initialization and rotated logs to help identify interruption causes.
- Critical errors take priority. Large text logs retain a clearly marked tail, and summaries distinguish the current connection from historical failures. Account credentials and plugin implementations remain excluded.

**If automatic updating fails, download the full package manually.** Close the old app and extract into a new folder without mixing versions. Accounts and settings remain in their user-data directory.

| Package | Runtime | Best for |
| --- | --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime | First-time users or systems without the runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 | Systems with the runtime; smaller download |
