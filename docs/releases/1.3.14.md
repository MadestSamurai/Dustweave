# Dustweave 1.3.14

## 中文

- 藏红花移除收割前逐块巡田。直接走到首个成熟作物的可收割位置，核对条件后准备料理并开始收割；后续移动仅用于实际收割。
- 三种增产料理已经生效但回调遗漏时，使用游戏中的效果状态恢复，不重复使用料理。收割时长评估不再重复计入巡田耗时。
- 活动扫荡及游戏内自动战斗的确认窗消失时，确认指令尚未提交且关卡、免费次数、储存次数均未变化，才有限重开窗口。已提交或结果不明时不重复开始。
- 潘多拉大逃脱改善 BOSS 战中的距离控制、提前转弯和退路选择；按受伤情况、怪物分布和攻击预警选择道具，主动技能检查冷却与命中方向。
- 诊断压缩包先保留各类近期记录，再收录历史记录，减少旧 NPC 查询挤掉活动交易现场的情况。
- 若 OTA 失败，请手动下载完整包并解压到新目录，保留 `app` 文件夹；账号与设置继续沿用。

Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。1.3.4–1.3.13 支持新版通道直接差分更新，更早版本请手动下载。本次验证覆盖离线回归、客户端组件编译、成品及更新恢复，未进行实机游玩验证；潘多拉的模拟结果不代表实际通关率。

## English

- Removes the saffron pre-harvest field tour. The tool moves directly into reach of the first mature crop, checks readiness, prepares food and harvests. Subsequent movement serves actual harvesting.
- Recovers a missed food callback when all three effects are confirmed active in the game, without consuming food again. Harvest estimates no longer count a preliminary tour twice.
- Safely reopens vanished event sweep and native auto-battle previews only when confirmation was not submitted and the stage, free AP and stored AP remain unchanged. Ambiguous or submitted actions are not repeated.
- Improves Pandora boss spacing, early turns and escape routes. Pickup and skill decisions account for missing health, surrounding enemies, warnings, cooldown and aim.
- Diagnostic exports retain recent evidence from each category before bulk history, reducing starvation of event transaction records by old NPC queries.
- If OTA fails, extract the complete package into a new folder and keep the `app` folder. Existing accounts and settings are retained.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64). Versions 1.3.4–1.3.13 support direct differential updates on the current channel; earlier versions require a manual download. Validation covers offline regressions, installed-client compilation, packaged applications and updater recovery. Live gameplay was not tested; Pandora simulation results are not real-game win rates.
