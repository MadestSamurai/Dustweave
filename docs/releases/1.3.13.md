# Dustweave 1.3.13

## 中文

- 普通启动与隔离多开共享同账号的日常结果和周收集地图进度，保留较新的结果。日常完成状态按游戏每日重置，地图进度按周周期核对。
- 缩小周收集的重新核对范围：地图范围更新不再重置整项完成记录，执行时只补查缺失或未完成的地图。
- 吸收次数用完后，暂缓剩余物品收集，继续后续可执行的压制；不会自行开启步行收集。
- 修复沙盒专属目录与全局默认目录同时存在时，误报“隔离目录与登记位置不一致”的问题。启动、登录信息回收与绑定修复均已覆盖，无需删除沙盒、注册表或重新保存账号。
- 若 OTA 更新失败，请手动下载完整软件包并解压到新目录，保留 `app` 文件夹；账号与设置继续沿用。

Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。1.3.3–1.3.12 支持新版通道直接差分更新，更早版本请手动下载。源码、成品和更新恢复分别验证，本次未进行实机游玩验证。

## English

- Ordinary and sandbox runs share validated daily results and weekly collection progress for the same account, retaining newer results. Daily completion expires at the game reset; map progress follows the server week.
- Narrows collection rechecks: catalog updates no longer reset the entire completed stage. Selected routes check only missing or unfinished areas.
- When absorption runs out, remaining item collection is deferred while available suppression continues. Walking collection is never enabled automatically.
- Fixes false sandbox directory mismatches when a per-box path and a global default coexist. The shared fix covers startup, sign-in recovery and binding repair without deleting sandbox data or saved accounts.
- If OTA fails, extract the complete package into a new folder and keep the `app` folder. Existing accounts and settings are retained.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64). Versions 1.3.3–1.3.12 support direct differential updates on the current channel; earlier versions require a manual download. Source, packaged applications and update recovery are validated separately. Live gameplay was not tested for this release.
