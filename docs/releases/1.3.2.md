# Dustweave 1.3.2

## 中文

- 修复 Sandboxie 沙盒改名后无法重新启动账号的问题：按原数据目录和账号记录找回关联，保留登录信息及任务记录。
- 账号管理新增「修复沙盒绑定」。自动判断不唯一时，可手动选择并确认；其他账号或其他目录不能误绑定。修复前请关闭该沙盒中的游戏及工具窗口，无需删除沙盒或注册表。
- 补充明确的 Windows 任务栏身份和图标路径，并使用明确的界面图标资源。旧版本固定项若仍显示空白，请取消固定，再从新版运行窗口重新固定。
- 1.3.1 可通过新版独立 OTA 差分升级。若更新失败，请手动下载完整软件包，解压到新目录后启动根目录的 `Dustweave.exe`。账号与设置继续保留。

Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。两种版本都需要保留 `app` 文件夹。

## English

- Repairs account startup after a Sandboxie box is renamed. The original data directory and saved account identify the correct box; sign-in and task records remain in place.
- Adds **Repair sandbox binding** in Accounts. When automatic matching is ambiguous, select and confirm a verified box manually. Other accounts or data directories cannot be adopted. Close that sandbox's game and tool windows first; do not delete its files or registry.
- Sets an explicit Windows taskbar identity and icon location, with an assembly-qualified interface icon. If an old pinned shortcut remains blank, unpin it and pin the running updated window again.
- Version 1.3.1 supports a differential upgrade on the separate OTA channel. If updating fails, extract the complete package into a new folder and launch the root `Dustweave.exe`. Existing accounts and settings are retained.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64). Keep the `app` folder with both editions.
