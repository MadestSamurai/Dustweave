## Included changes

Includes all pending weekly NPC navigation, delayed theft target, local recovery,
and shared tool style fixes. Recovery clears the previous controller, refreshes
position and target, and bounds retries. Independent weekly collection and theft
continue when a specific NPC task is deferred. Exhausted weekly NPC quota with no
active quest no longer causes a tour of all maps. Clear native paths retain
continuous movement; real portal and hazard avoidance remains scoped.

See `../WEEKLY_ROUTE_RECOVERY_2026-11-09.md` for the source investigation and the
authorized MadDuplicate quest validation. That quest completed in the game,
preserving the first two completed quests. The earlier intermittent native
navigation stop was not reproduced conclusively; stop observations and bounded
recovery were added, not a claim to have identified every native stop cause.
No game, login, or account operation was performed during this release run.
The private monster plugin is not included or advertised.

## Verification and preserved failures

Packaging used Weekly scope, reusing the completed 1.6.4 Full baseline for
unchanged client components. The 28 affected groups passed 3,297 checks.
Both editions passed actual startup/UI, three-language light/dark shared-tool
checks, live utility self-tests, and complete archive-member hashing. The changed
native bridge compiled against the installed client without connecting to it.

The original 1.6.5 self-updaters passed all ten actual acceptance cases: upgrade,
failed-target startup rollback, interruption recovery through the host and the
preserved helper, and damaged-base refusal, in both editions. Exact application
bytes and account/plugin sentinels were verified. Interruption injection is not
a physical power-cut test; offline tests do not establish live-game reliability.

Repeated publisher self-test attempts encountered Windows temporary-directory
move access denials. Exact-input isolated publisher validation passed all 206
checks; canonical packaging now permits reuse only after matching the entire
publisher input inventory, hashes, report hash and passed case count. No server
code, download policy or timeout was changed for this release. One fresh checkout
also lacked locked restore evidence for BundleBridge and OtaMirror; locked restore
was completed before the successful source gate. All failed evidence remains.

Lite's first main UI smoke failed the plugin-market install-action assertion.
The same unchanged executable passed a fresh isolated main smoke. The original
failure remains in `Lite-checks/smoke/smoke.json`; the passing run and the remaining
canonical packaging steps are recorded in `Lite-final-checks`,
`package-resumption.json` and `artifacts/deployments/1.6.6/resume-package.ps1`.
The resumption verifies unchanged source inputs and the already-uploaded Portable
archive hash; it does not relabel the initial failed result as passed. The exact
cause of this intermittent UI assertion remains unconfirmed.
