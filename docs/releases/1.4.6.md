# Dustweave 1.4.6

## 中文

- **周 NPC 任务路线修复**：能在普通地图完成的击杀目标，按当前剩余目标规划路线并压制，不再被游戏自动指引带往狩猎场。清除接取、提交后的旧指引，并阻止其在动画或切图结束后继续；可用目标不足时仅暂缓对应 NPC 任务。
- **恶魔猎人支持两种怪物**：新增巴萨卡、炎虎选择，分别处理攻击预判、闪避和炎虎的接触／爆炸时机。选择怪物或连接时不会自动开战；通关后停止输入并保留结算。
- **恶魔猎人完整内置化**：沿用独立工具窗口，统一织尘主题、语言、加载动画和连接互斥。源码、日志和缓存由主项目维护，缓存跟随织尘设置，旧日志纳入迁移；原独立仓库已归档。
- **工具列表更清晰**：所有工具一项一行，入口排列一致。

## English

- **Weekly NPC quest routes**: kill objectives available on ordinary maps now follow the planned route and current remaining targets, without the game's automatic guide sending the player into hunting grounds. Clear stale guides after accepting or claiming quests and prevent them from resuming after animations or map changes. Insufficient targets defer only the affected NPC task.
- **Both Fiend Hunter monsters**: choose Berserker or Fiery Tiger, with separate attack prediction, dodge timing and Tiger contact/explosion handling. Selecting a monster or connecting does not start combat. Victory stops input and keeps the result screen visible.
- **Integrated Fiend Hunter**: retain its separate window while sharing Dustweave themes, language, loading feedback and connection exclusion. Source, logs and cache now belong to the main project; cache follows Dustweave settings and legacy logs are migrated. The former standalone repository is archived.
- **Clearer tool list**: every tool occupies one row.
