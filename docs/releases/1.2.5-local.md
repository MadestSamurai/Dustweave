# Dustweave 1.2.5 本地包 / Local package

用于复测周收集步行拾取与中断恢复。塔防位置优化不包含在本包中。

- 按游戏原生可拾取状态筛选和确认目标，区分物品类型与剩余奖励状态。
- 途中其他物品的回执不再代替目标完成证据；移动停滞时有限次恢复寻路。
- 已有完整成功回执的旧步行记录可以安全退出待核对状态，不将原目标伪装成已收集，也不重发奖励请求。

修复已通过 155 项定向检查，以及当前客户端的离线组件编译和读取路径验证。用户现场仍需复测；此说明不代表 GitHub 或 OTA 已发布。
