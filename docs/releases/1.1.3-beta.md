# Dustweave · 织尘 1.1.3-beta

## 中文

- 今日任务的「启动并执行」按钮放到顶部状态卡右侧。批量结束后，可直接返回主窗口的单账号日常，切换账号查看各自完成情况并选择任务；不再另外打开沙盒窗口。
- 批量进度页仅用于当前批量，返回后关闭，重新启动批量时才会出现。各账号当天的完成情况继续保留，已完成项默认不再勾选；跨天按游戏每日刷新时间重置。
- 周收集自动覆盖固定的可收集卡带并根据游戏进度接续，移除起止章节等范围设置，只保留默认关闭的步行收集选项。
- 镜中免费战斗使用游戏原生连续次数，减少重复进出。例如1倍40场可一次启动，剩余次数不足倍率时再处理尾批。
- 修复游戏已登录、但本地启动凭据不完整时无法连接的问题，并完善登录阶段诊断。
- 日志最多保留7天；成功步骤保留摘要，异常步骤保留前后证据，以及继续任务必需的状态，减少长期占用。

**如果自动更新失败，可能需要手动下载完整软件包。** 关闭旧版，将完整包解压到新目录后运行；不要混放不同版本。账号和设置保留在原用户数据目录。

| 分发包 | 运行环境 | 适合 |
| --- | --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时 | 首次使用或未安装运行时 |
| **Lite** | 需 .NET 8 Desktop Runtime x64 | 已安装运行时，下载更小 |

## English

- Launch-and-run now sits on the right of the Today’s Tasks status card. After a batch finishes, return to account tasks in the same window to switch accounts, review progress and choose tasks. No extra sandbox window opens.
- The batch overview is temporary: returning dismisses it until a new batch starts. Each account keeps its daily progress, completed tasks are unchecked by default, and old results expire at the game’s daily reset.
- Weekly collection follows the supported cartridges and in-game progress. Range selectors have been removed; optional walking collection remains off by default.
- Mirror battles use the native continuous battle count. Forty free battles at a multiplier of one can start as a single batch, with a smaller final batch when needed.
- Fixes connecting to an already signed-in game when local launch credentials are incomplete, and improves login diagnostics.
- Logs are retained for at most seven days. Successful steps keep summaries; failed steps retain surrounding evidence and essential recovery state.

**If automatic updating fails, download the full package manually.** Close the old app and extract into a new folder without mixing versions. Accounts and settings remain in their user-data directory.

| Package | Runtime | Best for |
| --- | --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime | First-time users or systems without the runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 | Systems with the runtime; smaller download |
