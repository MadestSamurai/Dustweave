# Dustweave · 织尘 1.2.0

## 中文

- 修复尚未解锁后续商店的账号无法读取跑商计划。仅按已解锁商店计算回款，需要未解锁商店售卖的物品会保留。
- 适度减少跑商未来资金预留：将现有未锁定库存中已安排在7天内高价售卖的部分，按预计回款的50%计入周转，上限为可用资金的25%。今日采购仍受实际余额、保留金币和支出上限限制。
- 修复切换通行证时继续使用上一页任务按钮的问题；切换完成后重新读取任务页。
- 周收集遵循游戏的剧情出现条件，不再查询尚未开放的敌人；相关地图保留待完成提示，其他可用地图继续处理。
- 单张地图重进后仍有待办时仅暂缓该地图；路线不可达或确认受卡带天赋限制时继续下一卡带。保留未完成地点和原因，吸收次数用尽、断线或账号变化仍会停止相应操作。
- 打开日常设置时跟随当前查看的账号，避免修改另一个账号的镜中倍率；记录配置倍率与实际批量计划，便于核对。
- 今日任务可保存命名预设，并在列表右上方切换。账号管理可为每个账号选择不同预设，多账号执行会分别使用。
- 账号管理新增「打开软件后执行勾选账号的日常」，默认关闭。沿用已勾选账号、顺序及执行方式；更新重启、定时启动和隔离子窗口不会重复触发。
- 关闭窗口时可选择退出或收起到系统托盘，并记住选择。收起后任务继续；可从托盘恢复或退出，也可在账号管理重新选择关闭方式。

预设只保存任务勾选，不覆盖各账号的倍率、材料预算等设置，也不重置游戏完成情况。

如果自动更新失败，可能需要手动下载完整软件包；解压到新目录后运行，保留系统用户目录中的账号和设置。日常任务变化仍可能需要按实际游戏状态处理。

## English

- Trading plans work with partially unlocked shops. Revenue uses accessible merchants only; items requiring locked merchants remain in inventory.
- Trading reserves allow 50% of expected premium-sale proceeds from existing unlocked stock allocated for sale within seven days, capped at 25% of usable funds. Today's purchases remain bounded by real balances, cash reserves and spending limits.
- Pass navigation refreshes the mission button after a page change instead of using the previous page's control.
- Weekly collection respects story gates for enemy appearance. Locked maps remain pending while other available maps can proceed.
- Unresolved collection targets are deferred per map after one reentry. Unreachable routes and confirmed cartridge talent restrictions defer that cartridge and continue the next one. Pending locations and reasons are retained; daily absorption limits and connection or identity failures still stop the relevant work.
- Daily settings follow the account being viewed. Mirror diagnostics record both the configured multiplier and the actual batch plan.
- Save and select named task presets on Today. Assign a different preset to each account for multi-account queues.
- Optional run-on-open uses checked accounts, their order and execution mode. It is off by default and does not retrigger on update restarts, scheduled launches or sandbox worker windows.
- Closing the window offers Exit or Minimize to tray, with a remembered choice. Tray mode keeps tasks running; restore or quit from the tray, or reset the close action in Accounts.

Presets contain task selections only. They do not replace account settings or reset game completion.

If automatic updating fails, download the full package manually and extract it to a new directory. Accounts and settings in your system user directory are preserved. Daily tasks can still require handling based on the live game state.
