# Dustweave 1.3.6

## 中文

- 藏红花收割后按账号设置种收 1–3 轮土豆，默认 3 轮，不再因料理加成剩余时间而提前结束。每轮收完后计数，完成后补种藏红花；其他成熟作物也可正常收割。重跑会读取当前农田并接续未完成的一轮，持续不可用时暂缓本环节，连接正常时继续其他日常。
- 新增内置「潘多拉大逃脱」：自动刷游戏货币可选择已解锁的地图与难度，自动移动、拾取、升级并循环同一关；自动刷挑战可重试挑战关卡。**挑战模式尚未加入装备数据，目前自动化无法通关。** 语言和外观跟随织尘，运行期间占用自动化控制，停止后释放。
- 沙盒启动前统一检查 Sandboxie-Plus。缺失或位置失效时，提供官网下载、选择已安装位置和重新检测；软件设置、并行设置及定时执行页面也可打开安装帮助。多账号共用一次提示，取消不会启动账号；定时任务不会反复弹窗或停止正在运行的工具。串行执行无需沙盒。

潘多拉已实测普通第一关结算后循环重开、改选第二关后进入对局，未进行长时间挂机或挑战通关验证。藏红花固定轮数流程已做离线回归，仍需自然成熟藏红花的完整实机验收。

差分 OTA 覆盖前十个发行版本窗口内的兼容版本，本次提供 1.3.1–1.3.5 直升补丁。已撤回的 1.3.0 需手动安装。若更新失败，请手动下载完整包并解压到新目录，启动根目录的 `Dustweave.exe`，保留 `app` 文件夹；账号与设置继续沿用。Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。

## English

- After saffron harvest, complete the account's selected 1–3 potato rounds (3 by default), independent of remaining food-buff duration. Count each round after harvesting it, then replant saffron. Other ripe crops may also be harvested. Reruns read current fields and resume an unfinished round; persistent unavailability defers this stage while other dailies continue when connected.
- Adds built-in **Pandora Escape**. Farm currency mode selects an unlocked map and difficulty, moves, collects items, chooses upgrades and repeats the same stage after settlement. Auto challenge retries challenge stages. **Equipment data is not included; automation cannot currently clear challenge mode.** Language and appearance follow Dustweave, and stopping releases automation control.
- Sandbox starts now share a Sandboxie-Plus preflight. Missing or invalid installations offer the official download, an installed-folder picker and a check-again action. Installation help is also available in App settings, parallel settings and Schedules. A multi-account attempt uses one prompt; cancelling starts no accounts. Scheduled attempts do not repeatedly prompt or stop running tools. Sequential execution does not require Sandboxie.

Live Pandora checks completed normal Stage 1, automatically restarted it, and entered Stage 2 after changing the selection. Prolonged farming and challenge completion were not tested. The fixed-round saffron flow passed offline regressions but still needs a complete live harvest using naturally mature saffron.

Differential OTA covers compatible versions within the preceding ten-release window, with direct patches from 1.3.1–1.3.5. Withdrawn 1.3.0 requires manual installation. If updating fails, extract the complete package into a new folder, launch the root `Dustweave.exe`, and keep the `app` folder. Accounts and settings are retained. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64).
