# Dustweave 1.4.17

## 修复与改进

- **游戏更新适配**：更新连接组件与读取规则，处理换期提示；游戏关闭或重启后及时停止连接准备，避免继续等待失效进程。
- **普通启动与隔离启动**：减少沙盒组件异常对普通启动的影响。隔离游戏复用本机更新后的程序与资源，并核对旧设计表覆盖副本；保留独立登录信息和可写缓存。更新游戏前请关闭所有游戏窗口，再通过普通官方启动器更新。
- **活动战斗**：依据游戏当前结束状态和剩余免费次数推进；免费次数耗尽后结束该环节，避免因历史回执不完整而卡住后续日常。
- **宾果与活动奖励**：支持宾果原生批量操作、初始棋盘与自动刷新。按活动玩法和当前周期识别，同类活动换名或换期无需逐个放行；无法识别的新玩法会给出说明。
- **跑商**：读取并验证当前客户端商品、价格、限购和料理配方。同机制的数据更新可重新生成缓存，不再仅因游戏版本变化而拒绝读取。
- **更新与恢复**：重启更新时暂停并等待后台维护释放资源，重新绑定实际运行进程与安装位置；主窗口就绪后先确认更新成功，避免其他启动任务延迟确认。失败时明确显示回退结果，并保留对应启动记录供诊断。
- **实验性快速赶路**：使用提高移动速度的天赋，按实际效果处理不同等级速度，不再误选冲刺类天赋。

## Changes

- Updates connection bindings and season-transition handling for the latest client. Closing or restarting the game promptly cancels connection preparation.
- Improves normal launch when optional sandbox components are unavailable. Isolated instances use updated host game files and reconcile stale design-table copies while preserving their separate login data and writable caches. Close all game instances before updating through the normal official launcher.
- Native event battles follow the current result and remaining free attempts, allowing the daily queue to continue when attempts are exhausted.
- Adds native bulk Bingo actions with initial-board and automatic-renewal handling. Recognition follows mechanics and the active schedule instead of individual event names; unsupported new mechanics are reported.
- Trading validates and refreshes current products, prices, limits and recipes for compatible data changes instead of rejecting them solely because the client version changed.
- Improves update handoff, installation/process identity, startup acknowledgement and rollback diagnostics. Background maintenance yields before replacement.
- Corrects experimental fast travel to use the movement-speed talent and its actual rank effects.
