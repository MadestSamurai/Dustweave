# Dustweave 1.4.2

## 中文

本版完善缓存统计与清理，并修正吸收次数用完后的周收集行为。

### 空间管理

- 总占用统一统计主程序数据、已登记的隔离账号数据、迁移后的缓存及织尘旧版运行库解压目录，避免界面显示的占用明显小于实际目录大小。
- 区分总占用与可清理空间。账号、游戏文件、正在使用的目录和待恢复记录受保护；正在运行的隔离账号会跳过清理。
- 过期组件缓存不再因“保留最后两份”而永久留下；补齐旧数据组件、构建临时文件和旧运行库解压目录的清理。
- 隔离队列结束后也会按日志设置维护数据，避免只有主窗口目录得到清理。关闭自动清理时仍会完成已成功步骤的日志精简。
- 减少重复目录遍历及完整日志读取；已完成的旧回执保留结果摘要，未完成操作保留恢复所需数据。
- 缓存迁移继续校验文件后切换，禁止迁入隔离账号或临时运行库目录。

### 周收集

- 吸收次数用完，但还有地图存在待吸收目标：暂停本次周收集，次日接续，不再每天绕图消耗压制次数。
- 刚好完成所有地图的吸收：继续完成剩余压制。
- 对尚未核实的卡带先读取当前游戏状态；玩家手动完成的地图可以重新核实，不被旧记录永久阻挡。
- 已完成的本周地图不会因每日天赋次数刷新而重跑；周 NPC 任务和偷窃仍可独立继续。

## English

This release improves storage accounting and cleanup, and corrects weekly collection after absorption uses run out.

### Storage management

- Include host data, registered sandbox accounts, relocated caches and obsolete Dustweave runtime extraction folders in total usage.
- Show reclaimable space separately. Protect account data, game files, active directories and unresolved recovery records. Skip cleanup for running sandbox accounts.
- Expire unused component generations instead of keeping the last two forever. Clean obsolete data components, build scratch files and runtime extraction folders.
- Maintain sandbox logs when a queue finishes, following cleanup preferences. Successful-step evidence is still compacted when automatic deletion is disabled.
- Reduce repeated directory scans and large log reads. Retain outcome summaries for completed old receipts and recovery evidence for unfinished operations.
- Verify cache relocation before switching, and reject sandbox or temporary runtime folders as destinations.

### Weekly collection

- When absorption uses run out while weekly drops remain, defer weekly collection until the next day instead of visiting maps for suppression each day.
- Continue remaining suppression only after all weekly absorption targets are complete.
- Check unknown cartridges against current game data, including maps completed manually since the previous run.
- Daily talent resets do not repeat maps already completed this week. Weekly NPC tasks and theft can continue independently.
