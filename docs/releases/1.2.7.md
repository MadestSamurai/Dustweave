# Dustweave · 织尘 1.2.7

## 中文

- 周收集按游戏实际可拾取状态筛选目标，寻找拾取范围内的可达落脚点，遵循游戏对高度和范围的判定。
- 明确无法到达的单个拾取点会暂缓，继续收集其他物品和后续地图；未收集目标保留，方便之后补跑。
- 修复路径检查失败后仍等待拾取结果，以及旧步行记录持续阻塞周收集的问题；补充暂缓点的位置和原因诊断。
- 当前计划、接续和补跑统一在导航前核对旧操作；连接组件更新后可接续同一游戏进程的原队列。
- 塔防在等待金币、召唤冷却或出售后补位期间继续调整站位、追击 Boss；保留补抽预算，避免空等与无关花费。

跨地图不同连通区域的自动绕行仍在设计中，本版提供单点暂缓及局部拾取范围改进。

## English

- Weekly collection selects targets using native pickup availability and finds reachable ground within the game's pickup area, respecting its height and range rules.
- Individually unreachable pickups are deferred while collection continues with other items and maps. Uncollected targets remain available for later retries.
- Fixes waiting for pickup results after a rejected path check and historical walking records blocking weekly collection. Deferred-target diagnostics include positions and reasons.
- New plans, resume and retries reconcile old operations before travel. Queues can resume after a connection component reload in the same game process.
- Apostle Defense continues free positioning and boss pursuit while waiting for recruitment funds, summon cooldowns or a replacement after selling, preserving recruitment reserves.

Automatic detours between disconnected regions across maps remain under design. This release adds individual-target deferral and local pickup-area improvements.

If automatic updating fails, download the full package and extract it to a new directory. Accounts and settings remain in the system user directory.
