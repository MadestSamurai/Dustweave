# 1.5.0 delivery · 2026-10-25

The normal [1.5.0 release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.5.0)
uses source `19ff1d0d9981ba0e7da62657c92bcee4e01e15e7`. Portable and Lite are
standard single-file application bundles with adjacent data/documentation. No
separate launcher or updater is distributed.

## Download and update policy

- Full installation packages are GitHub release assets. The application also
  links to the maintained Quark download directory.
- The new lane hosts **differential OTA only**, with a direct-patch limit of
  10 MiB, an exact baseline/edition and compatible runtime. A damaged baseline
  or unavailable patch leads to manual-download instructions, not a full cloud
  download or block repair.
- The signed initial index is
  `https://bd2.madsam.work/updates/dustweave/all-in-one/releases.json`. Its SHA-256
  is `fbe3aa86d1122975fe8211e700f692714025da19d3d1abc70b9c26a25b6ddbeb`.
  It contains the 1.5.0 baseline and no synthetic or historical-layout patches.
- Qicaiyun's new prefix is `dustweave/ota/all-in-one`. The two full-package trial
  objects were withdrawn. Both origin and CDN full-archive URLs return 404.
- The briefly published earlier 1.5.0 build was withdrawn before this lane was
  activated. Anyone who downloaded it must download the corrected release again.
  It is not a supported differential baseline.

## Validation

Both editions passed actual temporary-self-copy differential upgrades,
failed-target startup rollback, interrupted replacement recovery through the host
and preserved copy, and damaged-baseline refusal without installation writes:
10 cases in total. File hashes and account/plugin sentinels were checked.
The predecessor was a separately built layout-3 fixture; this does not claim
automatic migration from 1.4. Injected interruptions are not physical power cuts.

The acceptance observer additionally checks the real WPF shell and version when
a rollback notice enters a modal loop before the post-Show startup record is
written. It neither clicks through the notice nor changes application behavior.

The package passed 451 targeted checks in 11 groups, actual packaged UI/tool
checks, 147 publisher checks and 6 mirror checks. Unchanged components reuse the
recorded 6,326-check full baseline; the release workflow independently rebuilt
and ran the full source suite. Public GitHub downloads of both packages matched
the release hashes. No game operations were performed for this delivery.

Evidence is retained under `artifacts/self-update-20261025/delta-acceptance-3`,
`artifacts/releases/1.5.0-delta-final` and `artifacts/deployments/1.5.0`.

## Server separation

The new publishing account, index, directories and state are separate from the
v2 and retired lanes. Nine public checks verified the signed index, absence of
full archives and unchanged old feeds. Installation also checked old configuration
and publisher hashes and denied cross-lane writes. Arbitrary SSH commands were
rejected; the temporary administrator key was revoked and a fresh login denied.

The old lane's subsequent 1.4.18 release is a separate operation. It contains
the common functional fixes and migration guidance, and never advertises 1.5.0
as an automatic upgrade. See [distribution design](../ALL_IN_ONE_DISTRIBUTION.md).
