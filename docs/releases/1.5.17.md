# Dustweave 1.5.17

## 简体中文

- 重新设计“存储空间”：按磁盘、存储位置和内容分类展示占用，区分可清理、可重新生成、暂时保留及需要保留的文件。
- 清晰显示当前可释放空间和暂不可清理的原因；无法读取的内容标为未知，避免误显示为零。清理、迁移和沙盒管理入口分别呈现。
- 修复自动购买天赋药时，目标数量超过商店单次上限导致无法补足的问题；现在会分批购买，并继续遵守金币预留和实际库存。
- 修复部分情况下战术教材等插件预加载使用了不正确的游戏位置；改为使用当前选定游戏的位置，并完善失败提示。

## 繁體中文

- 重新設計「儲存空間」：依磁碟、儲存位置及內容分類顯示占用，區分可清理、可重新產生、暫時保留及需要保留的檔案。
- 清楚顯示目前可釋放空間與暫時無法清理的原因；無法讀取的內容標示為未知，避免誤顯示為零。清理、遷移及沙盒管理入口分別呈現。
- 修復自動購買天賦藥時，目標數量超過商店單次上限而無法補足的問題；現在會分批購買，並繼續遵守金幣預留及實際庫存。
- 修復部分情況下戰術教材等插件預先載入使用了不正確的遊戲位置；改為使用目前選定遊戲的位置，並完善失敗提示。

## English

- Redesigns Storage to show usage by drive, location and content, distinguishing files that can be cleaned, regenerated, temporarily retained or kept.
- Shows the space currently available to reclaim and why some files must be retained. Unreadable content is marked as unknown rather than zero. Cleanup, storage migration and sandbox management have separate controls.
- Fixes automatic Talent Pill purchases failing when the required quantity exceeds the shop limit for a single purchase. Purchases now proceed in batches while respecting the gold reserve and actual inventory.
- Fixes plugin preload checks using an incorrect game location in some cases, including Tactical textbook. Checks now use the currently selected game location and provide clearer failure messages.
