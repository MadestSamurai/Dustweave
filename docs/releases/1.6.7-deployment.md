## User changes

- Cache immutable reflection metadata and reuse temporary lookup structures within
  one observation. Live values, game objects and cross-frame observations are not
  cached. Observation cadence, game commands and identity boundaries are unchanged.
- Show the free-software/refund notice by default. Its right-hand dismissal button
  opens a themed confirmation and requires the localized confirmation phrase.
- Persist acknowledgement as encrypted, machine/Windows-user-bound REG_BINARY.
  Flush and read back before hiding; invalid data shows the notice and never gates
  login, automation or updates. This record is outside portable preferences,
  cache migration and diagnostic exports. Normal restarts and upgrades preserve it;
  this is not a promise against OS/profile loss or deliberate system modification.
- The MIT license is unchanged. No claim is made that all redistribution is illegal
  or that open source can make removal technically impossible.
