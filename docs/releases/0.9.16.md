# Dustweave 0.9.16

私有本地更新，未公开发布。

- 开启MANSION RUNAWAY的80连锁目标后，固定使用此前83连实测的Build26决策配置：3秒碰撞预判、路线权重110、无主动等待、无新增的附近道具拾取绕路。
- 关闭目标后恢复综合策略。两种策略均保留已持有道具的使用、躲避、转向和目前的连接修复。
- 暂停后切换并重新开始即生效，清理上次策略的目标和路线；自动续局仍沿用所选策略。日志记录生效配置。

The 80-chain goal now selects the recorded Build26 profile. Ordinary runs retain the balanced planner, including profitable nearby-item detours. Existing item use, avoidance, camera movement and connection fixes remain available in both profiles.

Source comparison used the actual embedded source from the historical Build26 assembly. Motion and RouteGuide match after formatting; Planner logic matches apart from profile defaults and the subsequent optional pickup policy. Historical performance is evidence for that run, not a guaranteed result for each random maze. Profile selection is source_implemented_pending_runtime until tested in a new game session.
