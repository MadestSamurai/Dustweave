# Dustweave · 织尘 1.0.4-beta

## 中文

- 新增启动引导：确认游戏位置、试启动游戏并验证角色身份，提示正常关闭游戏后保存账号，再通过高亮导览介绍各分页。引导可跳过，也可从账号管理重新打开。
- 日常设置提供所有账号共用的游戏位置，支持选择安装目录中的游戏程序或恢复自动检测。
- 修复部分电脑双击后没有窗口的问题，补充主界面出现前的启动记录和错误提示。
- 校正程序、README、入门说明与内置装备助手的用语：登录后进入的是主菜单，账号验证无需前往卡带城镇。简体中文、繁體中文和 English 同步更新。

| 分发包 | 运行环境 |
| --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时，完整解压后运行 |
| **Lite** | 下载较小，需 .NET 8 Desktop Runtime x64 |

两版功能一致，运行 `Dustweave.exe`。已有账号与设置保留；老用户可在账号管理中打开启动引导。本次为普通 Release。首次安装和手动下载使用 GitHub；国内源用于软件内 OTA，并为 1.0.0-beta、1.0.1-beta 提供直接升级差分包。

本次包括此前本地试用版的启动与引导改进。离线回归与成品界面验证不代表首次连接已经在每位用户的游戏环境中实测。

[使用说明](https://github.com/MadestSamurai/Dustweave/blob/main/docs/GETTING_STARTED.md)

## English

- Adds skippable setup: check the game location, try one launch, verify your character, close the game normally and save the account. A highlighted tour then introduces each page. Reopen setup from Accounts.
- Daily settings now provides one game location shared by all accounts, with manual selection and automatic detection.
- Fixes startup without a window on some PCs and adds early startup diagnostics and visible errors.
- Uses consistent main-menu wording in the app, README, setup guide and integrated Equipment Assistant. Account verification does not require visiting a cartridge town. Simplified Chinese, Traditional Chinese and English are updated together.

| Package | Runtime |
| --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime |
| **Lite** | Smaller download; requires .NET 8 Desktop Runtime x64 |

Both editions have the same features. Extract the full package and run `Dustweave.exe`; existing accounts and settings are retained. This is a normal Release. First installs and manual downloads use GitHub. The domestic source serves in-app OTA, including direct differential upgrades from 1.0.0-beta and 1.0.1-beta.

This release includes the startup and setup improvements from the earlier local candidates. Offline and packaged UI checks do not claim first-use connection validation in every user's game environment.
