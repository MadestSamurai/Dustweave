# Dustweave 1.3.8

## 中文

- 修复“只购买收藏商品”模式跳过砍价：先砍价，读取新的折扣报价后再购买。已有砍价效果时直接沿用，不重复消耗天赋药。
- 只购买已收藏商品，不制作、不出售、不修改收藏。没有可购买商品时不消耗砍价用药；日常天赋药保留下限继续生效。
- 同步简体中文、繁体中文和英文说明。

若 OTA 更新失败，请手动下载完整包并解压到新目录，保留 `app` 文件夹。账号与设置继续沿用。

## English

- Fixes favorites-only trading skipping bargaining. It now bargains first, then reads fresh discounted prices before purchasing. Active bargains are reused without spending additional talent pills.
- Buys only saved favorites, without cooking, selling or changing favorites. Empty baskets spend no bargaining pills; the daily pill reserve remains enforced.
- Updates Simplified Chinese, Traditional Chinese and English descriptions.

If OTA fails, extract the complete package into a new folder and retain the `app` folder. Existing accounts and settings are preserved.
