## Delivered behavior

Daily settings now keep the game location in a compact row with a separate editor. Trading funds and break-even purchasing settings are available outside the preview. A daily-queue-only Talent Pill reserve defaults to zero. Automatic refill is off by default; when enabled it uses the verified weekly NPC quest discount and resumes the interrupted task after confirming the purchase. Shortages explain the affected task while allowing other eligible tasks to continue.

This release also includes recovery for stale room/guild requests, restaurant bubbles, weekly map transitions and unfamiliar pass definitions, expanded diagnostic evidence, and cross-period allocation of incomplete shared-ingredient batches. Collection, NPC quests and theft retain separate confirmed progress.

The integrated Territory tool supports a minimum tree growth stage, with fully grown trees remaining the default. The independent [BD2 Territory 0.4.4 release](https://github.com/MadestSamurai/bd2-territory/releases/tag/v0.4.4) was published by [GitHub Actions](https://github.com/MadestSamurai/bd2-territory/actions/runs/38076346752) at 02:37:28, with bilingual Portable and Lite EXE/ZIP assets. Its release metadata and all four binary/archive digests were verified. Each edition passed 69 UI assertions and 31 connection assertions. Dustweave users receive the integrated changes through Dustweave OTA.
