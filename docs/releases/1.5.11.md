# Dustweave 1.5.11

## 简体中文

- 新增死魂之盘工具：自动采购、升级、排阵并连续挑战五关，支持暂停与接续，按照当前账号实际可用的升级上限计算。耗尽生命后自动重新挑战当前关卡，保留本轮已经完成的关卡。
- 魂盘决策兼顾当前战斗与后续成长，联合考虑地板、角色、装备和可用金币。游戏中会显示购买与升级过程，工具显示计算进度、预计胜率和花费。模拟胜率仅供参考，不保证每次通关。
- 修复日常从死魂之盘卡带返回时停住的问题。备战页保留进度退出，结算页返回大厅，再进入主菜单；正在进行的战斗先等待结算。
- 存储迁移同时搬移缓存与账号沙盒，保留登录数据，并支持异常中断恢复。存储页面按磁盘展示占用与可清理空间。迁移前请关闭正在使用的游戏与工具。

## 繁體中文

- 新增死魂之盤工具：自動採購、升級、排陣並連續挑戰五關，支援暫停與接續，依目前帳號實際可用的升級上限計算。耗盡生命後自動重新挑戰目前關卡，保留本輪已完成的關卡。
- 魂盤決策兼顧目前戰鬥與後續成長，聯合考慮地板、角色、裝備及可用金幣。遊戲中會顯示購買與升級過程，工具顯示計算進度、預估勝率及花費。模擬勝率僅供參考，不保證每次通關。
- 修復日常從死魂之盤卡帶返回時停住的問題。備戰頁保留進度退出，結算頁返回大廳，再進入主選單；進行中的戰鬥先等待結算。
- 儲存空間遷移同時搬移快取與帳號沙盒，保留登入資料，並支援異常中斷恢復。儲存空間頁面依磁碟顯示占用及可清理空間。遷移前請關閉使用中的遊戲與工具。

## English

- Adds a Soul challenge tool with automatic purchases, upgrades and placement across all five dungeons. Supports pause and resume and respects each account's actual upgrade limits. Exhausted dungeons are retried while completed dungeons from the current run are retained.
- Planning considers the current battle, future growth, floors, units, equipment and available coins. Purchases and upgrades are visible in the game; the tool shows search progress, estimated win rate and spending. Simulated win rates do not guarantee a successful run.
- Fixes daily tasks getting stuck when leaving the Soul cartridge. Preparation exits preserve progress; results return through the lobby to the main menu. Active battles are allowed to finish first.
- Storage relocation moves caches and account sandboxes together, preserves sign-in data and supports recovery after interruption. The storage page shows usage and reclaimable space per drive. Close active games and tools before moving.
