# Dustweave 1.3.5

## 中文

- 定时执行中的接管选项调整为「到点停止内置工具，重启游戏并执行日常」。等待当前操作完成后正常关闭游戏，再按计划中的账号和执行方式重新启动，不再要求从各小游戏逐层返回。默认关闭；已经开启此选项的计划使用新行为。
- 日常执行不再为每一步反复扫描全部历史操作记录。后续查询只更新发生变化的记录，同时保留对未确认操作、账号和周期变化的检查。
- 餐厅领取成功后立即重新识别下一气泡；周收集合并短时间内、无后续操作的重复进度查询。恢复核对仍重新读取游戏数据。
- 修复打开天赋菜单后，界面尚未展开就被误判为关闭的问题。菜单出现即可继续，不增加固定等待，也不重复发送天赋指令。
- 周任务遇敌后按实际界面推进暂停、退出和确认；对确认未执行且界面未变的操作进行有限重试。天赋菜单失败时保留对应回执与前后状态，便于诊断。

在同一沙盒约 4,800 条历史记录的只读对照中，重复查询从约 4.7–5 秒降至多数 4–16 毫秒；首次索引仍需读取历史。这是记录查询耗时，不代表整张地图或整轮日常的完成时间。本次通过离线回归、成品界面和升级恢复检查，未重新运行实机日常。

支持新版通道的差分 OTA，覆盖最多前十个发行版本中的兼容版本。本次提供 1.3.1–1.3.4 直升补丁，两种版本约 1 MB；已撤回的 1.3.0 需手动安装。若更新失败，请手动下载完整包并解压到新目录，启动根目录的 `Dustweave.exe`，保留 `app` 文件夹。账号与设置继续沿用。Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。

## English

- Scheduled takeover now stops built-in tools, waits for the current operation, closes the game normally, then launches the scheduled accounts and execution mode. It no longer navigates out of individual minigames. Off by default; existing enabled plans use this new behavior.
- Daily actions no longer rescan the entire operation history between steps. Subsequent lookups update changed records while retaining checks for unsettled operations, account identity and reset periods.
- Restaurant claims immediately refresh the next bubble. Weekly collection reuses very recent progress only when no subsequent action has invalidated it; recovery still requests fresh game data.
- Fixes a talent menu being treated as closed before its first visible frame. Automation proceeds when ready, without an added fixed delay or repeated talent command.
- Weekly encounter recovery follows the current pause, exit and confirmation screens, with bounded retries only for confirmed unexecuted inputs. Failed talent-menu transitions retain their receipt and before/after state.

In read-only comparison within the same sandbox containing about 4,800 historical records, repeated lookups fell from roughly 4.7–5 seconds to mostly 4–16 milliseconds. Initial indexing still reads history. These are lookup timings, not complete map or daily-run timings. Validation covers offline regressions, packaged UI and updater recovery; live daily automation was not rerun.

Differential OTA covers compatible baselines within the preceding ten releases. This release offers direct patches from 1.3.1–1.3.4, roughly 1 MB for either edition; withdrawn 1.3.0 requires manual installation. If updating fails, extract the complete package into a new folder, launch the root `Dustweave.exe`, and keep the `app` folder. Accounts and settings are retained. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64).
