# Dustweave 1.3.1

## 中文

1.3.0 因安装目录过于扁平、启动入口不明显已撤回。此版本重新整理文件，**完整解压后，双击最外层的 Dustweave.exe 即可启动**。

- 运行库、组件及资源统一放入 `app` 文件夹，根目录只保留启动程序和少量说明、许可及更新信息。
- 保留现有账号、设置和插件登记；目录整理不影响用户数据。
- 新版 OTA 继续与 1.2.x 的旧通道隔离，后续兼容版本使用差分更新。

**已下载 1.3.0 的用户也需要手动下载此完整包，解压到新文件夹。** 启动文件布局已经改变，本次无法使用旧结构的差分。请保留 `app` 文件夹，不要只复制 EXE，也不要覆盖旧目录。

Portable 自带运行库；Lite 需要已安装 .NET 8 Desktop Runtime（x64）。两种包均从根目录的 `Dustweave.exe` 启动。

## English

Version 1.3.0 was withdrawn because its flat directory made the launcher difficult to find. **Extract the complete package and double-click Dustweave.exe at the top level.**

- Runtime files, components and resources are grouped in `app`. The root contains the launcher and a few guide, license and update files.
- Existing accounts, settings and plugin registrations are retained.
- The new OTA channel remains separate from the legacy 1.2.x channel. Future compatible versions use differential updates.

**Users who downloaded 1.3.0 must also download this complete package into a new folder.** The startup layout has changed, so this migration cannot use an old-layout patch. Keep the `app` folder alongside the EXE and do not overwrite the old installation.

Portable includes the runtime. Lite requires .NET 8 Desktop Runtime (x64). Both editions start from the root `Dustweave.exe`.
