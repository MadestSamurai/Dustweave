# 1.5.2 delivery · 2026-10-26

The normal [1.5.2 release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.5.2)
uses source `2f8151da01d895f37b88f29cf395f37dd8c54dc6`. GitHub latest points to
1.5.2. The [publication workflow](https://github.com/MadestSamurai/Dustweave/actions/runs/40264463513)
passed on attempt 2 after rebuilding and testing the tagged source, then verifying
and publishing the four draft assets. The first attempt had passed its build and
tests but publication was dispatched before tag/assets preparation was complete;
the preflight was corrected before retrying.

## Delivered changes

- Field routing considers available native shop and quest-board shortcuts and
  reduces repeated planning and unnecessary waits after a scene becomes usable.
- Fast travel is no longer experimental. New preferences default to enabled;
  schema 18 preferences migrate to schema 19 with fast travel enabled even when
  previously disabled. The three-language first-start release notice explains
  this change. A later explicit opt-out is retained and talent-pill reserves
  remain effective.
- Weekly NPC collection/carrying uses quest targets rather than guide markers;
  known task rejections defer the affected task instead of blocking later work.
- Weekly equipment crafting tries other craftable N recipes when materials run
  out, with the missing progress label supplied.
- Reward-list interaction excludes loading, pooled or incorrectly bound items
  and waits for refresh before subsequent actions. Duplicate update download
  rows are removed.

## Validation

The source suite passed 6,652 synthetic checks across 125 groups. Its complete
passed report arrived just after the former six-minute wrapper deadline; the
full-suite timeout was raised to eight minutes. Canonical packaging reused the
unchanged synthetic inputs rather than rerunning the full local suite. Both
editions passed packaged UI, integrated-tool and archive-integrity checks, plus
current-client native compilation checks covering 161 read paths.

Ten acceptance cases used actual packaged applications to cover 1.5.1 upgrades,
failed-target startup rollback, interrupted replacement through both the host
and preserved helper, and damaged-baseline refusal. A separate run verified
actual 1.5.0 upgrades for both editions. Checks include exact installed bytes,
visible application versions and account/plugin sentinels. These fixtures do
not claim physical power-cut coverage. No game was connected or operated during
this release acceptance; earlier authorized movement evidence is documented in
[field navigation](../FIELD_NAVIGATION.md).

Evidence is retained in `artifacts/releases/1.5.2`,
`artifacts/tests-20261026-031332-5001`,
`artifacts/ota-bundled-1.5.2-final`,
`artifacts/ota-bundled-1.5.2-from-150`, and
`artifacts/deployments/1.5.2`. Failed and preliminary runs remain available.

## Private companion

A separate private plugin 0.2.11 package requires host 1.5.2 and passed reward
flow regressions, battle-input checks and both packaged-host lifecycle suites.
It is neither installed automatically nor included in this public repository,
GitHub assets or OTA payloads. The confirmed reward-list timing defects were
fixed; the reported intermittent game crash has not been reproduced, so this
does not claim every crash has the same cause.
