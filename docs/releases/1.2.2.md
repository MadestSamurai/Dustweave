# Dustweave · 织尘 1.2.2

## 中文

- 修复货币栏的重复控件被误认为多个前台页面，导致重启后仍无法开始日常的问题。
- 末日之书新纪录页面即使延迟出现，也会在按钮就绪后关闭并接续后续任务，不会重打已完成的战斗。
- 修复周NPC任务到达目标后拾取、搬运仍被寻路状态拦截的问题；保留已完成进度，个别卡带失败时继续其他可处理任务。
- 优先接取符合条件、总金币报酬较高的周NPC任务，补充相关诊断信息。
- 日常设置新增砍价技能训练：显示当前级别所需资源，自动前往广场商人，练满后提醒使用天赋书升级；资源不足或结果待核对时停止，避免重复消耗。
- 训练连续砍价时复用当前商店页面，减少重复进出和等待。

如果自动更新失败，可能需要手动下载完整软件包，解压到新目录运行。账号与设置保存在系统用户目录中。

| 分发包 | 运行环境 |
| --- | --- |
| Portable | 包含 .NET 8 桌面运行时 |
| Lite | 需要 .NET 8 Desktop Runtime x64 |

## English

- Fixes currency-bar components being mistaken for duplicate foreground pages, preventing daily tasks even after restarting.
- Delayed Last Night record screens now close when ready and allow the queue to continue without replaying completed battles.
- Fixes navigation state blocking weekly NPC pickup and carry interactions after arrival. Completed progress is retained, and a failed cartridge no longer prevents other eligible tasks.
- Prioritizes eligible weekly NPC quests by total gold reward and expands their diagnostics.
- Adds bargaining training in Daily settings: preview resources, travel to the plaza merchant, train the current tier and receive a talent-book reminder. Insufficient resources or uncertain results stop further spending.
- Continuous bargaining reuses the current shop page, reducing repeated navigation and waits.

If automatic updating fails, download the full package manually and extract it to a new directory. Accounts and settings remain in the system user directory.

| Package | Runtime |
| --- | --- |
| Portable | Includes the .NET 8 desktop runtime |
| Lite | Requires .NET 8 Desktop Runtime x64 |
