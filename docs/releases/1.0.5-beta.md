# Dustweave · 织尘 1.0.5-beta

## 中文

- 修复跳过启动引导后窗口不关闭、底部报错。确认跳过后返回主界面，取消跳过则继续引导；不会关闭游戏或保存未经验证的账号。
- 修复内置领地工具连接成功后误报「游戏进程已变化」。启动时检查统一连接的实时会话，不再要求独立版生成的连接记录。
- 修复启动失败后布局工具反复显示同一条旧错误的问题。

| 分发包 | 运行环境 |
| --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时，完整解压后运行 |
| **Lite** | 下载较小，需 .NET 8 Desktop Runtime x64 |

两版功能一致，运行 `Dustweave.exe`，账号和设置保留。本地修复候选；尚未发布 GitHub 或 OTA。

## English

- Fixes setup remaining open with an error when skipped. Confirming returns to the main window; cancelling continues setup. Skipping does not close the game or save an unverified account.
- Fixes the integrated Territory tool falsely reporting a changed game process after connecting. Starting now verifies the live hosted session without requiring a standalone connection record.
- Fixes Layout reopening a previous start error after recovery.

| Package | Runtime |
| --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime |
| **Lite** | Smaller download; requires .NET 8 Desktop Runtime x64 |

Both editions retain existing accounts and settings. Extract the full package and run `Dustweave.exe`. Local candidate; not yet published to GitHub or OTA.
