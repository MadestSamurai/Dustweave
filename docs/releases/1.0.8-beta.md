# Dustweave · 织尘 1.0.8-beta

## 中文

- 优化插件首次导入检查：主程序与插件共用本次客户端解析，减少无缓存时的等待及超时。
- 接口版本、客户端变更、文件完整性及来源确认仍分别检查；不会因加速而跳过不兼容检查。

**如果自动更新失败，可能需要手动下载完整软件包。** 请关闭旧版，将完整包解压到新目录运行，勿混放不同版本。已有账号和设置保留。

| 分发包 | 运行环境 |
| --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时 |
| **Lite** | 需 .NET 8 Desktop Runtime x64 |

## English

- Speeds up first-time plugin checks by sharing client analysis between the host and extension during one preparation, reducing cold-import waits and timeouts.
- Interface versions, client changes, file integrity and source confirmation are still checked independently.

**If automatic updating fails, you may need to download the complete application package manually.** Close the old app and extract into a new folder without mixing versions. Accounts and settings are retained.

| Package | Runtime |
| --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 |
