# Dustweave 1.3.10

## 中文

- 无插件时，活动战斗可使用游戏自带的连续自动战斗，从尚未通关的关卡开始，每个活动每日最多尝试 5 次免费战斗；普通关卡完成后再按设置推进挑战关卡。
- 可选择自动战斗失败后停止本环节，或扫荡此前最高可扫荡关卡，默认后者；后续日常继续执行，不购买付费次数。
- 新增独立的「救赎之塔」日常环节，默认关闭。进入恶魔城并走到入口后，按已通关难度、每日钥匙和补满成长加成所需石头安排扫荡；可设置保留钥匙数，默认 0。已有挑战和非每日钥匙保留。
- 处理恶魔城赛季奖励弹窗，完善中断后的当前状态核对，避免旧操作记录长期阻止继续执行。
- 已实测入口、奖励弹窗和无可用关卡／免费次数时的跳过流程。因测试账号条件不足，实际消耗次数后的战斗与扫荡结算分支尚未完成实机验证；相关离线回归已通过。

若 OTA 更新失败，请手动下载完整包并解压到新目录，保留 `app` 文件夹。账号与设置继续沿用。

## English

- Without a plugin, event battles can use the game's built-in consecutive auto battle, starting from the first uncleared stage and attempting up to five free battles per event per day. Normal stages are completed before optional challenge stages.
- Choose whether a failed auto battle ends this stage or sweeps the highest previously eligible stage; sweeping is the default. Later daily stages continue, without purchasing attempts.
- Adds a separate, opt-in Tower of Salvation daily stage. It enters Evil Castle and walks to the gate, then limits sweeps by cleared difficulty, daily keys and stones still needed for permanent growth upgrades. The daily-key reserve defaults to zero. Existing challenges and non-daily keys are preserved.
- Handles the Evil Castle season reward popup and checks fresh state after interruptions so old operation records do not permanently block progress.
- Live checks covered entry, reward acknowledgement and skipping when no cleared difficulty or free attempts remain. Consuming battle/sweep settlement branches still require live validation on an eligible account; their offline regressions passed.

If OTA fails, extract the complete package into a new folder and retain the `app` folder. Existing accounts and settings are preserved.
