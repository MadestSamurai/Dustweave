# Dustweave 1.5.3

这是针对 1.5.2 日常入口异常的紧急修复，建议正在使用 1.5.2 的用户更新。

- 修复新增检查错误拦截正常按钮的问题。教材奖励列表的加载与刷新保护只作用于该列表，不再套用到其他日常入口。
- 修复餐厅收益入口识别，包括收益满额后的入口；修复教材奖励列表错误地持续显示未就绪。
- 修复安装或更新插件后，子工具与主窗口使用不同插件版本造成的连接失败。插件变更在重新启动软件后统一生效。
- 奖励展示未结束、后续页面未就绪和状态未刷新会给出不同提示；操作按钮不可用时补全说明。

更新后，先接续或重新勾选此前失败的环节。历史错误记录不会因为安装更新就自动变成完成。软件仍无法继续时，可在诊断页面导出本次日志。

1.5.0–1.5.2 可在软件内更新；1.4 及更早版本请手动下载完整包到新目录。保留 `Dustweave.exe` 旁的 `app` 文件夹。更新失败时请从 [GitHub 最新版](https://github.com/MadestSamurai/Dustweave/releases/latest) 或 [夸克网盘](https://pan.quark.cn/s/0ee553c60c0d?pwd=5AgC)（提取码 `5AgC`）重新下载。

## English

This hotfix addresses daily-task entry failures introduced in 1.5.2. The additional loading checks now apply only to the tactical-training reward list. Other daily controls retain their native button behavior. It also fixes restaurant entry detection, reward-list readiness and mixed plugin versions between the application and its child tools, and clarifies reward-cleanup errors.

After updating, resume or select the previously failed tasks again. Installing an update does not mark historical failures as completed. Users of 1.5.0–1.5.2 can update in the application; older versions require a complete download into a new folder. Keep the adjacent `app` folder.
