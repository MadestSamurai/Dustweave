## Delivered behavior

Controller liveness now uses Windows limited-information queries. Restricted process access no longer becomes false evidence that the controller exited. Confirmed exit and changed process identity still stop automation. An isolated client-Mono comparison reproduced the old higher-access lookup failure and verified the new alive/unreadable distinction; it did not modify or attach to a user's running game. The original user's precise access restriction remains unproven by their older logs.

Diagnostic exports now prioritize connection/ownership transitions, queue/bootstrap failures and rotated evidence. Large text files retain a bounded, labeled tail; coverage records omitted or truncated sources. Credentials and external extension implementations remain excluded. Automatic cleanup includes the bounded ownership journal.
