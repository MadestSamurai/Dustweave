# Dustweave 1.3.7

## 中文

- **藏红花**：成熟后使用三种增产料理并收割。先使用已有料理，缺少时优先以可用材料制作，材料不足才购买；共享材料统一分配。土豆默认种收两轮，可设置 1–3 轮，不受加成时长影响，已有账号的轮数设置沿用。完成后补种藏红花；新增默认开启的自动料理／售卖选项，先出售二、三级藏红花，只用一级制作浓汤并保留一份。锁定材料不会被用于制作。
- **跑商**：新增默认关闭的“只买收藏”。开启后按商店当前报价购买已有收藏商品，其他策略设置暂停生效；不自动砍价、不修改收藏、不制作料理，也不出售物品。
- **连接恢复**：修复管理员游戏连接助手的跨权限通信缺陷，保留账号、进程和会话校验。本机只读数据偶发截断时最多重读两次，内置工具同步修复；不会重发消耗指令。连接阶段记录纳入诊断导出，并提供具体恢复提示。
- **潘多拉挑战**：新增“自动选择装备”开关，默认开启。关闭后由用户选择升级装备，选完自动继续；等待期间释放移动，不因选择时间较长而中断。刷货币模式保持自动选择。

本轮完成离线回归、打包与更新器验收；没有操作真实游戏。藏红花完整自然成熟收割、受影响用户的提权连接及潘多拉手动选择仍需现场复测。挑战模式尚未加入装备数据，目前自动化无法保证通关。

差分 OTA 提供兼容的 1.3.1–1.3.6 直升补丁；旧通道保持不变。若更新失败，请手动下载完整包并解压到新目录，启动根目录的 `Dustweave.exe`，保留 `app` 文件夹；账号与设置继续沿用。Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。

## English

- **Saffron**: use three harvest-buff foods once crops are ripe and ready to collect. Reuse owned food, craft missing portions from available materials, then buy the remaining types. Shared ingredients are allocated together. Potato rounds default to two, with 1–3 selectable and existing settings retained. Replant saffron afterwards. Optional processing is enabled by default: sell grade 2/3 saffron before cooking, use only grade 1 for soup, and keep one portion. Locked ingredients are excluded.
- **Trading**: adds opt-in favorites-only purchasing at current native shop prices. Other strategy controls are inactive while enabled. It does not bargain, change favorites, cook or sell items.
- **Connection recovery**: repairs cross-elevation communication with the game connection helper while preserving account, process and session checks. Truncated local read-only responses receive up to two retries, including built-in tools; consuming commands are never replayed. Exported diagnostics now include connection stages and actionable recovery messages.
- **Pandora Challenge**: automatic equipment choices can be disabled. Choose upgrades manually and automatic play resumes. Movement is released while choosing, without a selection timeout. Currency farming remains automatic.

This release was checked with offline regressions, packaged applications and updater acceptance; no real game was operated. A complete naturally mature saffron harvest, affected-user elevation connections and manual Pandora choices still need live verification. Challenge equipment data is not included and automatic completion is not guaranteed.

Direct differential OTA covers compatible 1.3.1–1.3.6 installations. The legacy channel is unchanged. If updating fails, extract the complete package into a new folder, launch the root `Dustweave.exe`, and keep the `app` folder. Accounts and settings are retained. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64).
