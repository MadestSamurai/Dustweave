# Dustweave 1.4.3

## 中文

### 日常与内置工具

- 修复圣石库存栏折叠后无法获取数量的问题。选择“库存最少”时自动展开，并等待五种库存完整；指定圣石属性时不再要求读取全部库存。读取失败会说明恢复方法，诊断包保留具体库存读数。
- 日常装备分解可分别设置 N、R、SR、UR 的强化等级。旧账号沿用原强化等级，可以按品质调整；相同等级合并批量处理，锁定、收藏、穿戴和指定抽取装备的限制保持生效。
- 潘多拉挑战读取游戏最终结算与生存时间，确认完成后停止，保留结算画面并显示完成提示，避免通关后再次重开。
- 核对全部十一种内置工具的连接行为：短暂状态读取间隙显示等待，恢复后继续；确认游戏退出、账号变化或连接被接管后停止。结果不明的消耗操作不自动重发。

### 空间管理

- 日常机器记录使用紧凑格式，减少重复空白。
- NTFS 磁盘上的适用旧记录与缓存可分批透明压缩，保留内容及原有时间，不重置日志保留期限；空间统计反映压缩后的实际占用。
- 崩溃转储纳入空间统计及保留期限清理。账号凭据、游戏文件与其他程序的数据不在清理范围内。
- 空闲维护分批处理，跳过使用中或不适用的文件，避免大型目录维护长时间占用执行流程。

## English

### Daily tasks and built-in tools

- Fix unavailable Holy Stone balances when the game's inventory panel is collapsed. Least-owned selection expands the panel and waits for all five balances; fixed-element selection no longer requires inventory comparison. Failures include recovery guidance and diagnostic readings.
- Configure separate pre-dismantling enhancement levels for N, R, SR and UR equipment. Existing accounts inherit their previous level. Equal targets share batches, while lock, keep, equipped-item and selected-draw protections remain intact.
- Detect Pandora challenge completion using the game's final result and survival time. Stop on completion, preserve the result screen and show a completion notice instead of starting another round.
- Review connection handling across all eleven built-in tools. Temporary observation gaps show a waiting state and resume when fresh data returns. Confirmed game exit, account change or connection takeover stops commands. Ambiguous consuming operations are not replayed.

### Storage

- Write machine records in compact form to reduce unnecessary whitespace.
- Transparently compress eligible older records and caches in bounded batches on NTFS. Preserve contents and timestamps, keep retention deadlines intact and account for compressed on-disk size.
- Include application crash dumps in storage accounting and retention cleanup. Account credentials, game files and other applications' data stay outside cleanup.
- Perform idle maintenance in bounded batches, skipping busy or unsupported files.
