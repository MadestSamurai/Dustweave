# Dustweave · 织尘 1.2.1

## 中文

- 定时执行可以单独选择逐个账号运行或沙盒并行，并保存并发数量；不再依赖账号页上临时选择的执行方式。
- 新增「到点接管正在运行的工具」，默认关闭。开启后先正常停止内置工具、等待已提交操作结束，再开始指定账号队列；不会中断另一条日常队列。
- 可在日常设置中选择 Sandboxie 的实际安装目录，也可恢复自动识别。
- 改善连接状态轮询，减少重复进程扫描，将相关读取移到后台，降低界面卡顿。
- 更新领地工具：自动料理默认每累计100份售出整批、保留余数；领地币不够补种时只卖够下一批费用。两个选项可分别关闭，且只处理当前配方的未锁定成品，遵守播种预算。
- 更新使徒防守50波策略：前10波筛选7/8阶核心，符合自动续局条件时重开无核心的开局；之后集中培养暗、水和一组高阶补位，有上限地补抽缺少的暗水角色，并为后续波次及首领预留升级金币。

如果自动更新失败，可能需要手动下载完整软件包，解压到新目录运行。账号与设置保存在系统用户目录中。

| 分发包 | 运行环境 |
| --- | --- |
| Portable | 包含 .NET 8 桌面运行时 |
| Lite | 需要 .NET 8 Desktop Runtime x64 |

## English

- Schedules now save their own sequential or parallel-sandbox mode and concurrency, independently of the temporary choice on Accounts.
- Optional scheduled takeover is off by default. When enabled, it stops the active integrated tool normally, waits for submitted operations to settle, then starts the selected account queue. Other daily queues are not interrupted.
- Choose the actual Sandboxie installation directory in Daily settings, or restore automatic detection.
- Connection polling avoids repeated process scans and moves related reads off the UI thread.
- Updated Territory: automatic cooking defaults to selling complete batches of 100 dishes, retaining the remainder. If planting currency is low, sell only enough to fund the next batch. Both options can be disabled independently; only unlocked dishes from the selected recipe are eligible, within the planting budget.
- Updated Apostle Defense: the wave-50 strategy looks for a tier-7/8 core in the first ten waves and can restart an unsuitable opening when auto-next permits it. It then focuses on dark, water and one high-tier support element, with bounded rolls for missing complementary units and upgrade savings for upcoming waves and bosses.

If automatic updating fails, download the full package manually and extract it to a new directory. Accounts and settings remain in the system user directory.

| Package | Runtime |
| --- | --- |
| Portable | Includes the .NET 8 desktop runtime |
| Lite | Requires .NET 8 Desktop Runtime x64 |
