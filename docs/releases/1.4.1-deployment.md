# Dustweave 1.4.1 delivery

Published on 2026-10-17 (Asia/Hong_Kong) as a normal [GitHub release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.4.1). Domestic layout-2 OTA is live. See the [bilingual notes](1.4.1.md) for changes and downloads.

## Source and validation

- Source/tag: `b1ff77aa3b7e8c7154c2ca53316378b2f9d9107e`.
- **5,023 checks / 106 groups** passed. This release used the full regression scope because the shared local connection broker changed.
- Both actual Portable and Lite packages passed source/input identity, distribution boundaries, localization, hosted sessions, main-window and tool-loading checks. All eleven built-in tool windows and their current-client compatibility compilation passed.
- Pandora UI checks cover three languages, two themes, both modes, unavailable saved characters and compact scrolling. The packaged Chinese light challenge view, English dark compact view and account page were visually reviewed.
- [Source CI](https://github.com/MadestSamurai/Dustweave/actions/runs/38971885757) and the [release workflow](https://github.com/MadestSamurai/Dustweave/actions/runs/38973367691) passed. GitHub Actions verified the tag, source, uploaded identities and hashes before publishing the normal release.
- Both public GitHub ZIPs were downloaded in byte ranges, reassembled and hash-verified. Packaging and updater acceptance did not connect to or operate the game. Installed client files were read only for offline compilation and are not distributed.

The Pandora strategy was separately calibrated before release: one live challenge reached the native 1,200-second limit. It is evidence of one successful trial, not a win-rate estimate. Character selection and final UI integration were subsequently checked offline; the live trial was not repeated during publishing. The activity-preview incident from the older 1.2.11 log was confirmed to be covered by the existing 1.3.14 fix and is not claimed as a new 1.4.1 change.
