# Dustweave · 织尘 1.0.6-beta

## 中文

- 启动引导顶部新增语言选择：简体中文、繁體中文、English。立即应用到整个软件并保存选择，切换时保留当前引导进度。
- 修复跳过启动引导后窗口不关闭、底部报错。确认跳过后返回主界面，取消跳过则继续引导。
- 修复内置领地工具连接成功后误报「游戏进程已变化」，以及启动失败后布局工具反复显示旧错误的问题。

| 分发包 | 适用情况 |
| --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时，推荐不确定运行环境的用户选择 |
| **Lite** | 下载较小，需要已安装 .NET 8 Desktop Runtime x64 |

两版功能一致。完整解压后运行 `Dustweave.exe`，保留已有账号和设置。已安装用户可通过软件内更新升级；国内线路用于 OTA，并优先使用适用的差分包。

## English

- Adds a language selector at the top of setup: English, 简体中文 and 繁體中文. Changes apply across the app immediately and persist without resetting setup progress.
- Fixes setup remaining open with an error when skipped. Confirming returns to the main window; cancelling continues setup.
- Fixes the integrated Territory tool falsely reporting a changed game process after connecting, and Layout repeatedly showing a previous start error.

| Package | Choose this when |
| --- | --- |
| **Portable** | You want the .NET 8 desktop runtime included |
| **Lite** | You already have .NET 8 Desktop Runtime x64 installed |

Both editions have the same features. Extract the full package and run `Dustweave.exe`; existing accounts and settings are retained. Installed users can use in-app updates, with differential packages preferred when available.
