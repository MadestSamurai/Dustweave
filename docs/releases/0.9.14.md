# Dustweave · 织尘 0.9.14

本地候选版本，尚未公开发布。

## 更新内容

- 工具菜单增加 MANSION RUNAWAY，复用现有连接，按需准备组件。
- 支持普通模式、挑战模式和可选失败重试；实时显示关卡、剩余糖果、生命、计时、连锁及追兵位置。
- 根据实际迷宫与敌人状态规划路线，使用游戏原有道具并前往出口；镜头转向平滑至约五帧。
- 修正共享连接繁忙时的误断开，并支持小游戏组件关闭后重新开启，无需重启游戏。
- 继承简体中文、繁體中文、English 和深浅主题，保存上次选择。停止、关闭窗口或连接过期后交回操作。

## 使用方式

连接游戏后，在游戏中进入 MANSION RUNAWAY 入口。从 Dustweave 的工具菜单打开同名工具，选择模式并开始。普通模式共有四关；挑战模式按游戏计时连续推进，时间结束结算不表示所有关卡已通关。

其他自动化正在运行时需要先停止；窗口仅打开但未启用时不占用控制权。

## Changes

- Added MANSION RUNAWAY to the tool menu, using the existing shared connection and on-demand preparation.
- Normal and Challenge modes, optional retries, and a live map showing candy, pursuers, lives, time and chain counts.
- Routes follow the native maze and enemy state. Uses native items and exits with camera turns smoothed over approximately five frames.
- Fixed false disconnects while the shared connection is busy, and reopening the minigame component without restarting the game.
- Three languages, light/dark appearance and saved mode preferences. Stopping, closing or losing the connection releases control.

Historical local-candidate notes. These changes are included in the public 1.0.0-beta release; see its release notes for the current package and verification scope.
