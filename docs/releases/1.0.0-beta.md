# Dustweave · 织尘 1.0.0-beta

## 中文

织尘首次公开发布，主体采用 MIT 许可证。本版汇总 0.9.13 之后的改进，提供普通 GitHub Release（不是 Pre-release）。

- 多账号日常时间线、三语言和深浅主题，配套更新主界面截图、入门与贡献文档。
- 工具箱加入 MANSION RUNAWAY，支持普通／挑战推进、平滑转向和达到80连锁后完成本局停止。
- 改善隔离账号启动：等待协议时显示明确状态，确认后接续；保留游戏已经写入、与账号及客户端匹配的协议记录，避免重建隔离空间时遗漏。不会伪造协议确认。
- 插件导入遇到短暂文件占用时有限重试，保存前再次核对完整性。
- 语义化版本识别支持 `1.0.0-beta`，确保未来 `1.0.0` 能正确升级，并同步插件兼容检查。

| 包 | 适用情况 |
| --- | --- |
| Portable | 包含 .NET 8 桌面运行时，完整解压后运行 |
| Lite | 较小，需已安装 .NET 8 Desktop Runtime x64 |

两种包功能相同，支持简体中文、繁體中文和 English。下载本页附件，完整解压到新目录后启动 `Dustweave.exe`，已有账号与设置会继续沿用。

**本次请手动安装完整包。** 旧版 OTA 只识别数字版本，本次保留旧更新源，避免发布它们无法解析的清单。国内线路仍只用于软件内 OTA。

隔离多开仍属实验功能，游戏更新后的具体流程可能需要进一步适配。离线回归、界面与包检查不等于所有账号实机流程均已验证。扩展实现不包含在发行包内。

## English

The first public MIT release of Dustweave consolidates changes since 0.9.13. It is a normal GitHub Release, not a prerelease.

- Multi-account task timelines, three interface languages and light/dark themes, with refreshed screenshots and contributor documentation.
- Integrated MANSION RUNAWAY, normal/challenge progression, smooth turns and an 80-chain goal that finishes the current round before stopping.
- Clear agreement waiting states and preserved game-written agreement records for matching accounts and clients. Existing confirmations are retained; acceptance is never fabricated.
- Bounded retry for transient extraction locks, with a final integrity check before recording an imported plugin.
- Semantic-version ordering and plugin host checks support `1.0.0-beta` and a later `1.0.0` upgrade.

Portable includes the .NET desktop runtime. Lite requires .NET 8 Desktop Runtime x64. Both packages have the same features. Extract the complete package into a new directory and run `Dustweave.exe`; existing accounts and settings are reused.

**Install this release manually.** Older OTA clients cannot parse suffixed versions, so their existing feed is preserved. Domestic hosting remains reserved for in-app OTA. Isolated multi-instance operation is experimental; offline verification is separate from live-game acceptance. Extension implementations are distributed separately.
