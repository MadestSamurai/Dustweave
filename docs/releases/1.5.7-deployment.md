## Scope and validation

The safe-hub stealth detour is restricted to Nightmare Winter patrol fields.
Ordinary maps retain actual enemy checks and walkable gate edges, including the
recorded Memory's Edge Sector 4 case. Update preparation tolerates processes
which exit during sandbox inspection, while preserving errors for live processes
and the block on active isolated windows.

Full synthetic validation passed **6,990 checks in 129 groups**. Both packaged
editions passed startup, language, tool/session and shared-component checks.
No game was launched, connected to or operated during this release acceptance.

The real released **1.5.6** self-copy updater passed **10 cases** across Lite and
Portable: upgrade, failed-target startup rollback, interrupted replacement recovery
through the host and preserved helper, and refusal of a damaged baseline without
installation writes. Exact installed bytes, target startup, and account/plugin
sentinels were checked. Interruption was injected; this is not a physical power-cut
test.

Older installed versions still execute their own updater when installing 1.5.7.
The release notes therefore retain manual-download guidance for users who still
return to the old version after restarting.
