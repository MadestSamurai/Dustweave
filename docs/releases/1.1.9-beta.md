# Dustweave · 织尘 1.1.9-beta

## 中文

- 精简日常设置、今日任务、工具、跑商和定时页面的说明，减少重复导语与默认值复述，保留消耗限制和操作条件。
- 诊断页把“刷新状态”并入连接卡片，简化帮助文字，更容易找到错误信息和日志导出。
- 简体中文、繁体中文和英文同步调整。任务参数、账号设置及自动化行为保持不变。

**如果自动更新失败，可能需要手动下载完整软件包。** 关闭旧版，将完整包解压到新目录后运行；不要混放不同版本。账号和设置保留在原用户数据目录。

| 分发包 | 运行环境 | 适合 |
| --- | --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时 | 首次使用或未安装运行时 |
| **Lite** | 需 .NET 8 Desktop Runtime x64 | 已安装运行时，下载更小 |

## English

- Shorter descriptions across Daily settings, Today, Tools, Trading and Schedules. Removes repeated introductions and default-value reminders while keeping spending limits and prerequisites clear.
- Moves Refresh status into the connection card on Diagnostics and simplifies help text, making errors and log export easier to find.
- Updates Simplified Chinese, Traditional Chinese and English together. Task parameters, account settings and automation behavior are unchanged.

**If automatic updating fails, download the full package manually.** Close the old app and extract into a new folder without mixing versions. Accounts and settings remain in their user-data directory.

| Package | Runtime | Best for |
| --- | --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime | First-time users or systems without the runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 | Systems with the runtime; smaller download |
