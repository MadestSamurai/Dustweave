# Dustweave 1.3.16

## 中文

- 跳过、暂缓和失败显示对应原因及可执行的下一步；旧记录缺少明细时提供明确提示。
- 周收集合并同账号、同周期的地图记录，分别保留收集与偷窃进度。未执行或较旧的记录不再覆盖已完成结果，普通启动和隔离多开共用有效进度。
- 使徒防守接入织尘内置界面，仍保留独立工具窗口。窗口先出现，再显示连接加载状态；主题、语言、设置与日志随织尘管理。连接成功后由用户启动自动化，沿用现有退火策略。
- 所有内置工具在连接准备、自动化执行和收尾期间互斥，避免同时连接或争用控制权。空闲打开窗口不占用日常执行；暂停、设置和关闭保持可用。取消连接或游戏退出后释放占用。
- 若 OTA 失败，请手动下载完整包并解压到新目录，保留 `app` 文件夹；账号与设置继续沿用。

Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。1.3.6–1.3.15 支持直接差分更新，更早版本请手动下载。本次验证包含离线回归、成品界面、连接竞争模拟及真实更新器恢复测试；未操作游戏，不代表新增实机通关验证。

## English

- Skipped, deferred and failed tasks now show a relevant reason and next action, including clearer handling of older records without details.
- Weekly collection merges map records for the same account and cycle, preserving collection and theft separately. Unstarted or older records no longer replace completed progress, across ordinary and sandbox execution.
- Apostle Defense uses Dustweave's integrated UI while retaining a separate tool window. The window opens before connection preparation and displays loading progress. Themes, language, settings and diagnostics follow the host. Automation starts on user request; the existing annealed strategy is unchanged.
- All hosted tools share exclusive control during connection, automation and settlement. Idle windows release control; stop, settings and close remain accessible. Cancellation and game exit release the connection reservation.
- If OTA fails, extract the complete package into a new folder and keep the `app` folder. Existing accounts and settings are retained.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64). Versions 1.3.6–1.3.15 support direct differential updates; earlier versions require a manual download. Validation covers offline regressions, packaged UI, simulated connection contention and actual updater recovery. No game was operated and no new live clear-rate claim is made.
