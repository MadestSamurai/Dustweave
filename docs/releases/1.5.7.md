# Dustweave 1.5.7

本次修复周收集路线限制过严，以及部分用户重启更新后仍回到旧版的问题。

- **隐身与路线范围**：只有恶梦之冬的巡逻区域使用“快捷返回安全区、准备隐身、再经传送阵进入”的特殊路线。其他地图继续按实际怪物情况判断隐身，不再仅因伤害性物件而开隐身、禁止步行或绕行。
- **记忆边缘 · 第4区**：修复周收集发现可达入口，却因目标地图没有传送阵而显示暂缓的问题。已有完成进度保留，更新后可接续周收集，无需清理记录。
- **重启更新**：修复更新前检查已经退出的旧进程时异常中断、重新打开旧版的问题。正在运行的隔离窗口仍需正常退出。

旧版本执行更新时仍会使用旧版更新程序。如果点击重启更新后仍显示旧版，请下载完整包并解压到新目录，保留 `Dustweave.exe` 旁的 `app` 文件夹，然后从新目录启动。无需删除账号、设置或沙盒；使用快捷方式、定时任务或开机启动时，请同步指向新目录。

Portable 包含运行库；Lite 需要已安装 .NET 8 Desktop Runtime x64。通常请选择 Portable。

## English

- The safe-area stealth and portal detour now applies only to Nightmare Winter patrol fields. Other maps use actual enemy checks; damaging objects alone no longer force stealth, detours or a ban on walking.
- Fixes weekly collection incorrectly deferring Memory's Edge Sector 4 despite reachable gates. Maps without portals remain accessible on foot. Completed progress is preserved; resume weekly collection after updating.
- Fixes an update check failing when the old process has already exited, causing the old version to reopen. Running isolated windows must still be closed normally.

Older versions still use their existing updater to install this release. If restarting for an update still opens the old version, extract the complete package into a new folder, keep `app` beside `Dustweave.exe`, and launch from that folder. Do not delete accounts, settings or sandboxes. Update shortcuts, schedules and startup settings to use the new location.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime x64.
