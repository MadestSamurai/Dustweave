# Dustweave 1.5.6

本次更新重点改善周收集与领地赶路，并增加本机和沙盒之间的手动游戏设置同步。

- **危险地图绕行**：针对恶梦之冬等存在伤害物件的地图，优先快捷移动到安全区，在安全区传送阵旁准备隐身，再通过传送阵进入目标地图。隐身被打断时回到安全区处理，避免在伤害物件旁反复施放。危险区域不再安排步行拾取；可用的探查和吸收仍按原设置执行，无法完成的部分会保留记录。
- **领地步行与跳跃**：行走前规划可跨越的低障碍，跳跃时持续前进，落地后接续路线；房屋等高障碍仍然绕行。修复部分坡面被重复阻挡检查误判，以及暂时无法播种的地块被反复选中的问题。
- **藏红花赶路**：日常藏红花流程可以使用交通工具。路线遇到需要跳跃的障碍时提前下车，确认落点后跳跃，通过后再按剩余距离决定是否骑乘。
- **手动同步游戏设置**：在「账号管理 → 管理沙盒 → 同步游戏设置」中，选择「本机 → 沙盒」或「沙盒 → 本机」，分别勾选个人偏好、语言画面声音、操作战斗设置。个人偏好包含商店收藏等账号本地设置。只在点击同步时执行一次，不开启后台同步。
- **首次使用提示**：首次手动隔离启动会建议同步游戏设置，可以跳过；手动并发启动可以在同一个弹窗切换账号。定时任务和自动启动不会因此等待弹窗。

同步游戏设置前，请正常关闭普通游戏和该账号的隔离游戏，保留登录状态。选中的设置以来源为准覆盖目标；语言、画面和声音等通用设置也会影响目标环境中的其他账号。登录凭证、背包和游戏进度不在此功能的同步范围。

1.5 系列可在软件内检查更新。旧版或自动更新无法完成时，请下载完整包到新目录，并保留 `Dustweave.exe` 旁的 `app` 文件夹。

## English

- Hazardous maps now use a safe-area shortcut and portals where available. Stealth is prepared beside the safe-area portal, and interrupted protection is handled from safety instead of repeatedly casting beside damaging objects. Walking pickups are avoided in hazardous areas; unfinished collection remains reported.
- Territory plans validated jumps over low obstacles, keeps moving through the jump, and routes around buildings and other high obstacles. Fixes slope checks and repeated selection of temporarily unavailable planting plots.
- Daily saffron travel can use vehicles, dismount before a planned jump, and resume riding when the remaining distance makes it useful.
- **Accounts → Manage sandbox → Copy game settings** offers a one-time copy in either direction. Choose personal preferences such as shop favorites, language/display/audio, and gameplay settings separately. Close both affected game windows normally without logging out before copying. Selected destination settings are replaced; shared display and language settings affect other accounts in that environment too. Sign-in credentials, inventory and game progress are excluded.
- The first manual isolated launch offers a skippable suggestion. Scheduled and automatic runs continue without this dialog or automatic copying.

Check for updates in the application on the 1.5 series. For older versions or an unavailable automatic update, download the complete package into a new folder and keep its adjacent `app` folder. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime x64.
