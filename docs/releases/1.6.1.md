# Dustweave 1.6.1

## 简体中文

- 修复部分游戏启动和连接时，加载状态判断不正确导致无法继续的问题。
- 修复活动战斗结算后返回页面较慢时，流程提前中断的问题。
- 修复天赋药不足时派遣入口迟迟打不开的问题；按账号设置补药，无法补足时暂缓相关任务并继续其他日常。
- 重新整理日常设置：顶部直接展示天赋药与自动补药设置，有参数的任务显示当前配置，只有开关的任务集中展示。
- 日常设置改为自动保存。有效修改会自动保存到当前账号；输入未完成或无效时保留输入并提示，不覆盖原设置。切换账号、开始执行和退出前也会处理待保存修改。
- 因未开启自动补药而中断的任务提供“设置自动补药”入口，直接打开对应账号的设置。

## 繁體中文

- 修復部分遊戲啟動及連線時，載入狀態判斷不正確而無法繼續的問題。
- 修復活動戰鬥結算後返回頁面較慢時，流程提早中斷的問題。
- 修復天賦特效藥不足時派遣入口遲遲無法開啟的問題；依帳號設定補藥，無法補足時暫緩相關任務並繼續其他日常。
- 重新整理日常設定：頂部直接顯示天賦特效藥與自動補藥設定，有參數的任務顯示目前配置，只有開關的任務集中顯示。
- 日常設定改為自動儲存。有效變更會自動儲存至目前帳號；輸入未完成或無效時保留輸入並提示，不覆蓋原設定。切換帳號、開始執行及退出前也會處理待儲存變更。
- 因未開啟自動補藥而中斷的任務提供「設定自動補藥」入口，直接開啟對應帳號的設定。

## English

- Fixes incorrect loading-state checks that could prevent game startup or connection from continuing.
- Fixes event battles stopping too early when returning from the results screen takes longer.
- Fixes dispatch getting stuck when Ability Pills are insufficient. Refills follow the account's settings; affected tasks are deferred if supplies remain insufficient, while other daily tasks continue.
- Reorganizes Daily settings with an always-visible Ability Pills card, current-setting summaries for configurable tasks, and a compact group of simple task switches.
- Daily settings now save automatically for the selected account. Incomplete or invalid input stays available to correct without replacing saved settings. Pending edits are also checked when switching accounts, starting tasks or exiting.
- Tasks interrupted because automatic refill is off now include a shortcut to that account's refill settings.

Portable includes the required runtime. Lite uses an installed .NET 8 Desktop Runtime. Extract the complete archive and run `Dustweave.exe` from its root folder, keeping the adjacent `app` folder.
