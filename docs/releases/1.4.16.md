# Dustweave 1.4.16

## 修复内容

- **每周偷窃**：修复游戏已返回成功结果，却因可选的天赋计数字段为空而误报回执不匹配、暂停合并周流程的问题。
- **接续执行**：已有记录包含有效 NPC 冷却回执时，可在重新执行中完成核对，无需清空记录，也不会为补确认而重复偷窃。
- **探查与砍价训练**：改进共用天赋回执的区分；仅排除已确认属于其他技能的完整结果，缺少身份或相互矛盾的回执继续保留核对。

更新后，受影响用户可重新执行原队列或补跑对应周任务。

## Changes

- **Weekly theft:** fixes successful attempts being rejected because an optional talent-counter update is absent, interrupting the combined weekly route.
- **Resume:** existing valid NPC cooldown responses can be reconciled on rerun without clearing records or repeating a theft solely for confirmation.
- **Research and bargaining training:** distinguishes interleaved talent responses. Only complete, verified unrelated results are excluded; unidentified or conflicting evidence remains available for reconciliation.

After updating, resume the original queue or rerun the affected weekly tasks.

## Validation / 验证

The receipt fixes passed 315 targeted synthetic checks. Offline replay of records
from 12 diagnostic archives accepted 368 valid responses and correctly rejected
one unrelated response. No game was operated during this investigation.
