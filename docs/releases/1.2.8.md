## English

- Fixes lossy Sandboxie configuration reads for paths containing non-ASCII characters while retaining account and directory ownership checks. The code-level gap is verified; the affected user's exact case still needs a retest.
- Fixes weekly hunt quests failing to interact at their target. Quest-owned triggers are identified separately from monster IDs.
- Adds the default-disabled **Saffron planting and harvest** daily stage. It plants empty fields, checks mature-field access, inventory, currency and available time, prepares three yield foods and immediately harvests saffron. Remaining buff time is used for potato rounds; saffron is replanted after the buffs expire, and cooked dishes are sold while retaining one.
- Diagnostic exports include sandbox path mismatches and saffron operation records for reconciling unconfirmed actions.

Saffron takes 20 hours to grow. Offline logic and packaged compatibility checks have passed, but **the complete mature-crop live cycle still needs validation**. The stage is disabled by default. Missing prerequisites skip it with an explanation and without consuming yield food. See the [saffron stage guide](../SAFFRON.md).

If automatic updating fails, download the full package and extract it to a new directory. Accounts and settings remain in the system user directory.
