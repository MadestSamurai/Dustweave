## Behavior and diagnosis

Independent host launches no longer inherit a previous process's control identity. Hosted helpers preserve their parent identity. Daily activation requires an identified, nonempty account and player. Runtime stop reasons distinguish owner exit/unreadability, missing identity, actual account changes and control handoff; waiting for a pending receipt no longer replaces the original reason. Actual account changes still stop actors, and unconfirmed operations are not replayed.

These are source-confirmed defects with synthetic transition coverage. The original user's screenshot alone does not establish which path occurred on that machine; no claim is made that every session interruption is fixed or that their exact game state was reproduced.

The diagnostic dialog exports allowlisted recent logs to a selected ZIP path, includes developer contacts and reports skipped files. It excludes login stores, plugins and keys, redacts common secret fields and never uploads automatically. The supplied icon is embedded, the default height is 900 device-independent units bounded by the work area, and download links appear above update history. Chinese, Traditional Chinese, English and light/dark themes are supported.

This release also includes per-account task browsing, independent checkbox drafts, returning to account tasks after an isolated batch, first-use preparation improvements and bounded retries when saving a temporarily locked game-location preference.
