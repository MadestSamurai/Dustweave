# Dustweave 1.2.12 legacy migration delivery

Published on 2026-10-15 (Asia/Hong_Kong) as a normal [GitHub release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.2.12) on `maintenance/1.2-migration`. This is a retirement notice for layout 1, not the current feature release. GitHub latest remains **v1.3.16**.

## Startup and compatibility

- Tag/source: `3862afb89812a5f976920fba503349ced091bb7c`, based on v1.2.11. No legacy application code was merged into main.
- The three-language notice appears before game launch, scheduled/parallel execution, connection helpers and tools. Closing it exits the requesting process. Exact Chinese or English acknowledgement enables only the current owner lifetime; hosted children inherit it while that owner remains alive. A fresh owner asks again.
- The rendered notice acknowledges a healthy OTA startup without granting automation consent. Offline checks and installer recovery remain usable.
- The signed legacy feed covers the 23 published layout-1 baselines from **1.0.0-beta through 1.2.11**. Their update-selection methods were compared; both endpoints were exercised using actual historical helpers. Versions predating public OTA support and users who disable automatic updates cannot be forced to update remotely. Withdrawn layout-2 version 1.3.0 cannot downgrade to this lower version; it needs a manual current full download.

## Validation

- Full synthetic regression: **3,613 checks in 83 groups**. Both packaged editions passed UI checks, three languages/two themes, exact acknowledgement validation and close/continue behavior.
- Isolated process tests checked normal, scheduled, parallel, selected-task, tool and connection starts with automatic execution enabled in the fixture. No business state was created before consent. A separate process test checked acceptance, child inheritance, cleanup and stale-owner rejection.
- The actual **1.2.11 helpers** passed Lite/Portable patch-only upgrades. The actual **1.0.0-beta helpers** passed Lite/Portable full upgrades. Both acceptance runs passed startup-failure rollback and interrupted-bootstrap recovery, preserving account/plugin sentinels.
- Lite's first tool-session fixture timed out waiting for its next synthetic window. The unchanged executable passed a fresh 19-case run and the resumed package checks. Original failure evidence is retained. Source equality was verified before resuming the canonical remaining package steps; no production defect or fix was inferred from this non-reproduced fixture failure.
- [GitHub Actions](https://github.com/MadestSamurai/Dustweave/actions/runs/38759942909) verified source, tests, tag, uploaded archive hashes and package boundaries, then published with `latest=false`. The first attempt reached asset validation before upload completed and failed; the subsequent run passed.
- All tests were offline, with isolated profiles and no game operation. Recovery used injected interruption, not a physical power cut.
