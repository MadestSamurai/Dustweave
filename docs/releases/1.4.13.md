# Dustweave 1.4.13

修复卸载沙盒后无法正常启动账号的问题，并统一工具窗口和预设操作。

- **卸载沙盒后可普通启动。** 旧沙盒账号目录、已失效的自选安装位置或损坏的沙盒设置，不再强制要求普通启动完成沙盒登录同步。保留旧数据；使用隔离启动时仍检查安装和账号归属。若游戏要求重新登录，请正常登录后重新保存账号。
- **统一内置工具界面。** 所有工具使用一致的大标题、顶部窗口按钮、操作控件和深浅主题。工具列表统一显示“打开工具”，关闭工具后保持在工具页面。准备连接时继续显示加载、取消和重试。
- **简化预设删除。** 可以直接删除当前预设；确认框说明关联账号，删除后任务选择与相关账号回到“全部已启用环节”，不再要求先切换其他预设。
- **更新更容易发现。** 检测到新版时，版本入口旁显示醒目标识；已经是最新版则不显示。关闭自动下载仍检查新版本，实际更新继续等待空闲与确认。
- **校对游戏用词。** 根据游戏文本核对简体中文、繁体中文和英文的天赋、道具、难度及工具名称；不改写用户账号名或历史设置。

Portable 包含运行库；Lite 需要 .NET 8 Desktop Runtime x64。首次安装或手动更新请完整解压到新目录并运行 `Dustweave.exe`，保留 `app` 文件夹。更新失败时可手动下载完整包。账号和设置沿用。

## English

This release fixes ordinary account launch after removing Sandboxie and improves consistency across tools and preset actions.

- Retained sandbox folders, unavailable custom installation paths and damaged optional sandbox preferences no longer force a credential handoff during ordinary launch. Existing data is preserved; explicit isolated launches still validate the installation and account ownership. If the game requires a new sign-in, sign in normally and save the account again.
- All integrated tools share consistent headings, window controls, actions and themes. Tool-list buttons use “Open tool”; closing a tool keeps the Tools page selected. Connection preparation retains progress, cancellation and retry.
- The active task preset can be deleted directly. Confirmation identifies affected accounts; deletion resets their assignments and the task selection to all enabled stages.
- An update badge appears only when a verified newer version is available. Update checks also run with automatic downloads disabled; installation still requires idle time and confirmation.
- Simplified Chinese, Traditional Chinese and English terminology is checked against game text without rewriting account names or compatibility identifiers.

Portable includes the runtime. Lite requires the .NET 8 Desktop Runtime x64. Extract the entire archive into a new folder and run `Dustweave.exe`; keep the `app` folder. If an update fails, download the full package manually. Accounts and settings are preserved.
