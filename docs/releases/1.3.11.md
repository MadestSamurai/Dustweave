# Dustweave 1.3.11

## 中文

- 修复亲密度咨询升级礼物延迟弹出时中断的问题。等待游戏完成奖励展示后再选择下一位角色，避免把仍在加载的礼物误判为已关闭。
- 支持接续旧版留下的咨询礼物弹窗，核对当前角色与免费次数后继续，不重复消耗已完成的咨询次数。
- 修复潘多拉大逃脱 Game Over 后偶发无法重开的问题。已选择重试但结果页面尚未退出时，继续处理同一结果页面，不重复确认或无限等待。
- 改进潘多拉续局诊断，记录实际页面和关键状态变化，便于定位后续异常。

已依据用户日志和当前游戏代码完成离线回归与组件编译验证；本次未进行实机游玩验证。

若 OTA 更新失败，请手动下载完整包并解压到新目录，保留 `app` 文件夹。账号与设置继续沿用。

## English

- Fixes counseling interruptions when a level-up gift appears late. The next character is selected only after the game's pending reward presentation has finished.
- Resumes delayed counseling gifts left by older versions after checking the current character and free-attempt balance, without repeating a confirmed consultation.
- Fixes intermittent Pandora Escape restarts after Game Over. When retry is selected but the result page remains open, the same result page is handled without repeated confirmation or indefinite waiting.
- Records actual pages and bounded transition history for Pandora restart diagnostics.

Verified through offline regressions and component compilation against the installed game, informed by user logs and game code. Live gameplay verification was not performed for this release.

If OTA fails, extract the complete package into a new folder and retain the `app` folder. Existing accounts and settings are preserved.
