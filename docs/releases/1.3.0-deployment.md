# Dustweave 1.3.0 publication and OTA isolation

Published on 2026-10-13 (UTC+8) as a normal GitHub release. The new OTA lane starts with 1.3.0; no migration entry was added to the old lane.

## Release

- Tag `v1.3.0`, packaged source `9c53892e0481b3e3f1f2554e40278c50fab0c12e`.
- Build workflow `38412449046` and verified-publication workflow `38413033070` passed. The latter verified the tagged source, candidate provenance, package boundaries, MIT license and archive hashes before publishing.
- Both complete archives were downloaded again from their public GitHub URLs; lengths and SHA-256 hashes match the tested local packages.
- The 3,626-check full baseline, 287 affected checks, packaged UI/tool checks and five actual updater scenarios passed. The final launcher-only correction is recorded in `launcher-repair2.json`. All other package files were byte-identical to the validated package. Later server-isolation and documentation changes did not change packaged runtime inputs.
- No live game was connected. Packages contain no private plugins, game assemblies, account data or Python.

The new lane uses a distinct constrained SSH key and account. The OS account selects a fixed configuration path, including detached publishing workers. Neither account can write the other lane's static files, state or configuration. Arbitrary SSH commands are rejected. The original lane executable and configuration were not replaced.

Channel tests passed 54 cases on both Windows and the server's Linux runtime, including schema/layout isolation and rejection of full uploads to layout 2. First installation seeded the exact signed production 1.3.0 feed; no synthetic acceptance version or test patch was uploaded. Subsequent releases use the constrained signed publisher with the v2 client configuration.

Public HTTP validation confirmed both signatures, exact feed hashes, no-cache metadata and HTTP Range support. The new static directory contains only the 3,200-byte feed and an empty initial version directory. A complete Portable package URL on the domestic v2 route returns 404; complete packages are GitHub downloads. Future v2 publications carry matching direct deltas only.

- Legacy feed SHA-256 remained `8d4f18d80911da0ca8a5b642cc8172b03726138ec66357a1bd40d44467ea005b`.
- New feed SHA-256 is `09f13e252c738a30b6a0ab174f8cc960b5704a03ed74dbe37f35a1dae4a49a95`.
- Legacy executable and configuration hashes matched their pre-installation values.
- The temporary administrator key was removed; authentication with it was confirmed to fail. The new constrained publisher remained functional after revocation.

Users on 1.2.x or earlier must download and fully extract 1.3.0 into a new directory. Saved accounts and settings remain in the existing user-data location. Runtime/layout changes, missing baselines, a gap greater than ten releases or an oversized patch require a manual download; layout 2 does not silently fall back to a full OTA package.
