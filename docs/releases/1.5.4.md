# Dustweave 1.5.4

本次更新主要修复周收集不必要的隐身、启动后按钮变灰，以及历史缓存持续占用空间的问题。

- **周收集与隐身**：捕获对象和可破坏物不再被当作战斗敌人。压制完成、场上没有战斗威胁时，不再多余地开隐身或续期；真正的巡逻守卫仍保留保护。
- **天赋效果确认**：隐身或加速施放后，暂时读不到效果会进行短暂重读，避免单次读取异常就中断。不会重复施放或再次消耗天赋药；提示会明确指出对应技能。
- **后台清理让行**：修复软件启动一段时间后按钮长时间变灰的问题。用户连接游戏、执行日常或打开工具时，后台维护会暂停。
- **历史缓存清理**：过期缓存按设置的保留天数清理，并兼顾版本数量限制；覆盖内部遗留的测试记录，改善沙盒长路径的空间统计。保留正在使用的文件、账号与设置；用户自行导出的采集文件不会被自动删除。

1.5 系列可在软件内检查更新。1.4 及更早版本、或自动更新无法完成时，请下载完整包到新目录，保留 `Dustweave.exe` 旁的 `app` 文件夹。
