# 1.3.9 publication receipt

Published on 2026-10-14 as a normal [GitHub release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.3.9), with domestic layout-2 OTA live.

## Source and validation

- Tag `v1.3.9`: `1a469d3e8ac46374e460476b9e9dd2ba11572005`.
- Adds the frozen offline-annealed stage-restart rule to the existing cultivation policy. It assesses the board once at each eligible five-wave checkpoint and keeps the existing summon, upgrade, sale and placement decisions. Restarting is disabled when automatic continuation is off or the user requests stopping after the round.
- There is no FPS/latency eligibility gate. Observed frame duration remains an input to the game's attack-cadence estimate, with a fallback; it does not select whether the new strategy is enabled.
- **8,192 new independent normal-scenario simulations** produced **44,271 exact feature/checkpoint comparisons**, with maximum error zero against the frozen research implementation. Estimated cumulative time to first clear decreased from **16.7772 to 12.2042 hours (27.26%)**, counting failed attempts and 30 seconds per restart. Improvements appeared in every sampled FPS stratum. Individual successful attempts decreased from 160 to 91 because the policy deliberately abandons some potentially winning rounds. This is an offline model result, not a real-game timing guarantee. Stress conditions were not used as the release veto and can regress.
- **512 paired closed-loop cases / 1,024 simulations**, including the native restart guard, produced identical results to the research policy.
- Equivalent performance changes matched **15,080 decisions across 7,540 snapshots from 128 complete games**. A 4,000-decision measurement decreased average planner time from 0.2497 to 0.2019 ms and average temporary allocation from 105,108 to 51,257 bytes. A separate 4,096-state golden check passed. These are planner measurements, not whole-game speedups.
- **3,914 checks in 86 groups** passed locally, along with both packaged application smoke checks, native component checks and source/binary input integrity.
- [Source CI](https://github.com/MadestSamurai/Dustweave/actions/runs/38570055690) and the [publication workflow](https://github.com/MadestSamurai/Dustweave/actions/runs/38571340782) passed. The latter independently built and checked the tagged source, verified candidate provenance and published the normal release.
- The actual **1.3.8 updater** passed Lite/Portable differential upgrades, startup-failure rollback, and interrupted-bootstrap recovery. Test accounts and plugins were preserved. This was injected process interruption, not a physical power-cut test.

No real game was operated during this release. Research and package checks remain separate from live-game calibration.
