# Dustweave · 织尘 1.2.3

## 中文

- 镜中不在战斗期时显示跳过原因并继续后续日常，不再反复等待开战；已开始的战斗先完成结算。
- 修复周NPC任务寻路被列车、陷阱等场景伤害打断后空等的问题。角色恢复可操作后，根据实际位移有限次重新开启任务寻路。
- 保留拾取、搬运和提交中的任务进度，恢复失败的任务暂缓处理，不重复消耗，也不无限重试。

如果自动更新失败，请手动下载完整软件包并解压到新目录。账号和设置保存在系统用户目录。

## English

- Mirror battles now skip with a clear reason outside the battle period, allowing the daily queue to continue. Submitted battles settle first.
- Weekly NPC navigation can recover after environmental damage interrupts movement. Once controls are available, actual position progress determines whether to restart the current route, with bounded retries.
- Pickup, carry and submission progress is preserved. Persistent failures defer the affected task without replaying uncertain interactions.

If automatic updating fails, download the full package and extract it to a new directory. Accounts and settings remain in the system user directory.

| Package | Runtime |
| --- | --- |
| Portable | Includes the .NET 8 desktop runtime |
| Lite | Requires .NET 8 Desktop Runtime x64 |
