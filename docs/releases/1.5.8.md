# Dustweave 1.5.8

- 修复游戏加载或切场较慢时，日常因短暂读取超时提前中断的问题。活动连续战斗、周收集，以及邮件、派遣、奖励等共用等待流程会按当前环节的时限等待。
- 等待确实超时后保留当前环节和已提交操作，不再在战斗或加载未结束时尝试下一项；已确认完成的周收集进度保留，加载恢复后可接续。
- 修复新账号尚未创建沙盒却被要求修复绑定，导致无法创建或隔离启动的问题，无需删除原有账号或沙盒。

本次修复的是慢加载引发的日常中断与错误跳转；游戏加载耗时本身的原因仍在排查。

Portable 自带运行环境；Lite 需要 .NET 8 Desktop Runtime x64。手动更新请解压到新目录，保留 `Dustweave.exe` 旁的 `app` 文件夹，并更新快捷方式、定时任务及开机启动路径。

## English

- Fixes daily runs stopping prematurely when game data is briefly unavailable during slow loading or scene changes. Consecutive event battles, weekly collection and shared waits for mail, dispatch and rewards now use the current step's time limit.
- If a wait does expire, the current step and submitted actions are preserved instead of attempting the next task during an unfinished battle or loading screen. Confirmed weekly progress is retained for resuming.
- Fixes new accounts being asked to repair a sandbox binding before a sandbox exists, preventing creation or isolated launch. Existing accounts and sandboxes do not need to be deleted.

This release addresses daily interruptions and incorrect transitions caused by slow loading. The underlying cause of the game's loading delays remains under investigation.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime x64. For a manual upgrade, extract into a new folder, keep `app` beside `Dustweave.exe`, and update shortcuts, schedules and startup settings to use the new location.
