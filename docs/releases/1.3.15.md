# Dustweave 1.3.15

## 中文

- 内置装备助手打开后自动读取库存；复用与游戏及组件版本相符的解析配置和静态表，减少重复准备时间。换账号、重启游戏或更新组件后会重新核对。
- 搓粉主按钮合并为“计算规划 → 确认并运行”，调整设置后重新规划。统一浅色／深色界面、弹窗、筛选及操作区域，工具列表不再单独显示组件版本。
- 装备助手日志纳入织尘诊断导出和空间管理。开启自动清理时，空闲期间自动迁移旧工具日志、清除过期日志及迁移后的空目录，无需先打开装备助手。保留原始日志时间、未完成批次、库存和连接状态。
- 周收集按当前可进入的五个活动卡带识别第 4、5 个，修正为“记忆边缘”和“戏水女王”；补齐对应地图，跳过当前不可进入的卡带。
- 修复日常执行期间，设置分类条在深色模式下变成白底的问题。
- 若 OTA 失败，请手动下载完整包并解压到新目录，保留 `app` 文件夹；账号与设置继续沿用。

Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。1.3.5–1.3.14 支持直接差分更新，更早版本请手动下载。本次验证覆盖离线回归、当前客户端组件编译、成品界面及更新恢复；未进行实际游戏操作，完整库存读取的实机耗时尚未测量。

## English

- The integrated Equipment Assistant reads inventory on opening and reuses compatible parsing configuration and static tables. Account, game-process and component changes invalidate the appropriate caches.
- A single primary action now progresses from planning to confirmed execution. Changed settings require a new plan. Themes, dialogs, filters and actions follow Dustweave, and tool cards no longer show separate component versions.
- Equipment diagnostics share Dustweave export and retention. With automatic cleanup enabled, idle maintenance imports old logs, removes expired logs and prunes empty legacy log folders without opening the tool. Original timestamps, pending batches, inventory and connection state are preserved.
- Weekly collection resolves event cartridges 4 and 5 against the five currently accessible cartridges, corrects their map coverage and skips unavailable cartridges.
- Fixes the white settings-category background during automation in dark mode.
- If OTA fails, extract the complete package into a new folder and keep the `app` folder. Existing accounts and settings are retained.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64). Versions 1.3.5–1.3.14 support direct differential updates; earlier versions require a manual download. Validation covers offline regressions, installed-client component compilation, packaged UI and updater recovery. Live gameplay and full inventory-read timing were not tested.
