# Dustweave 1.3.12

## 中文

- 活动关卡扫荡一次设置本次允许的最大次数，遵守免费次数和每日剩余额度。
- 软件设置新增“日常完成后退出游戏”，默认关闭。支持单账号、串行及隔离多开，定时计划可独立设置；暂停或异常中断时保留游戏。
- 补齐活动卡带 3、4、5 遗漏地图的周收集与压制。旧版完成记录会核对新增地图；活动卡带 2 在非安全区优先使用可用的藏身天赋。活动卡带 6、7 的范围保持原样。
- 修复镜中自动战斗汇总遮挡段位窗口时的收尾中断。同一游戏进程、账号和刷新周期内，已确认完成的战斗可在重连后继续收尾，不重复扣除次数。
- 救赎之塔通过正常卡带列表进入恶魔城，修复此前切换卡带后首次进入失效、重试才成功的问题。
- 跑商计算前处理未提交的砍价预览；砍价成功后等商店恢复可操作再读取报价，不重复使用天赋药。界面遮挡不再误报账号异常，并补充精简报价诊断。
- 移除整个魔兽快速战斗环节。旧预设保留其他任务，旧队列自动跳过已移除环节。

本次采用用户日志、离线回归及当前游戏组件编译验证，未重新进行实机游玩验证。

1.3.2–1.3.11 支持软件内差分更新。若 OTA 更新失败，请手动下载完整包并解压到新目录，保留 `app` 文件夹；账号与设置继续沿用。

## English

- Adds omitted weekly collection and suppression areas in event cartridges 3–5. Existing completion records recheck the added areas. Event cartridge 2 uses available stealth outside safe areas; cartridges 6 and 7 keep their existing coverage.
- Fixes Mirror settlement when the auto-battle summary covers a rank window. Confirmed battles can finish presentation after reconnecting within the same game process, account and reset cycle without spending attempts again.
- Enters Evil Castle through the native cartridge list for Salvation sweeps, fixing first-entry failures after earlier cartridge switches.
- Handles unsubmitted bargain previews before planning and waits for an interactive shop after confirmed bargains. Ability Pills are not spent twice, window obstruction is no longer classified as an account change, and compact shop diagnostics are exported.
- Removes the entire Fiend Hunt quick-battle task. Existing presets retain other tasks, and old queues skip the removed task.

Validation uses user-log-informed offline regressions and component compilation against the installed game. Live gameplay was not rerun for this release.

In-app differential updates cover 1.3.2–1.3.11. If OTA fails, extract the complete package into a new folder and retain the `app` folder. Existing accounts and settings are preserved.
