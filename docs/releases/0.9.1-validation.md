## Actual executable acceptance / 真实成品验收

1. `artifacts/ota-delta-0.9.1-final-cards/results.json`: the new helper upgraded isolated Lite and Portable 0.9.0 installations using only signed delta packages, without cached full ZIPs. Installed EXE hashes exactly match the final packages, and new application startup was acknowledged. Account and plugin sentinel files remained intact.
2. The same run rejected an incompatible patch, fell back to a cached signed full package, and restored the previous executable when that deliberately invalid executable could not start. A persisted interrupted replacement also recovered through the actual application bootstrap.
3. `artifacts/ota-full-0.9.1-final-cards/results.json`: both complete upgrades passed using the actual **0.9.0 helper**. Full-package startup failure and bootstrap recovery passed as well.
4. Isolated profiles suppress release notices for both tested versions, keeping restored old startup dialogs from blocking the harness. Real user settings are unchanged.

0.9.0 itself cannot apply deltas. It needs one complete upgrade to acquire the new client; subsequent releases can use direct deltas. The patch-engine test intentionally uses the new helper and does not claim old-client patch support.

## Scope and retained evidence / 验证范围与历史证据

No game connection, injection, gameplay, real scheduled task or production publication occurred. No installed application or real account/plugin file was replaced. Interruption was injected into an isolated transaction; this is not a physical power-cut test. The native mouse/OLE drag loop was not physically exercised; production drop handlers, coordinate calculations, saved ordering and rendered insertion cues were exercised in WPF.

Earlier 0.9.1 candidates did not contain the account-card changes. The previously accepted package has been preserved under `artifacts/release-0.9.1-before-account-cards-20261007-161523/`; it must not be distributed as the final build. Earlier failed/draft directories remain diagnostic evidence. The current packages are only those in `artifacts/releases/0.9.1/`.

The territory smoke fixture refreshes its synthetic observation before each start assertion. An earlier stale-heartbeat failure was confined to that fixture; production validation was not relaxed. After final packaging, only this acceptance record and repository status were updated.
