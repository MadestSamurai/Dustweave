# Dustweave 1.4.7

- 恶魔猎人新增泰瑞丝、格兰希特与难度选择；修复贴身不攻击，调整突进预判、防御时机及治疗决策。本轮两名角色均已实测打通两种怪物的超困难，策略优先通关，不追求局内任务。
- 修复 Sandboxie 已安装但驱动不可用时阻止软件启动的问题；普通启动和普通日常不依赖沙盒，隔离功能不可用时单独提示。
- 从 1.4.7 起采用长期 OTA 基线：不再因相差十个版本停止更新；同结构、同运行库的直接差分不超过 10 MB 时可自动下载，超过上限或文件不匹配时提示手动更新。
- 此次继续为最近十个兼容旧版本提供直接差分。若 OTA 失败，请从 GitHub Releases 或固定网盘目录手动下载完整软件包。

- Fiend Hunter adds Teresse, Granhildr and difficulty selection. Fix close-range inactivity and improve dash prediction, defensive timing and damage-aware healing. Both characters cleared both monsters on Very Hard in live trials; the strategy prioritizes clears over in-round missions.
- An installed but unavailable Sandboxie driver no longer blocks application startup. Normal launch and dailies remain independent; isolation failures are reported only for isolation operations.
- Version 1.4.7 starts a long-term OTA baseline. Matching-layout and matching-runtime direct patches up to 10 MB remain eligible beyond ten releases. Larger updates or changed local files require a manual download.
- This release still provides direct patches for the latest ten compatible older releases. If OTA fails, download the complete package from GitHub Releases or the fixed mirror folder.
