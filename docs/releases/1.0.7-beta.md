# Dustweave · 织尘 1.0.7-beta

## 中文

- 修复未安装插件却提示插件不兼容、导致无法更新的问题。未安装、已停用或无法加载的插件不会阻止主程序更新；真正启用的插件仍会检查目标版本兼容性。
- 兼容本身使用管理员权限的 Windows 桌面。同一 Windows 用户、同一登录会话下按工具现有权限启动游戏，不要求修改系统设置；普通桌面的降权启动和连接组件按需提权保留。

**如果自动更新失败，可能需要手动下载完整软件包。** 特别是旧版提示“插件不支持此版 Dustweave”时，请从本页下载 Portable 或 Lite 完整包，关闭旧版，解压到新目录运行。已有账号和设置保留，无需安装任何插件；新版本会修复后续更新检查。

| 分发包 | 运行环境 |
| --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时 |
| **Lite** | 需 .NET 8 Desktop Runtime x64 |

两版功能一致。不要只复制 EXE 或将新旧版本混放。

## English

- Fixes updates being blocked by a plugin compatibility warning when no plugin is installed. Missing, disabled or unloadable plugins do not block base-app updates; enabled plugins are still checked against the target host version.
- Supports elevated Windows desktops using the caller's existing token after checking the Windows user and logon session. No system setting changes are required. The normal unelevated-desktop route and on-demand connection-helper elevation remain available.

**If automatic updating fails, you may need to download the complete application package manually.** In particular, if an older version reports that a plugin is incompatible, download the full Portable or Lite archive from this release, close the old app and extract into a new folder. Accounts and settings are retained; no plugin is needed. Future update checks use the fix.

| Package | Runtime |
| --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 |

Both editions have the same features. Do not copy just the EXE or mix versions in one folder.
