# Dustweave 0.9.15

私有本地更新，未公开发布。

- MANSION RUNAWAY增加“刷到80连锁后停止”。勾选后使用挑战模式，未达到目标时自动续局。
- 胜利结算没有重试按钮时，走游戏退出、模式选择和开始流程；失败时使用原生重试。
- 按本局原生结算的最高连锁判定，不能累加多局，也不能使用上次成绩。达到80后继续完成当前局的原生结算，再交回控制，避免退出丢失成绩。
- 目标模式记忆选择，显示本局进度和完成状态；可随时手动暂停，支持三语言和深浅主题。

Added an 80-chain goal. Challenge rounds repeat until the acknowledged native result contains a maximum chain of at least 80. The current round finishes normally before control is released. Results from separate rounds are never accumulated. The user can pause at any time.

Source and package validation are separate from runtime evidence. This update does not automatically start a game session.
