# Dustweave · 织尘 1.0.1-beta

## 中文

- 新增首次连接教程：正常登录游戏，退出后保存账号，再从织尘进入游戏。账号页保留入口，支持三语言与深浅主题。
- 合并周路线先完成已启用的安全收集，再做 NPC 任务；保留后续任务的击杀目标。单独运行 NPC 任务也会准备压制或藏身，并恢复意外遇敌后的任务进度。
- 活动任务奖励需要从邮箱领取时，先领邮箱，再处理拼图等消耗代币的活动，避免提前判定没有次数。
- 内置装备助手同步 0.3.7：修复首次连接提前读快照导致的超时，短暂只读通信错误有限重试；制作、分解和精炼不会因超时被盲目重发。

| 分发包 | 运行环境 |
| --- | --- |
| **Portable** | 包含 .NET 8 桌面运行时，完整解压后运行 |
| **Lite** | 下载较小，需 .NET 8 Desktop Runtime x64 |

两版功能一致。完整解压到新目录，启动 `Dustweave.exe`，已有账号与设置保留。本次为普通 Release；请手动下载完整包，国内旧版 OTA 源保持不变。

游戏启动器可能启动管理员权限的游戏；工具也设为管理员并不保证连接成功，建议按新教程保存和启动。程序不会自动修改系统权限设置。本轮验证使用隔离界面与合成场景，没有操作真实游戏或消耗资源。

[使用说明](https://github.com/MadestSamurai/Dustweave/blob/main/docs/GETTING_STARTED.md)

## English

- Added a themed, three-language first-use connection guide, also available from Accounts: sign in normally, exit, save the account, then launch through Dustweave.
- Combined weekly routes perform enabled safe collection before NPC quests while preserving future quest targets. NPC-only runs prepare suppression or stealth and refresh quest progress after incidental encounters.
- Event mission mail is collected before token-dependent activities, avoiding premature “no attempts” results.
- Integrated Equipment Assistant 0.3.7 fixes premature snapshot reads on cold connections and retries transient read failures within a bound. Crafting, dismantling and refinement are never blindly repeated after a timeout.

| Package | Runtime |
| --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime |
| **Lite** | Smaller download; requires .NET 8 Desktop Runtime x64 |

Both editions have the same features. Extract the full package into a new folder and run `Dustweave.exe`; accounts and settings are retained. This is a normal Release. Install it manually; the legacy domestic OTA feed is unchanged.

Game launchers may start elevated games. Elevating the tool as well does not guarantee a connection; follow the new guide instead. System permission settings are not changed automatically. This update was checked with isolated UI and synthetic scenarios, without operating the live game or spending resources.
