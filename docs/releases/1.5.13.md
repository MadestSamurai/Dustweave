# Dustweave 1.5.13

## 简体中文

- 诊断导出现在自动包含插件试加载记录、具体错误和游戏文件版本信息，无需再手动寻找检查目录。
- 改善日常跑图：绕开不可压制精英怪的接触范围，按矿车当前位置避让，受击或短暂移动中断后重新规划并继续。普通地图与隐身启用范围保持不变。
- 修复局部路线失败后再次直线靠近同一障碍的问题；改从当前地图重新选择路线，保留已经完成的任务。
- 死魂之盘可继续游戏已有进度，包括手动完成的关卡；改善断线后的进度核对与接续，避免因旧记录长期无法继续。
- 改善启动重试、工具连接和旧日常记录的恢复，补全需要处理时的提示。
- 优化账号列表滚动，减少账号较多时的卡顿。

## 繁體中文

- 診斷匯出現在自動包含外掛試載入紀錄、具體錯誤及遊戲檔案版本資訊，無須再手動尋找檢查目錄。
- 改善日常跑圖：繞開無法壓制的菁英怪接觸範圍，依礦車目前位置避讓，受擊或短暫移動中斷後重新規劃並繼續。一般地圖及隱身啟用範圍維持不變。
- 修復局部路線失敗後再次直線靠近同一障礙的問題；改從目前地圖重新選擇路線，保留已完成的任務。
- 死魂之盤可繼續遊戲既有進度，包括手動完成的關卡；改善斷線後的進度核對及接續，避免因舊紀錄長期無法繼續。
- 改善啟動重試、工具連線及舊日常紀錄的恢復，補全需要處理時的提示。
- 最佳化帳號清單捲動，減少帳號較多時的卡頓。

## English

- Diagnostic exports now include plugin test-load records, detailed errors and game file version information. There is no need to locate the check folder manually.
- Improves daily field travel with contact avoidance for elites that cannot be suppressed, local minecart avoidance, and route recovery after knockback or temporary movement interruptions. Ordinary maps and stealth activation rules are unchanged.
- Fixes failed local routes falling back to a straight approach toward the same obstacle. Travel now returns to route planning from the current map while preserving completed tasks.
- Soul challenges can resume existing game progress, including manually completed dungeons. Improves progress reconciliation after disconnection so old records do not permanently prevent resuming.
- Improves recovery for startup retries, tool connections and older daily-task records, with clearer actionable messages.
- Improves account-list scrolling when many accounts are saved.
