# Dustweave 1.4.14

改善周收集中断后的恢复，修复内置工具卡点，并加入程序完整性修复。

- **周收集恢复。** 识别当前游戏的连线超时提示；安全关闭后有限重试地图查询。接续时检查游戏实际请求状态，避免失效的等待计数永久拦住连接。保留已确认进度，不重复提交结果未知的吸收、购买等操作。
- **内置工具。** 修复钓鱼升级与收获弹窗叠加时中断、装备助手刷新库存误报“操作已停止”。停止请求仍约束制作、强化等消耗操作。
- **救赎之塔。** 扫荡次数一次设置到计划值，不再逐个增加；保留每日钥匙下限与成长目标限制。
- **检查与修复。** 版本更新页面可检查程序文件并修复缺失或损坏的部分，只下载需要的数据。主窗口打不开时，可直接打开 `app/support/Dustweave.Updater.exe` 使用独立修复工具。账号、设置与插件不在修复范围内。
- **更新体验。** 更新文件使用国内下载托管，保留源站回退及签名校验。修复启动时的连接检测干扰“重启更新”的问题。
- **减少等待。** 减少周收集、NPC 与偷窃已确认状态的重复读取；飞奔按步行距离判断，避免短途反复使用。
- **诊断与设置。** 导出更完整的工具连接与异常现场，未压缩日志上限提高至 128 MiB，保留敏感信息过滤。进入日常设置默认展示全部设置。

Portable 包含运行库；Lite 需要 .NET 8 Desktop Runtime x64。首次安装或手动更新请完整解压到新目录，运行 `Dustweave.exe` 并保留 `app` 文件夹。更新失败时可下载完整包手动更新。

这是正式线上 1.4.14，包含此前同版本本地测试包之后的修复。已使用本地测试包的用户请重新下载本次完整包；相同版本号不会触发自动升级。

## English

This release improves weekly recovery, fixes integrated tool interruptions and adds installation repair.

- Recognizes current connection-timeout notices and retries safe collection reads within a fixed limit. Resume checks the game's actual network queue instead of waiting forever on stale counters. Confirmed progress and unresolved consuming-operation records remain intact.
- Fixes overlapping fishing catch/level-up dialogs and inventory refresh incorrectly reporting a stopped operation. Stop still blocks consuming equipment actions.
- Sets the entire Tower of Salvation sweep count at once, respecting daily-key reserves and growth targets.
- Adds signed installation checks and repair that download only needed data. If the main window cannot open, open `app/support/Dustweave.Updater.exe` directly. Accounts, preferences and plugins are excluded from repair.
- Uses domestic file hosting with origin fallback and signature checks. Startup connection checks no longer prevent an update restart requested by the user.
- Reduces repeated confirmed-progress reads and uses walking distance to avoid unnecessary sprint activations.
- Expands diagnostic coverage with a 128 MiB uncompressed log budget and sensitive-data filtering. Daily settings opens on all settings.

Portable includes the runtime; Lite requires .NET 8 Desktop Runtime x64. Extract the entire archive into a new folder, run `Dustweave.exe`, and retain the `app` folder. If updating fails, download the full package manually.

This is the public 1.4.14 build, including fixes made after the earlier local test build with the same version. Users of that local build should download this full package; equal version numbers do not trigger automatic upgrades.
