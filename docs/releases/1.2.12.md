# Dustweave 1.2.12 · 旧版迁移提醒 / Legacy migration notice

这是 1.2 维护分支的迁移提醒包，不是新版功能更新。推荐直接下载当前 **1.3 或更高版本**。

1.2 系列停止跟进新版已超过 48 小时，可能仍有新版已经解决的漏洞和流程错误，也无法获得新功能。1.3 起采用全新的软件结构，需要手动下载完整软件包。

- [GitHub 最新发布](https://github.com/MadestSamurai/Dustweave/releases/latest)
- [夸克网盘](https://pan.quark.cn/s/0ee553c60c0d?pwd=5AgC)，提取码 **5AgC**

退出旧版，将新版完整解压到新目录，保留 `app` 文件夹，从 `Dustweave.exe` 启动。不需要删除已有账号或设置。

启动提醒支持简体中文、繁體中文及 English。输入 **我不需要更新**（简繁相同）或 **I do not need an update** 后才能继续本次使用；关闭提醒会退出整个软件。确认前不启动游戏、日常队列、沙盒工作进程或内置工具。确认只在本次主进程存活期间有效，不保存永久豁免。

此次更新使用原有 layout-1 OTA。1.3 的独立 OTA 不变。已经撤回的 1.3.0 无法自动降级为 1.2.12；请直接下载当前完整包。关闭自动更新或尚无可信 OTA 支持的旧版不能由服务器强行更新。

## English

This maintenance release adds a migration notice to the retired 1.2 line. It is **not the current feature release**. Please download the latest 1.3+ package using the links above.

The 1.2 line is over 48 hours behind the current release line and may retain defects and workflow failures already addressed in newer versions. The new layout requires a manual full download. Extract into a new folder, keep the `app` directory and run `Dustweave.exe`. Keep your saved accounts and settings.

Each launch requires an explicit typed acknowledgement before any game launch or automation. The notice supports Simplified Chinese, Traditional Chinese and English. Closing it exits Dustweave. Update installation/recovery and offline validation remain available without enabling automation. The current layout-2 OTA and latest-release download destination are unchanged.
