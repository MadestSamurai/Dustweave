# Dustweave 1.3.0

## 中文

**这是一次分发结构升级。1.2.x 及更早版本请手动下载完整包，解压到新文件夹，运行其中的 Dustweave.exe。请保留整个文件夹，不要只复制 EXE，也不要覆盖旧目录。原有账号和设置会继续使用。**

- Portable 和 Lite 改为完整文件夹分发，将稳定的运行库、工具资源和更新恢复程序独立保存，减少后续更新重复下载。
- 1.3.0 开始使用独立 OTA 通道；旧版 OTA 保持原样，不自动跨入新版。国内源只提供更新清单和差分，完整包从本页下载。
- 自动更新最多支持向前十个版本的直接差分；需要更换运行库、没有匹配差分或差分过大时，提示手动下载，不自动拉取完整包。
- 更新只替换发生变化的程序文件。启动失败或更新中断时，独立恢复程序可以恢复上一版；账号、设置和用户插件不在替换范围内。
- Lite 完整包约 20 MB；Portable 约 116 MB，包含 .NET 运行库和独立恢复程序。几百 KB 是小改动的目标，不代表每次更新都能达到。

选择 Portable 可免装 .NET；已有 .NET 8 Desktop Runtime（x64）的用户可选择 Lite。首次下载或跨结构升级必须完整解压。

验证：3,626 项完整基线检查、287 项受影响检查、双版本界面与工具检查，以及实际更新器的升级、失败回退和两种中断恢复场景均通过。本次没有连接游戏。

## English

**This release changes the distribution layout. Users on 1.2.x or earlier must download a complete package, extract it into a new folder and run Dustweave.exe. Keep the entire folder; do not copy only the EXE or overwrite the old installation. Existing accounts and settings are reused.**

- Portable and Lite now separate stable runtime files, shared tool resources and the recovery helper from frequently changing application files.
- A separate OTA channel starts at 1.3.0. The legacy feed remains unchanged. Domestic hosting serves signed metadata and differential updates only; complete packages are available here.
- Automatic updates support direct patches from up to ten preceding releases. An incompatible runtime/layout, missing patch or oversized patch prompts a manual download instead of downloading the full archive automatically.
- Only changed application files are replaced. The independent helper supports startup rollback and interrupted-update recovery. User accounts, settings and plugins are outside the replacement inventory.
- Complete downloads are approximately 20 MB for Lite and 116 MB for Portable. Small updates can be much smaller, but a sub-megabyte patch is not guaranteed for every release.

Choose Portable to include the .NET runtime, or Lite if .NET 8 Desktop Runtime (x64) is already installed. Always extract the complete package for first installation and layout migrations.

Validation passed the 3,626-check full baseline, 287 affected checks, packaged UI/tool checks for both flavors and five real updater upgrade/rollback/recovery scenarios. No live game was connected.
