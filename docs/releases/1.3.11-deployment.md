# Dustweave 1.3.11 delivery

Published on 2026-10-15 (Asia/Hong_Kong) as a normal [GitHub release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.3.11), with domestic layout-2 OTA live.

## Changes and validation

- Tag `v1.3.11`: `3087c1103f9061d8838c676d4eafeaa9965cd54e`.
- Counseling now observes the game's pending gift list before moving to another character or leaving. Delayed rewards left by an older version can resume after checking the current target and free quota. Presentation recovery can cross a connection-component instance change in the same game process, account, player and reset cycle; command identity checks remain intact.
- Pandora retry confirmation no longer implies that the next round has started. An already-selected retry may finish closing the same native result page, bounded by identity, initialization revision, stage, readiness and attempt limits. Transition diagnostics keep at most 64 state changes.
- Final full regression: **4,067 checks in 88 groups**. Targeted checks cover delayed gifts, old prematurely closed records, reconnects, wrong targets/processes/cycles, repeated result pages and bounded restart recovery.
- Both packaged editions passed their UI, language, component, ownership and current-client compilation checks. [Source CI](https://github.com/MadestSamurai/Dustweave/actions/runs/38604849315) and the [release workflow](https://github.com/MadestSamurai/Dustweave/actions/runs/38606830757) passed. GitHub Actions verified the candidate and published the normal release.
- The actual **1.3.10 updater** passed Lite/Portable differential upgrades, startup-failure rollback, and interrupted-bootstrap recovery in both editions. Inventoried files and account/plugin sentinels were checked. Interruption was injected, not a physical power-cut test.

These fixes were verified offline using synthetic regressions informed by local diagnostics and the installed game's code. No game was connected or operated for this release. Live gameplay remains a separate verification step.
