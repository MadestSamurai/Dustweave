# 1.5.1 delivery · 2026-10-25

The normal [1.5.1 release](https://github.com/MadestSamurai/Dustweave/releases/tag/v1.5.1)
uses source `ef8f6dbc5a507f25bbec23ee4c43b6afecaea75e`. GitHub latest points to
1.5.1. The [publication workflow](https://github.com/MadestSamurai/Dustweave/actions/runs/40170878821)
independently rebuilt and tested that tag before verifying and publishing its
four draft assets.

## Delivered changes

- Guild loading no longer reports an unsupported observer. Confirmed attendance
  survives transitions and resumption; the known reward presentation closes
  before subsequent daily tasks.
- Optional startup-page read failures no longer replace an authenticated account
  observation with a global read error. Partial UI observations still cannot
  authorize clicks.
- Flow, rule, draw, trade and map readers resolve the adjacent `app` content
  directory from both root executable and nested component entry points.

## Validation

The source suite passed 6,372 synthetic checks across 122 groups. Both official
packages passed their UI, component and archive-integrity checks; packaging also
verified shared native compilation. No game was connected or operated for this release.

The original published 1.5.0 executables passed actual self-copy delta upgrades to
1.5.1 in both editions. Ten acceptance cases covered upgrade, failed-target
startup rollback, interrupted replacement through the host and preserved helper,
and damaged-baseline refusal without installation writes. Exact installed bytes,
the visible application version, and account/plugin sentinels were verified.
The interruption fixtures do not claim physical power-cut coverage.

Evidence is retained in `artifacts/releases/1.5.1`,
`artifacts/tests-20261025-062810-0612`, `artifacts/ota-bundled-1.5.1-final` and
`artifacts/deployments/1.5.1`. An initial acceptance invocation referenced an old
RID-specific development assembly and failed before starting any update; that
evidence remains in `artifacts/ota-bundled-1.5.1`. The final run used the current
build's `src/Core/bin/Release/net8.0-windows/Dustweave.Core.dll`.
