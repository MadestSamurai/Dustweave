# Dustweave · 织尘 1.1.8-beta

## 中文

- 设置页的游戏位置缩为一行，点击后在弹窗修改；跑商资金和零收益采购设置移到日常设置。
- 新增仅对日常队列生效的天赋药保留下限，默认0；自动补药默认关闭，可设置补至数量，仅使用周NPC任务九折报价。药不足时显示原因和处理建议，补药后接续原任务。
- 修复重启后小屋／公会旧请求阻塞、餐厅气泡消失及周路线切图恢复；分别保留周收集、周NPC任务和偷窃的确认进度。
- 修复新手通行证定义与进阶领取，单个无法识别的通行证不再阻塞其他可处理奖励。
- 改进料理共享材料不足整份时的跨期分配，结合后续供给评估余量；不依赖历史保留记录。
- 领地工具新增砍树阶段下限，默认只砍成熟树；自动瞄准同样保护低于下限的树。
- 诊断导出补充异常现场，区分指令提交和实际执行，重复错误去重。

## English

- Game location is now a compact row with a separate editor. Trading funds and break-even resale options move into Daily settings.
- Adds a daily-queue-only Talent Pill reserve, defaulting to 0. Optional automatic refill is off by default and buys to a configurable target only at the weekly NPC quest discount. Shortages show actionable details; verified refills resume the task.
- Improves recovery from stale room/guild requests, disappearing restaurant bubbles and weekly map transitions. Collection, NPC quests and theft preserve separate confirmed progress.
- Fixes newbie pass definitions and reward progression; one incompatible pass no longer blocks other readable rewards.
- Improves cross-period allocation of shared ingredients left below a whole recipe batch, using future supply without relying on saved reserve history.
- The integrated Territory tool now supports a minimum tree growth stage. Fully grown trees remain the default, and auto-aim protects younger trees.
- Diagnostic exports include deduplicated failure snapshots and distinguish command submission from execution.

**If automatic updating fails, download the full package manually.** Close the old app and extract into a new folder without mixing versions. Accounts and settings remain in their user-data directory.

| Package | Runtime | Best for |
| --- | --- | --- |
| **Portable** | Includes the .NET 8 desktop runtime | First-time users or systems without the runtime |
| **Lite** | Requires .NET 8 Desktop Runtime x64 | Systems with the runtime; smaller download |
