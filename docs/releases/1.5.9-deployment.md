## Scope and acceptance

This release includes the November 16 trading transition and subsequent pricing
strategy, route recovery from actual arrival positions, second-account onboarding,
and the plugin marketplace. The existing control lock, single-instance ownership,
account identity and immutable update transactions remain in use.

Full synthetic validation passed **7,445 checks in 132 groups**. Final Portable
and Lite packages passed their startup, language, tool/session and component
checks. A missing runtime translation and a UI smoke fixture that reused another
case's saved selection were corrected before final packaging. The unchanged
application evidence was reused with the documented artifact rechecks; failed
attempts and their diagnostics remain separately identified.

The actual released **1.5.8** self-copy updater passed **10 cases** across both
editions: upgrade, failed-target startup rollback, interruption recovery through
the host and preserved helper, and damaged-baseline refusal without installation
writes. Exact files, startup and account/plugin sentinels were verified.
Interruption was injected; this was not a physical power-cut test.

The public textbook plugin and existing private plugin passed **60** combined
lifecycle/compatibility checks against the exact final Portable and Lite hosts.
First-install consent was checked in three languages and both themes. All users
may opt in; the single choice controls both solution upload and download.
Local-only is the default, uses no solution service and excludes shared-origin
cached solutions. Updates preserve consent; changing it cancels pending requests.

The public solver uses a default 60-second per-stage calculation budget. Its
NativeAOT worker and stripped native kernel are distributed separately from the
host. No complete game tables, game assemblies, credentials or debug symbols are
included in the public plugin. Recorded scenarios and independent Linux replay
were used; no game was launched, connected to or operated for this release.

## Plugin and shared solutions

The signed market lists textbook plugin **1.0.0**, requiring host **1.5.9**.
Archive size: **2,614,491 bytes**. SHA-256:
`0afee13cb3a72bd6002a53253fa992940bc2ea94df16054c0cd3e72b7515cc55`.

Plugin archives use the object-store CDN through a fixed website download URL.
The origin retains a fallback copy. A separate availability check withdraws the
redirect when the immutable object is unavailable or has an unexpected length;
the ordinary URL then serves the origin copy. Explicit fallback, automatic
withdrawal/recovery and actual market download/install with the released host
were verified. Signed catalogs, solutions and verification APIs stay on the origin.

The compressed submission service was tested with a recorded puzzle: anonymous
reservation, duplicate suppression, asynchronous upload, independent replay,
signed solution download, and subsequent duplicate suppression all passed.
Stopping the verifier did not interrupt static solution downloads; the verifier
was restored and checked. Replay validates the submitted declarative conditions,
not official provenance; clients must still review against their current game.
Unsupported mechanisms affect only their own submissions. No game installation
or current game tables are required by the server.

The original website stayed at 0.9.29. Temporary deployment copies were removed;
the temporary administrator key was revoked, fresh authentication was rejected,
and the local temporary key was removed. The protected signing-key backup and
server rollback configuration remain available.
