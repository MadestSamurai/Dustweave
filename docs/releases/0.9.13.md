# Dustweave · 织尘 0.9.13

## 更新内容

本版汇总 0.9.0 正式发布后的更新。

- 新增插件管理：本地 ZIP 导入、兼容性检查、启用／停用及版本回退。运行中的任务保留原版本，变更在重启主程序后生效。
- 新增可选 Sandboxie 隔离多账号和集中队列，默认同时执行两个账号；修复普通／隔离窗口间的登录凭据同步与归属登记恢复。
- 适配 10 月 8 日客户端更新，修复通行证读取和后台查询提示导致的中断；拼图活动按现有代币批量翻开，狩猎直接遵循所选优先级。
- 定时执行改为每天固定时间，账号卡片支持添加、移除和拖动排序；版本说明和确认弹窗统一适配深浅主题。
- 加入签名差分 OTA，不适用时自动回退完整包。0.9.0 需要先完成一次完整更新，之后可使用差分。

## Changes

- Manage local plugin packages with compatibility checks, enable/disable controls and version rollback. Running tasks retain their selected version; changes apply after restarting Dustweave.
- Optional Sandboxie instances and centrally managed concurrent queues; corrected credential synchronization and missing registration recovery.
- Updated client bindings, pass reading and background-notification handling. Reveal event puzzle tiles in batches and follow configured hunting priorities.
- Daily fixed-time schedules with reorderable account cards, themed dialogs and signed differential updates with a full-package fallback.

Both packages have the same features and three languages. Keep the repository private and distribute plugins separately. Source/package checks passed; complete live daily queues and the updated event paths remain separate runtime acceptance work.
