## English

**Version 1.5 was released over 48 hours ago. Please download the latest complete package manually.** The 1.4 series no longer receives ongoing fixes or new features and may encounter issues already fixed in newer releases.

Use the GitHub or Quark links above (Quark code: **5AgC**). Exit the old version, extract the complete new package into a **new folder**, keep its `app` folder and start its `Dustweave.exe`. Accounts and settings are retained. Re-save Windows startup and scheduled runs in the new version if enabled.

The startup notice supports Simplified Chinese, Traditional Chinese and English. Closing it exits Dustweave. Type **I do not need an update** or **我不需要更新** to continue this launch. Game launch, daily tasks and tools remain blocked until confirmation. Each fresh launch asks again.

This is a migration reminder based on 1.4.18, not a backport of subsequent 1.5 fixes. Users already on 1.5 should keep their current version.
