# Dustweave · 织尘 0.9.1

- 版本说明在主窗口显示后弹出，后方界面变暗，深色模式不再出现白底弹窗。
- 统一确认、账号编辑、任务详情与跑商窗口的标题区域；保留关闭按钮、Esc 和键盘焦点。
- 定时执行账号改为可添加、移除的卡片，支持搜索添加、拖动排序、跨行插入提示和 Ctrl＋左右键调整；保存后按新顺序执行。
- 新增签名差分更新，复用单文件程序及数据中的未变内容。补丁不适用或校验失败时自动回退完整包，沿用失败回退与中断恢复。

## English

- Release notes appear after the main window renders, over a dimmed workspace, with proper dark-theme colors.
- Confirmations, account editing, task details and trading use consistent custom headers, close controls and keyboard behavior.
- Scheduled accounts use removable cards with searchable additions, drag-to-reorder, wrapped-row insertion cues and Ctrl+Left/Right keyboard ordering. Saved schedules retain the new order.
- Signed delta updates reuse unchanged executable and data content. Missing or invalid patches automatically fall back to full packages, retaining rollback and interruption recovery.

Use GitHub Release assets for first installs. Domestic hosting is reserved for in-app OTA. Version 0.9.0 needs one full update before it can use deltas. The game does not need to restart.
