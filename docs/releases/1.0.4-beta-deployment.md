## Terminology and scope

Game navigation identifies `MenuUI` as 主菜单 / 主選單 / main menu, separately from cartridge maps, the plaza and mode lobbies. The account identity guard accepts fresh, advancing verified character snapshots without requiring a specific town. Setup and connection guidance now use the main-menu wording; a process-location failure only asks the user to start the game. README files, setup/client-update documentation, demonstration scenes and the integrated Equipment Assistant are aligned in the supported languages.

This release also contains the previously local startup fix, shared game-location setting, first-use account verification and highlighted page tour. Existing accounts are not forced to repeat setup. No live game connection, automation or account change was performed for this release.
