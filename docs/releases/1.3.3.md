# Dustweave 1.3.3

## 中文

- 新增侧栏底部的「软件设置」，集中管理外观、语言、游戏与沙盒位置、关闭方式、更新和日志清理。支持登录 Windows 时启动织尘，默认关闭；是否自动执行日常单独设置。
- 重新整理账号管理：保存账号、登录新账号与恢复上次登录并排放置；列表集中管理账号、日常预设与执行队列。移除批量验证登录和单独的隔离启动入口，沙盒并行在队列执行方式中选择。
- 沙盒绑定先显示自动匹配结果；点击「不是这个」才展开手动选择。保留账号与原目录核对，避免误绑定。
- 日常设置按日常奖励、战斗、每周、资源与跑商分类，修正居中错位与输入框对齐。搜索跨分类查找；输入错误时展开对应设置并保留原值。
- 定时执行合为连续的计划编辑页面，底部保存按钮始终可见，明确区分已保存的下次执行时间和未保存修改。
- 精简诊断页，只保留当前连接状态与问题反馈；移除高级公会检查、历史操作提示和时间线跳转。更新记录默认只展开最新版。
- 启动引导放到窗口顶部，与连接按钮相邻。统一下拉菜单、键盘焦点、深浅色与三种语言的排版；没有账号时提供明确的设置入口。

1.3.1／1.3.2 可通过新版 OTA 差分升级。若自动更新失败，请手动下载完整软件包，解压到新目录并启动根目录的 `Dustweave.exe`。账号与设置继续保留。Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。请保留 `app` 文件夹。

## English

- Adds **App settings** at the bottom of the sidebar for appearance, language, game and sandbox locations, closing behavior, updates and log cleanup. Starting Dustweave at Windows sign-in is optional and off by default; running daily tasks is a separate choice.
- Reorganizes Accounts: save, new sign-in and restore actions share one row, while the list focuses on saved accounts, task presets and the execution queue. Batch sign-in checking and standalone isolated launch entries are removed; sandbox parallelism remains available in queue execution mode.
- Sandbox repair presents the verified automatic match first. **Not this one** reveals manual selection. Account and original-directory checks remain in place.
- Groups Daily settings into rewards, battles, weekly tasks and resources/trading. Fields stay aligned; search crosses categories, and invalid input opens its section without losing the entered value.
- Combines scheduling into one continuous editor with a fixed save button. The saved next run and unsaved changes are clearly distinguished.
- Simplifies Diagnostics to connection status and problem reporting. Advanced guild checks, historical operation messages and timeline navigation are removed. Update history expands only the newest release by default.
- Moves Getting started beside Connect to game in the window header. Refines dropdowns, keyboard focus, both themes and all three languages, with a clear account setup action for first-time users.

Versions 1.3.1 and 1.3.2 support differential OTA upgrades. If updating fails, extract the complete package into a new folder and launch the root `Dustweave.exe`; accounts and settings are retained. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64). Keep the `app` folder.
