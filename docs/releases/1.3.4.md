# Dustweave 1.3.4

## 中文

- 修复「打开软件自动执行」完成登录检查后就中断的问题。已完成的旧记录在清理详细数据后，不再被当作待恢复的操作读取；普通执行和沙盒账号队列均适用。
- 并行队列中断时显示具体原因并保留接续入口，区分用户主动暂停和程序异常。成功恢复后清除过期错误提示。
- 诊断保留完整错误位置，便于定位问题。未确认的消耗操作仍按当前游戏状态核对，不会因为历史记录缺少数据而直接认定成功。

已对 5,109 条本地历史记录进行只读回放，原先的 26 次解析失败均已消除；另有针对恢复、队列和界面的回归检查。本次未重新运行实机日常。

1.3.1–1.3.3 支持新版 OTA 差分升级。若更新失败，请手动下载完整软件包，解压到新目录并启动根目录的 `Dustweave.exe`。账号与设置继续保留。Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime（x64）。请保留 `app` 文件夹。

## English

- Fixes automatic daily execution stopping after sign-in checks. Completed historical operations are no longer read as pending recovery work after their detailed data has been compacted. This applies to normal and sandbox account queues.
- Parallel interruptions retain the specific reason and a resume action, distinguishing an intentional pause from an application error. A successful resume clears stale errors.
- Diagnostics retain the full error location. Unconfirmed resource-consuming actions still reconcile against the current game state; missing historical details do not count as success.

Read-only replay of 5,109 local historical records resolved all 26 previous parsing failures, alongside recovery, queue and interface regression checks. Live daily automation was not rerun for this release.

Versions 1.3.1–1.3.3 support differential OTA upgrades. If updating fails, extract the complete package into a new folder and launch the root `Dustweave.exe`; accounts and settings are retained. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime (x64). Keep the `app` folder.
