## English

Run selected accounts from the Accounts page, schedule fixed account queues, and update Dustweave from inside the app.

- Schedules are opt-in, with weekday/time selection and duplicate-run protection. Windows can start a closed app while the computer is awake and the user is signed in.
- Release notes appear once per version. Signed updates download in the background, resume interrupted transfers and ask before restarting while idle. Failed startups roll back; interrupted replacements recover on the next launch.
- Improved messages in all three languages and reduced repeated waits during collection and ability selection.

Extract the complete package into a new folder and launch `Dustweave.exe`. Accounts, settings and history are retained. This first OTA-enabled version requires a manual installation.

本次发布通过合成回归、三语界面与成品升级／回退检查；真实定时游戏队列仍需正常使用验收。源码仓库保持私有，分发包不含外部插件。
