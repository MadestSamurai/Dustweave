# Dustweave 1.5.2

- **更快赶路**：商店、告示牌等游戏内可用的快捷移动纳入路线选择，近处仍可直接步行；减少路线计算和换图后已可操作时的等待。快捷移动到告示牌附近，不再额外开隐身。
- **快速赶路默认开启，移除实验性标记**：修复快速赶路技能被错误拦截的问题。已有加速效果可跨路段继续利用，按距离和效果剩余时间判断，减少重复开技能。本次升级会为原先关闭的账号开启快速赶路，之后可在“日常设置 → 全体设置”关闭，后续不会反复开启；仍遵守天赋药保留量。
- **周 NPC 任务**：修复任务道具与指引标记混淆、无法正确走向拾取和搬运目标的问题。任务服务器明确拒绝时说明原因并暂缓对应任务，避免已知错误弹窗卡住后续流程；不会把未完成任务标成完成。
- **周常制作装备**：材料不足时继续尝试其他可制作的 N 装，直到完成目标或没有可制作项；补全选择装备时的提示文字。
- **操作稳定性与界面**：奖励任务列表尚未填充、刷新或回收列表项时，不再提前领取或关闭。版本更新页移除重复下载行，保留“重新下载”入口。

战术教材插件的奖励列表流程另有配套更新；使用该私有插件的用户需同时更新插件。本体安装包不包含私有插件。本次修正了已确认的列表加载时序问题，尚未复现用户反馈的偶发闪退，不能保证所有闪退都由同一原因引起。

1.5.0／1.5.1 可在软件内检查更新。1.4 及更早版本请手动下载完整包并解压到新目录。请保留 `Dustweave.exe` 旁的 `app` 文件夹。

更新无法应用时，请从本页附件或[夸克网盘](https://pan.quark.cn/s/0ee553c60c0d?pwd=5AgC)重新下载完整包，提取码 **5AgC**。Portable 自带运行库；Lite 需要 .NET 8 Desktop Runtime x64。

## 繁體中文

- 將商店、告示牌等可用的快捷移動納入尋路，減少計算與換圖後起步等待；快捷抵達告示牌附近不再額外開隱身。
- 快速趕路移除實驗性標記並預設開啟，本次也會為原先關閉的帳號開啟；之後可在日常設定的整體設定關閉，不會反覆啟用。修復技能攔截、沿用剩餘加速效果，仍遵守天賦藥保留量。
- 修復週 NPC 任務道具辨識、拾取及搬運導航；已知任務錯誤會說明並暫緩對應任務，避免阻擋後續日常。
- 週常製作裝備在缺料時改試其他可製作的 N 裝，並補齊提示。
- 避免獎勵任務清單載入或刷新時提前操作；更新頁保留單一組重新下載入口。

戰術教材私有插件需同步更新，本體不包含插件。已修正清單載入時序問題，但尚未重現使用者回報的偶發閃退。

1.5.0／1.5.1 可在軟體內更新。1.4 與更早版本需手動下載完整套件至新目錄；請保留 `app` 資料夾。無法套用更新時，請從附件或上述網盤重新下載。

## English

- Routing now considers available native shop and quest-board shortcuts, while retaining short walks when faster. Reduced planning and movement-start delays; a nearby board shortcut no longer triggers unnecessary stealth.
- Fast travel is no longer experimental and is enabled by default, including previously disabled accounts on this upgrade. You can turn it off under Daily settings → General; that choice will be retained. Fixed rejected speed talents and reuses active effects while respecting the talent-pill reserve.
- Fixed weekly NPC quest prop selection and navigation for collection and carrying. Known server rejections defer the affected task with an explanation instead of blocking subsequent tasks.
- Weekly equipment crafting tries other craftable N items when materials are insufficient, with clearer progress messages.
- Prevents premature interaction with reward lists during loading or refresh. Removes duplicate download links from the updates page.

The private tactical-training plugin has a companion update and is not included in these packages. The confirmed reward-list timing gaps are fixed; the reported intermittent game crash has not been reproduced.

Users of 1.5.0 or 1.5.1 can update in the application. Users of 1.4 or earlier must download the complete package into a new folder. Keep the `app` folder beside `Dustweave.exe`. If an update cannot be applied, download the complete package from the release assets or Quark above. Portable includes the runtime; Lite requires .NET 8 Desktop Runtime x64.
