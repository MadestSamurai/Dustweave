This release adds signed installation repair and cloud-backed file delivery, fixes weekly-collection reconnect recovery, fishing settlement and equipment inventory reads after stopping, sets Salvation Tower sweep quantities directly, and prevents the startup connection check from taking over an approved update restart. It also includes the prepared diagnostic, daily-settings and safe repeated-read improvements.

The earlier unpublished 1.4.14 local candidate changed the launcher and failed the old-helper compatibility gate. The published package restores the exact 1.4.13 bootstrap. Repair is available from the desktop and independent `app/support/Dustweave.Updater.exe`; an automatic launcher failure prompt and `Dustweave.exe --repair` are not shipped. Future automatic bridge updates will deliver those capabilities without permanently freezing the launcher; see [the update evolution plan](../UPDATE_EVOLUTION.md).

Users of the earlier same-version local test package should install the published full package into a fresh directory. Its version number alone does not identify the final package, and same-version update detection must not be treated as validation of its bytes.
