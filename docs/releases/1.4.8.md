# Dustweave 1.4.8

- **周收集恢复**：捕获次数用尽后，仅剩捕获目标的地图明确留待次日，继续其他可执行目标。修复步行拾取的隐身校验冲突及无拾取回执时的停滞恢复；有限次重新寻路仍不可达时跳过该点。补跑仍遵循“步行收集”设置，不会因吸收次数用尽自动改为步行。
- **地图与入口**：收集查询会处理已知的地图奖励、卡带列表遮挡，地图变化后重新规划。连连看先进入实际大厅再准备组件；前往广场商人时误入末日之书大厅可返回原路线。
- **藏红花**：农田未载入时先接近已登记的农田，确认数据及收割条件后才使用料理；无法接近或仍未载入时给出原因，不消耗新料理。
- **组件准备**：减少无关方法的重复计算并复用有效缓存，补充准备阶段及耗时记录。实际耗时仍取决于设备与客户端版本。
- **执行进度**：显示当前动作与地图进度，长环节按工作量计入总进度；单账号在步骤变化时跟随当前行，多账号在各自账号下显示当前环节和动作。

- **Weekly collection recovery:** capture-only maps wait until the next daily reset when the capture allowance is exhausted. Walking pickup uses consistent stealth checks and bounded navigation recovery, then defers unreachable points. Reruns follow the walking-collection setting; exhausted absorption does not enable walking automatically.
- **Maps and entrances:** collection queries dismiss known map-reward and cartridge-list overlays and replan after location changes. Sichuan enters its actual lobby before component preparation. Travel to square merchants can return from an accidentally opened Book of Apocalypse lobby.
- **Saffron:** approach registered fields that have not loaded before checking harvest readiness. No new food is consumed during this preparation or when it fails.
- **Component preparation:** reduce unnecessary method processing, reuse valid caches and record preparation timing. Actual speed depends on the device and game version.
- **Execution progress:** show the current action and map counts, weight longer stages by work, follow active single-account steps, and display each account's current stage and action in batch runs.
