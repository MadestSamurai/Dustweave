# Dustweave 1.4.11

- **日常顺序**：新队列依次执行其他日常、日常／周常／通行证奖励、活动任务／转盘／代币兑换、周收集／周 NPC／每周偷窃、跑商、邮箱收尾。先取得奖励中的金币和天赋药，周 NPC 仍在跑商前完成。单账号、多账号及已有任务预设均使用新顺序；接续旧队列保留原顺序与进度。
- **执行进度**：按今天可执行的次数显示细分进度，周收集等长环节有更高权重。已经处理过的环节计入执行进度，100% 表示本次队列已处理完，不代表所有游戏目标均已完成；暂缓、失败及战斗回退仍在详情和结果汇总中说明。暂停记录及普通／隔离窗口之间保留已确认的进度。
- **暂停恢复**：修复偷窃回执混入其他天赋回执后异常退出核对、导致重连也无法继续的问题。只排除可以明确配对的无关回执；无法判定的记录继续保留现场，不虚报成功，也不盲目重复消耗。
- **料理名称**：自定义料理列表及材料使用游戏当前名称，并随简体中文、繁体中文、英文切换；支持跨语言搜索，已保存的料理选择及顺序不变。
- **定时与更新**：版本说明、下载完成和手动更新提醒不再阻挡定时日常。到点先收起提醒并执行日常；实际安装仍遵守空闲与确认条件，不会在队列运行中重启更新。

- **Daily order:** new queues collect daily/weekly/pass rewards and event rewards before combined weekly collection, NPC quests and theft, followed by trading and final mail collection. NPC discounts remain available before trading. Applies to single-account runs, batches and saved presets; resumed queues retain their original order and progress.
- **Run progress:** counters reflect work executable today, with larger weights for lengthy stages. Handled stages advance run progress; 100% means the run has been handled, not that every game objective succeeded. Deferred objectives, failures and battle fallbacks remain visible. Confirmed counters survive pauses and normal/isolated window transfers.
- **Pause recovery:** prevents unrelated talent replies from breaking theft reconciliation and repeatedly pausing the queue. Only unambiguously paired unrelated replies are excluded; uncertain records retain their evidence without claiming success or blindly repeating actions.
- **Recipe names:** custom recipes and ingredients use current game names in Simplified Chinese, Traditional Chinese and English, with cross-language search. Saved recipe identities and order are preserved.
- **Scheduling and updates:** informational update windows no longer block scheduled runs. Due queues take priority over update reminders; installation still requires confirmation and an idle application.

Portable 自带运行库；Lite 需要 .NET Desktop Runtime 8 x64。使用 GitHub Release 完整 ZIP 或软件内 OTA；更新失败时请手动下载完整包并解压。1.4.7 起的直接差分仍按 10 MB 上限判断支持范围。

Portable includes the runtime; Lite requires .NET Desktop Runtime 8 x64. Use the full GitHub Release ZIP or in-app OTA. If updating fails, download and extract the complete package. Direct patches from 1.4.7 onward retain the 10 MB eligibility policy.
