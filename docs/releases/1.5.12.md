# Dustweave 1.5.12

## 简体中文

- 修复死魂之盘出售角色后可能异常暂停的问题，改用游戏已确认的出售结果同步金币，避免多余的关卡刷新。
- 减少日常记录和魂盘运行记录中的重复数据，降低持续使用时的缓存增长。
- 优化更新缓存：减少重复更新副本，空闲时清理已完成更新留下的文件，同时保留必要的回退与中断恢复数据。
- 修复仅残留启动设置、尚未创建沙盒的账号阻止存储迁移的问题。真实的沙盒绑定异常会显示具体账号、路径和原因，保留原数据。
- 补全魂盘异常诊断，优先保留挑战状态和错误记录，便于定位意外暂停。

## 繁體中文

- 修復死魂之盤出售角色後可能異常暫停的問題，改用遊戲已確認的出售結果同步金幣，避免多餘的關卡重新整理。
- 減少日常紀錄及魂盤執行紀錄中的重複資料，降低持續使用時的快取成長。
- 最佳化更新快取：減少重複更新副本，閒置時清理已完成更新留下的檔案，同時保留必要的回復與中斷恢復資料。
- 修復僅殘留啟動設定、尚未建立沙盒的帳號阻止儲存空間遷移的問題。實際的沙盒綁定異常會顯示具體帳號、路徑及原因，保留原資料。
- 補全魂盤異常診斷，優先保留挑戰狀態及錯誤紀錄，便於定位意外暫停。

## English

- Fixes an unexpected Soul challenge pause after selling a unit. Coins now synchronize from the game's confirmed sale result without an unnecessary dungeon refresh.
- Reduces duplicate data in daily-task and Soul records to slow cache growth during continued use.
- Reduces redundant update copies and cleans completed update files while idle, preserving the data needed for rollback and interrupted-update recovery.
- Fixes storage migration being blocked by leftover launch preferences for accounts without a created sandbox. Actual sandbox binding errors now identify the account, path and cause while preserving existing data.
- Improves Soul diagnostics by prioritizing challenge status and error records when exporting a diagnostic package.
