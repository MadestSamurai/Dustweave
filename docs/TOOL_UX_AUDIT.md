## 本批改动（2026-11-13）

- `ToolWindowDesign`：工具把 `ConnectButton.Tag` 设为 `"next"` 时，连接按钮使用主按钮样式。
- 宅邸：回合数据与图例在首帧数据到达后才显示。
- 连连看：间隔改完即生效，去掉「应用间隔」；补单位；自动本局说明改为告诉玩家按钮做什么；README 同步。
- 领地：寻路开关改为白话，去掉与下方说明重复的悬停提示；README 同步。
- 恶魔猎人：未连接时状态改为「在游戏中进入恶魔猎人大厅，然后点击『连接游戏』」。
- 钓鱼、领地、音游、连连看、恶魔猎人、宅邸：接入连接按钮高亮。
