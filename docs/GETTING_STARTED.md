# 开始使用织尘

[English](GETTING_STARTED.en.md) · [返回首页](../README.md)

## 准备

- Windows x64，已正常安装并登录的 BrownDust II 原生 PC 客户端。
- 完整解压的 Dustweave 包：Portable 包含运行时；Lite 需要 .NET 8 Desktop Runtime x64。
- 首次安装或手动升级请从 [GitHub Releases](https://github.com/MadestSamurai/Dustweave/releases) 获取完整包。国内线路仅作为软件内 OTA 更新入口。GitHub 的 Source code 压缩包不是安装包。

启动 `Dustweave.exe`。程序文件夹中的 `data`、`flows`、`connection` 等目录是分发内容，需一同保留。源代码构建输出仅供开发，不等于完整用户包。

## 第一次运行

1. **打开启动引导，确认游戏位置。** 首次未保存账号时会自动出现；也可从 **账号管理 → 启动引导**重新打开。选游戏本体 `BrownDust II.exe`，确认后尝试启动一次。游戏已运行时直接验证当前游戏。
2. **进入游戏，等待识别。** 请在游戏中完成登录并进入主菜单。织尘准备连接并核对真实角色信息，识别成功后会提示角色名。
3. **正常退出，再保存账号。** 按提示关闭游戏与启动器，填写易区分的账号备注名后保存。此时保存的是正常退出后最新的登录状态；身份变化时需要重新验证。
4. **跟随分页导览。** 高亮框会带你了解今日任务、日常设置、工具、账号、定时执行、插件、诊断和更新入口。只介绍功能，不执行日常。
5. **以后由织尘启动游戏。** 在账号列表点击 **进入游戏**。避免从桌面快捷方式或加速器内启动游戏；需要加速时只开启加速服务。
6. 按账号配置日常环节，先选择少量任务验证，再启用多账号队列或定时执行。

引导可以跳过，跳过前会提示尚未完成配置的影响，不会关闭游戏或清除登录。已保存账号的用户不会因升级被强制重新验证。游戏位置也可随时在 **日常设置 → 游戏启动位置**修改，所有账号共用，下一次启动生效。

## 工具与外观

在**工具**页打开钓鱼、领地或小游戏。打开窗口不等于启用自动化；当某个工具实际运行或等待结算时，主程序协调控制权。结束当前自动操作后，再运行另一项任务。

在主窗口选择简体中文、繁體中文或 English，内置工具跟随切换。可选择浅色、深色或跟随系统。文档中的界面截图使用演示数据，不代表真实账号的执行结果。

## 停止与补跑

需要中止时使用工具的停止入口，留意已经提交的操作是否还在结算。补跑时选择需要重新执行的环节，先核对当前账号和游戏状态；不要因为记录显示异常就重复确认未知的消耗操作。

## 更新与数据

从首个公开版 1.0.0-beta 起，在左下角「版本更新」管理 OTA。默认自动检查并优先后台下载差分包，空闲时确认重启更新；账号、设置与插件保留，失败时恢复旧版。1.0.0 之前的内部版本不再维护升级兼容，请手动完整解压到新文件夹，并退出旧工具后启动。普通界面更新不要求重启游戏；遇到明确的组件提示时按提示处理。

日常数据默认位于 `%LOCALAPPDATA%\BD2DailyAssistant`，账号会话位于 `%LOCALAPPDATA%\BD2AccountSessionManager`；自定义数据目录的使用者以自己的设置为准。更换软件解压目录不会自动清空这些数据。

账号会话受当前 Windows 用户的数据保护机制保护；不要把会话目录当成可直接跨电脑搬运的普通配置，也不要作为问题附件上传。

## 遇到问题

| 现象 | 先检查 |
| --- | --- |
| Lite 无法启动，提示缺少运行时 | 安装 **.NET 8 Desktop Runtime x64**，或使用 Portable |
| 提示缺少数据或组件 | 是否只复制了 EXE；重新完整解压同一版本的包 |
| 无法连接游戏 | 游戏是否运行、客户端是否刚更新、工具显示的权限/准备错误；先记录原始提示 |
| 其他任务正在使用连接 | 先在对应工具中停止自动化并等待当前结算，不是反复点连接 |
| 环节等待或中断 | 保存版本、环节、时间、最后提示与实际游戏画面；核对账号及是否有待处理弹窗 |
| 可选功能未显示 | 界面只显示当前可用功能；插件问题请核对版本与安装目录 |

不要把“以管理员身份运行”或“重启游戏”当成所有错误的固定解决办法。若游戏以管理员身份运行，连接可能需要相应权限；按程序的具体提示判断。

仍有问题请提交 [Issue](https://github.com/MadestSamurai/Dustweave/issues/new/choose)。提供版本、Windows版本、发生环节、预期与实际结果、复现步骤。日志只附相关时段，先检查账号标识、登录信息和其他私人数据；不要上传完整账号目录或用户采集库。安全问题见 [SECURITY.md](../SECURITY.md)。

从旧版本升级：完整解压到新目录，启动 `Dustweave.exe`；已有账号、设置和历史会自动沿用，无需迁移数据。不要将新旧程序混放在同一目录。
