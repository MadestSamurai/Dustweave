# 开始使用织尘

[English](GETTING_STARTED.en.md) · [返回首页](../README.md)

## 准备

- Windows x64，已正常安装并登录的 BrownDust II 原生 PC 客户端。
- 完整解压的 Dustweave 包：Portable 包含运行时；Lite 需要 .NET 8 Desktop Runtime x64。
- 首次安装或手动升级请从 [GitHub Releases](https://github.com/MadestSamurai/Dustweave/releases) 获取完整包。GitHub 的 Source code 压缩包不是安装包。

启动 `Dustweave.exe`。请保留根目录的 `Dustweave.exe` 和 `app` 文件夹；主程序和工具依赖已打包在 EXE 中，数据与说明在 `app` 中。源代码构建输出仅供开发，不等于完整用户包。

## 第一次运行

引导右上角可直接选择 **简体中文 / 繁體中文 / English**。语言即时应用到整个软件并保留到下次启动；切换不会重置当前步骤或账号备注。

1. **打开启动引导，确认游戏位置。** 首次未保存账号时会自动出现；也可从 **窗口顶部 → 启动引导**重新打开。选游戏本体 `BrownDust II.exe`，确认后尝试启动一次。游戏已运行时直接验证当前游戏。
2. **进入游戏，等待识别。** 请在游戏中完成登录并进入主菜单。织尘准备连接并核对真实角色信息，识别成功后会提示角色名。
3. **正常退出，再保存账号。** 按提示关闭游戏与启动器，填写易区分的账号备注名后保存。此时保存的是正常退出后最新的登录状态；身份变化时需要重新验证。
4. **跟随分页导览。** 高亮框会带你了解今日任务、日常设置、工具、账号、定时执行、插件、诊断、软件设置和更新入口。只介绍功能，不执行日常。
5. **以后由织尘启动游戏。** 在账号列表点击 **进入游戏**。避免从桌面快捷方式或加速器内启动游戏；需要加速时只开启加速服务。
6. 按账号配置日常环节，先选择少量任务验证，再启用多账号队列或定时执行。

引导可以跳过，跳过前会提示尚未完成配置的影响，不会关闭游戏或清除登录。已保存账号的用户不会因升级被强制重新验证。游戏位置也可随时在 **软件设置 → 游戏与沙盒位置**修改，所有账号共用，下一次启动生效。

## 工具与外观

在**工具**页打开钓鱼、领地或小游戏。打开窗口不等于启用自动化；当某个工具实际运行或等待结算时，主程序协调控制权。结束当前自动操作后，再运行另一项任务。

在**软件设置 → 外观与语言**选择简体中文、繁體中文或 English，内置工具跟随切换。可选择浅色、深色或跟随系统。文档中的界面截图使用演示数据，不代表真实账号的执行结果。

## 停止与补跑

需要中止时使用工具的停止入口，留意已经提交的操作是否还在结算。补跑时选择需要重新执行的环节，先核对当前账号和游戏状态；不要因为记录显示异常就重复确认未知的消耗操作。

Windows 桌面本身使用管理员权限时，织尘会在同一用户和登录会话下沿用现有权限启动游戏，无需修改系统设置；普通权限桌面仍优先用于启动。连接需要提权时，只对连接组件提出请求。

## 更新与数据

在「版本更新」检查新版。默认自动检查并在后台下载更新，空闲时确认重启即可安装；账号、设置与插件保留，失败时恢复旧版。普通软件更新不要求重启游戏。

从 1.4 及更早版本升级到 1.5，需要手动下载完整包并解压到新目录，更新快捷方式，并重新保存开机启动及定时设置。自动更新无法应用或程序损坏时，也请从 [GitHub](https://github.com/MadestSamurai/Dustweave/releases/latest) 或[夸克](https://pan.quark.cn/s/0ee553c60c0d?pwd=5AgC)（提取码 **5AgC**）重新下载完整包。

日常数据默认位于 `%LOCALAPPDATA%\BD2DailyAssistant`，账号会话位于 `%LOCALAPPDATA%\BD2AccountSessionManager`；自定义数据目录的使用者以自己的设置为准。更换软件解压目录不会自动清空这些数据。

账号会话受当前 Windows 用户的数据保护机制保护；不要把会话目录当成可直接跨电脑搬运的普通配置，也不要作为问题附件上传。

旧版更新若在没有安装插件时提示「插件不支持此版」，请手动下载当前完整软件包，关闭旧版后解压到新目录启动。无需安装插件，原账号和设置会继续沿用。

## 遇到问题

| 现象 | 先检查 |
| --- | --- |
| Lite 无法启动，提示缺少运行时 | 安装 **.NET 8 Desktop Runtime x64**，或使用 Portable |
| 提示缺少数据或组件 | 是否只复制了 EXE；重新完整解压同一版本的包 |
| 无法连接游戏 | 游戏是否运行、客户端是否刚更新、工具显示的权限/准备错误；先记录原始提示 |
| 其他任务正在使用连接 | 先在对应工具中停止自动化并等待当前结算，不是反复点连接 |
| 环节等待或中断 | 保存版本、环节、时间、最后提示与实际游戏画面；核对账号及是否有待处理弹窗 |
| 可选功能未显示 | 界面只显示当前可用功能；插件问题请核对版本与安装目录 |

不要把“以管理员身份运行”或“重启游戏”当成所有错误的固定解决办法。若游戏以管理员身份运行，连接可能需要相应权限；按程序的具体提示判断。

仍有问题请提交 [Issue](https://github.com/MadestSamurai/Dustweave/issues/new/choose)。提供版本、Windows版本、发生环节、预期与实际结果、复现步骤。日志只附相关时段，先检查账号标识、登录信息和其他私人数据；不要上传完整账号目录或用户采集库。安全问题见 [SECURITY.md](../SECURITY.md)。

从旧版本升级：完整解压到新目录，启动 `Dustweave.exe`；已有账号、设置和历史会自动沿用，无需迁移数据。不要将新旧程序混放在同一目录。

沙盒改名后：在账号管理选择对应账号，点击「修复沙盒绑定」。关闭该沙盒中的游戏及工具窗口后，软件先显示自动核对一致的候选；点击「使用此沙盒」完成绑定。候选不合适时点击「不是这个」，再手动选择并确认。不要删除原沙盒数据。

## 软件与定时设置

侧栏底部的**软件设置**集中管理语言、外观、游戏与 Sandboxie 位置、关闭方式、更新和日志清理。登录 Windows 时启动织尘默认关闭，与打开软件后执行日常分别设置。选择关闭方式会立即保存。

**定时执行**是一份单独保存的计划：设置时间，添加账号并拖动排序，选择逐个执行或沙盒并行，最后点击始终位于底部的保存按钮。页顶显示的是已保存计划的下次执行时间；未保存修改不会改变已有定时任务。
