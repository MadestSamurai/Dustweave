# 插件市场与教材共享解法

设计日期：2026-10-31。目标版本：1.5.9。本文是实施规格；未完成的项目不代表已经发布。

## 使用过程

插件页面提供「插件市场」与「已安装」两个入口，沿用主程序的主题、字号和按钮。进入页面才读取市场，不参与启动连接检测。网络失败时保留已安装功能和缓存目录，允许手动重试、导入本地 ZIP。

市场条目显示名称、用途、版本、大小、发布者及安装按钮。安装前确认将启用的插件；当前接口只允许一个插件生效，切换会明确提示原插件停用。下载可以取消。完整校验、解压检查和独立试加载全部通过后才选择新版本；失败保留原选择。提示重启织尘生效，安装本身不启动游戏或自动执行日常。已安装页面保留停用、删除和回退。

公开教材插件只提供战术教材功能，不携带活动战斗或完整游戏数据表。游戏规则从本机当前游戏读取并按版本缓存。教材设置保留「启用」与「每关计算时间」，新默认值为 60 秒；不擅自覆盖用户明确保存的其他时限。

首次安装在同一个安装确认窗选择「仅本地计算」（默认）或「参与解法共享」。后者同时启用下载与自动贡献，不拆成两个互相矛盾的开关。说明只发送该题的计算输入与解法，不发送账号信息；不承诺服务器认证官方数据。选择按插件保存，更新不重置；已安装页可随时修改。关闭后取消待发请求；此前已经公开的解法不会因关闭而撤回。

每关执行顺序：读取当前题目 → 检查本地解法 → 仅在启用共享时查询共享解法 → 本机复核 → 必要时本地求解 → 再次确认题目未变 → 执行。仅本地模式完全不访问共享服务，也不读取来自共享服务的解法缓存。查询有很短的独立超时，网络错误仅回到本地路线；不会让日常等待服务器恢复。一次求解预算覆盖缓存复核和搜索，不因尝试多个候选不断重置。超时、停止、当前账号或题目变化均不得执行半成品。保留现有战斗接续与奖励收尾机制。

任务列表只展示当前动作：「检查已有解法」「本地计算，剩余 … 秒」「已找到解法」「执行教材」。来源、复核结果与失败原因放在任务详情。未算出时提示本次时间已用完及如何延长，不自动无限重试。没有服务或已有解法时，用户仍可独立使用本地求解器。

## 谁可以上传

所有用户均可选择参与，不使用测试者名单，不要求游戏凭证。首次安装选择参与后，本机关卡确认通关且产生新解法时自动查重并分享，不要求每关再次确认。任务详情记录是否复用了共享解法、贡献状态及实际压缩体积。2026-10-31 最新用户决定覆盖 Goal 初始描述中的“仅授权测试者上传”和之前“每次主动点击分享”的设计；首次安装选择同时决定上传与下载。

先向服务器询问题目指纹是否缺失。已有可用解法或已收到核验数据的题目直接结束，不重新上传。服务器原子地预留该题并发放短期上传许可，只有一个客户端上传；其他客户端直接得到“已有数据”状态。上传完立即返回已接收，后续核验与客户端日常分离。上传中断后预留到期可重新申请；无效数据或失败解法不得永久占住题目。断网保留本地解法，不自动密集补传。请求频率、单项体积、预留总量及总队列容量由服务端限制，这些只保护上传服务，不限制下载或本地计算。

## 上传内容与压缩

只传可移植的初始战斗状态、该题涉及的技能和效果参数、战斗规则、解法决策、协议与内核能力版本。按字段白名单重新构造，不上传整个诊断记录、完整游戏数据库、账户库存、进程编号、路径、登录数据或凭证。

采用单个 UTF-8 JSON 经 Brotli 压缩，不使用可携带任意路径的文件归档。请求标明压缩体和解压体字节数及 SHA-256。双端限制压缩体 2 MiB、展开后 16 MiB、JSON 深度与对象数量；流式解压达到上限立即拒绝。内核实际需要的规则闭包必须完整，缺失引用不能当作默认值。压缩摘要只校验传输，语义指纹取规范化、白名单处理后的未压缩内容。

题目标识排除当前摆位、随机种子、客户端路径与账号标识；包含角色固定面板、敌人、技能效果、初始资源、胜负条件、地图和相关战斗规则。同一道题只因游戏版本号变化而规则未变时可以继续复用；实际数据改变时得到不同指纹。

## 服务器核验的边界

服务器不安装游戏、不抓最新游戏数据、不为用户搜索。它使用提交的题目与规则快照重放解法，核验是否在这些条件下通关。它不能凭此证明上传内容来自官方游戏，因此下载方必须用自己游戏的数据再次复核，且只接受严格匹配的题目。

上传不接受可执行程序、脚本、动态代码或任意客户端提供的内核。只支持服务器已安装的协议与内核能力。新版本只是数值或题目变化时可直接复算；遇到新机制或不支持的能力，仅该项标记「等待核验器更新」，不阻断其他提交或本机计算。

后台单工作进程逐个处理，单项设置独立时间、内存和输出大小上限；进程异常或超时隔离该项后继续下一项。每项只重放候选，不做择优搜索；失败有固定原因与有限重试，不形成永久队首阻塞。服务重启可恢复已接收任务。

通过后生成带签名、版本和题目指纹的静态压缩解法文件；公开目录只发布通过的解法，支持撤下单个错误解法。静态分发与上传、核验分离，核验停机不影响已有文件下载。客户端错误缓存短期有效，不能因一次失败永久禁止共享。

## 验收要求

- 未安装、离线目录、签名错误、过期目录、下载中断、取消、版本不兼容、包哈希/清单不匹配、试加载失败均不改变已选插件。
- 三种语言、两种主题、最小窗口尺寸；安装与求解状态有可见取消入口，不整体冻结无关页面。
- 首次安装两种选择、取消安装、升级保留选择、开关即时生效；仅本地模式零共享请求且不读取共享缓存。共享模式自动下载和通关后上传，未通关或旧结果不得上传。
- 本机完整离线求解；共享命中、不命中、损坏、网络超时、输入变化、错误候选与停止；总计算预算不因回退而重置。
- 压缩传输往返、篡改、截断、展开超限、隐私字段剔除、重复提交、并发预留、失效上传许可、队列满、未知能力、核验超时、工作进程崩溃和服务重启。
- 服务器核验使用提交的规则，不借用服务器的“当前游戏版本”；同题跨版本命中与改动后的题目隔离。
- 真实成品导入、试加载、启停与回退；发布前完成主程序与插件版本兼容验收，实机验证另记，不能用离线通过冒充实机通过。

## 交付顺序

先完成主程序市场、独立本地插件和离线验收，再接入共享下载与已选择参与的用户自动贡献；最后准备服务器安装、核验与回退方案并执行发布。服务器首次部署权限只在方案完整可审查后申请。1.5.9 原有修复及本次新增功能共同通过发布验收后，完成提交、推送、GitHub 与 OTA 上线。
