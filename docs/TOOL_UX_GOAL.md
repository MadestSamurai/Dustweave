# 工具界面 UX 优化 Goal

2026-11-07 启动的长任务。依据 `TOOL_UX_GUIDELINES.md`，从整体到细节逐个优化全部工具窗口的易用性、直观性与美观度。只改界面、文案与交互，不改自动化执行逻辑、保存格式、IPC 与恢复语义；不连接游戏、不打包、不发布。

## 验证方式

- **后台类型检查（每次改动）**：在本机 Linux 工作区用 .NET 8 C# 编译器，对当前源码加上一次 Windows 构建生成的 XAML 代码，引用 1.6.3 Portable 发布包内的程序集做类型检查。覆盖 Desktop 与 9 个工具项目；不覆盖 XAML 标记编译。
- **Windows 里程碑检查（每完成一批）**：`build.ps1` 后以 `DUSTWEAVE_UI_SMOKE_SCOPE=tool-preparation` 运行隔离冒烟，生成全部工具三语 × 明暗与紧凑尺寸截图；我逐张审阅后再进入下一批。
- 各工具原有自检（`VerifyForSmoke`、`*Smoke.cs`）随交互变化同步更新。
