# 界面说明文字消融对照

日期：2026-10-11。范围：Dustweave 桌面主程序；本页记录本地界面实验，后续纳入 1.1.9-beta，发行状态以对应发布记录为准。

## 对照方法

基线为 1.1.8-beta 正式包，源码标签对应 `61d5335f4207f8ba0e6a4cc05666a01ee619627e`；修改基于 `5756781fabbe7acad506fb26a266b3cef94b2aeb`。

以相同的合成账号、界面状态和 WPF 截图流程对照修改前后。先移除重复说明层，再压缩留下的说明；最终合并候选经过界面验证，没有分别测量两类改动的因果收益。这不是用户分组测试，不据此宣称操作速度或成功率提升。

## 删除与保留

| 区域 | 本轮删减 | 保留的必要信息 |
| --- | --- | --- |
| 日常设置 | 顶部操作导语；公会、小屋、女神像、通行证的重复摘要；控件旁反复说明默认值；狩猎旧流程说明 | 账号选择、消耗范围、补药前置条件、倍率不足时的处理、任务开启条件 |
| 今日任务 | 多句操作说明合为一句，移除重复步骤 | 本次勾选范围、账号核对、接续原队列与补跑的区别 |
| 工具 | 共用连接、窗口与自动化关系的重复解释 | 启用自动化才占用游戏、停止后可切换、各工具实际用途 |
| 诊断 | 页面导语、最近操作说明的重复段落；刷新按钮并入状态卡 | 当前连接与最近操作分区、错误时间和分类、下一步操作、日志导出 |
| 跑商与定时 | 压缩流程及设置说明 | 120% 售卖条件、金币保留、预算、30 天周转、定时启动条件 |
| 插件与更新 | 重复页标题、实现方式介绍 | 重启生效、游戏可保持运行、更新保留设置与插件 |

资源清理移除了 5 个已无界面引用的说明条目。收起冗余摘要的任务仍保留摘要参与搜索；没有删除任务、参数或操作入口。

## 文本量

只统计本次改写的 **65 个资源条目**，包含标签与说明；不包含删除的条目，不代表整个软件的文字总量。字符数按资源字符串长度统计，包含空格、标点及格式占位符。

| 语言 | 修改前 | 修改后 | 减少 |
| --- | ---: | ---: | ---: |
| 简体中文 | 2,231 | 1,328 | 40.5% |
| 繁体中文 | 2,256 | 1,332 | 41.0% |
| English | 6,700 | 4,083 | 39.1% |

例如补药说明由默认值、流程和条件混合的长段文字，缩成“需本周已完成至少 1 条 NPC 任务，且商人提供天赋药九折价。”开关和目标输入框本身说明何时购买、补到多少。日常设置首屏因此能显示后续的任务开关，而非只显示整体设置。

## 验证

- 桌面 Release 构建、源码边界检查及差异格式检查通过。
- 隔离 WPF 界面检查通过，涵盖简中、繁中、英文及深浅主题，检查语言切换不会修改账号、任务选择和偏好。
- 动态工具提示验证改为检查对应的本地化模板，仍检查时间、昵称和原始诊断保留；两条旧来源提示映射至新的简短界面文案。
- 人工查看设置、今日任务、诊断、工具、定时、跑商的实际渲染；检查窄窗口英文和繁体界面。
- 未连接游戏、注入组件或执行日常；没有改变任务业务逻辑。本轮没有重跑完整业务回归或重新打发行包。
