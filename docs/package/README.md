# Dustweave · 织尘

把琐碎日常，织成有序时间线。

Windows x64 · 时间线日常助手 · 简体中文 / 繁體中文 / English

| 版本 | 如何选择 |
| --- | --- |
| Portable | 已包含 .NET 8 桌面运行时，解压后直接运行 |

请完整解压文件夹，运行 Dustweave.exe。文件夹中只有一个程序入口；data、flows、connection、licenses 与说明属于完整分发包，不要仅复制 EXE。程序不会自动开始执行日常。

语言在主界面统一设置，九个内置工具跟随切换；工具独立版的语言偏好不会被改写。亮色、深色和跟随系统使用同一操作布局。

沿用原来的账号与设置目录。首次试用前请关闭旧日常窗口，避免同时操作同一份配置；无需为界面更新重启游戏。未完成操作仍需按界面提示核对。本版本已做离线检查，真实游戏行为仍需正常使用时验证。

免费提供；B站MadSamurai / GitHub MadestSamurai。当前版本为 0.9.1，源码仓库保持私有。集成工具的许可证和来源见 licenses、docs/tools 与 THIRD_PARTY_NOTICES.md。

更新入口：主界面左下角「版本更新」。默认从 bd2.madsam.work 自动检查并后台下载，经过签名校验后，在空闲时询问是否重启更新；不会自动打断队列。请保留完整文件夹使用。项目不隶属于游戏官方，辅助工具可能带来账号及运行风险，请自行决定是否使用。

从旧版本升级：完整解压到新目录，启动 `Dustweave.exe`；已有账号、设置和历史会自动沿用，无需迁移数据。不要将新旧程序混放在同一目录。

0.9.0 新增：在账号页运行勾选账号；定时页配置时间、星期和固定账号；首次打开一个新版本时显示更新说明。定时运行需要电脑开机、保持唤醒并已登录 Windows，默认不启用。

0.9.1：定时执行账号支持卡片添加、移除和拖动排序；启动说明与弹窗适配深浅主题；支持签名差分更新，补丁不适用时自动回退完整包。0.9.0 需要先完整更新一次。首次安装请从 GitHub Releases 获取，国内线路仅用于软件内 OTA。
