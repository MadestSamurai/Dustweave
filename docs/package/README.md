# Dustweave · 织尘

把琐碎日常，织成有序时间线。

Windows x64 · 时间线日常助手 · 简体中文 / 繁體中文 / English

| 版本 | 如何选择 |
| --- | --- |
| Portable | 已包含 .NET 8 桌面运行时，解压后直接运行 |
| Lite | 体积较小，需要已安装 .NET Desktop Runtime 8 x64 |

请完整解压文件夹，运行 BD2DailyAssistant.exe。文件夹中只有一个程序入口；data、flows、connection、licenses 与说明属于完整分发包，不要仅复制 EXE。程序不会自动开始执行日常。

语言在主界面统一设置，九个内置工具跟随切换；工具独立版的语言偏好不会被改写。亮色、深色和跟随系统使用同一操作布局。

沿用原来的账号与设置目录。首次试用前请关闭旧日常窗口，避免同时操作同一份配置；无需为界面更新重启游戏。未完成操作仍需按界面提示核对。本版本已做离线检查，真实游戏行为仍需正常使用时验证。
