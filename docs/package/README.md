## 开始使用

完整解压到一个新目录，运行 `Dustweave.exe`。请保留旁边的 data、flows、connection、licenses 和说明文件，不要仅复制 EXE，也不要把新旧版本混在同一目录。首次运行不会自动执行日常。

升级前关闭旧版 Dustweave；已有账号、设置、插件登记和历史记录会自动沿用，无需迁移，也无需为主程序更新重启游戏。语言及深浅主题在主界面统一设置，内置工具跟随切换。

## 本次更新

- 新增「插件」页，可导入本地 ZIP、启用、停用、回退和移除已登记版本。
- 启用前检查完整性和兼容性；变更在重启 Dustweave 后生效，运行中的任务不会中途替换插件。
- 插件页面支持三语言与深浅主题。当前一次启用一个插件包。

在「插件」页点击「导入插件」，选择单独提供的 ZIP，核对来源后导入并启用，再按提示重启 Dustweave。主程序包不包含额外插件。只安装你信任的来源：文件完整性检查不等于发布者签名。

## 账号、定时与更新

账号页支持多账号队列。安装官方 Sandboxie-Plus 后可使用隔离运行；不要在游戏更新期间启动隔离实例。定时执行需要电脑开机、保持唤醒并已登录 Windows，默认不启用。

主界面左下角「版本更新」提供检查与下载。国内线路仅用于软件内 OTA；已签名的完整包或差分包会在空闲时询问是否重启更新，不会自动打断队列。本地拿到的新版本不一定已推送到 OTA。
