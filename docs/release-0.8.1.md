# Dustweave · 织尘 0.8.1

## 简体中文

- 重新整理时间线、导航和诊断页面，统一深浅主题、图标、间距与文字层级。
- 任务进度改为圆环和百分比，已完成的环节显示实际完成时刻。
- 当前账号移到执行状态旁，高亮行的状态文字不再叠加独立底色。
- 窗口三键融入应用顶部，保留拖动、缩放与原有退出处理，修正最大化时的内容裁切。
- 改善窄窗口、中英切换和键盘焦点显示。

| 版本 | 运行环境 |
| --- | --- |
| Portable | 包含 .NET 8 桌面运行时，推荐使用 |
| Lite | 需要 .NET Desktop Runtime 8 x64 |

两版功能相同，支持简体中文、繁體中文与 English。请完整解压，关闭旧日常窗口后运行 BD2DailyAssistant.exe；沿用原账号和设置。此次界面更新不要求重启游戏。仓库与发行页保持私有。

## English

- Refined the timeline, navigation and diagnostics with consistent light/dark themes, icons, spacing and typography.
- Added circular progress with a percentage and recorded completion times for finished stages.
- Moved the current account beside the run state and removed separate backgrounds behind highlighted row status labels.
- Integrated minimize, maximize/restore and close controls into the application header, preserving window behavior and the existing shutdown path. Fixed content clipping when maximized.
- Improved compact layouts, language switching and keyboard focus visibility.

| Edition | Runtime requirement |
| --- | --- |
| Portable | .NET 8 Desktop Runtime included; recommended |
| Lite | .NET Desktop Runtime 8 x64 required |

Both editions support Simplified Chinese, Traditional Chinese and English. Extract the complete archive, close the old daily assistant and run BD2DailyAssistant.exe. Existing accounts and settings are retained. This interface update does not require restarting the game. The repository and release remain private.
