# 黄金阵容码

## 使用

织尘「工具 → 黄金阵容分享」打开时自动读取当前游戏的预设及服装名称。选择槽位可查看已保存的阵容，点击「生成此槽阵容码」，再单独点击「复制阵容码」。导入时粘贴阵容码即可预览服装，选择槽位，点击「检查并导入」，确认后保存。游戏保持在主菜单、黄金大厅或预设界面；工具不会启动或切换账号，也不会进行战斗。保存并读回后会同步游戏的预设缓存，已经打开的预设窗口可关闭后重新打开。

网页黄金模拟器的「方案操作 → 阵容码 · 导入与导出」可以复制或导入指定一方。它使用与织尘完全相同的格式，无需账号或服务器存储。网页导入保留匹配服装已有的培养，新服装使用编辑器默认培养，不带入其他账号的库存。

阵容码包含：来源赛季、盘面宽高、按行动顺序排列的服装 ID 与站位、按顺序排列的先手和后手庇护。它不包含账号、装备实例、培养、费用、胜率或任何登录信息；完整模拟方案仍用原来的方案文件保存。

## 格式与唯一性

前缀为 `BD2G1.`，后接不带填充符的 Base64URL。所有位从低位开始写入；整数使用最多 5 字节的无符号 LEB128，支持 0 至 2,147,483,647。服装和庇护 ID 必须大于 0。限制输入长度 4,096 字符、宽高各 1–256、上场和两侧庇护各不超过 64 项，防止异常输入无限分配。

| 顺序 | 内容 |
| --- | --- |
| 1 | 来源赛季、宽、高、服装数量，分别为变长整数 |
| 2 | 1 位编码模式 |
| 3 | 直接模式：每名服装 ID + `ceil(log2(宽×高))` 位的站位 |
| 3（替代） | 紧凑模式：排序后 ID 的正差分；每名服装在剩余 ID 中的索引 + 站位，索引使用 `ceil(log2(剩余数量))` 位 |
| 4 | 先手庇护数量和各 ID；后手庇护数量和各 ID，保留原顺序 |
| 5 | 字节末尾补零，再附加 4 字节小端 CRC32 |

编码器计算两种模式，选择字节数更小者；相同时选择直接模式。解码后重新编码并要求完全一致，以拒绝过长整数、额外字节、非零填充位及 Base64 别名。外围空白可以忽略。

“无碰撞”来自完整信息的无损编码：对有效阵容 x 满足 `Decode(Encode(x)) = x`，因此不同的所含字段不可能编码为同一个码；不是以有限长度哈希替代阵容。CRC32 仅检查偶然传输损坏，不用于证明作者身份或防伪。未编码的培养、装备等差异不构成不同的分享阵容。

新增服装、庇护和赛季数字 ID 无需扩充编码字典。未来新增语义字段时使用新格式版本，不能把未知格式默默当作旧格式。此能力不承诺任意未来游戏接口或规则变化都无需维护。

## 导入规则与保存流程

来源赛季仅用于说明。导入游戏必须以正在运行的客户端本期规则为准：有效赛季时间、相同盘面尺寸、最大人数、持有服装、禁用服装/格位、完整费用表及原生默认费用、费用上限、庇护存在性、禁用庇护和双方点数预算。不能以阵容码声称的价格绕过规则；费用读取失败不当作 0。不同盘面要求先调整，不能偷偷挪动站位。

网页可继续编辑超费用方案，与原有离线模拟行为一致；织尘写入游戏始终拒绝超额。网页表未包含新 ID 时说明需要更新模拟数据，保留输入，不把它误报为损坏的阵容码。

1. 取得现有控制锁，仅连接当前游戏，核对进程、账号及会话。
2. 从原生预设接口读取所有槽位及本期费用。预览不会写入游戏。
3. 用户选槽并确认；本地保存目标槽位的精确原始备份。
4. 再读预设，逐字节确认目标槽位未被修改，再按最新规则检查。
5. 克隆目标预设，仅替换其中的黄金服装、顺序、站位和双方庇护，保留名称/图标。匹配当前账号实例，使用游戏角色关联表而非 ID 算术猜测。
6. 保存请求最多发送一次；回调后重新读取并检查目标内容及其他槽位。原生服务可能省略空装备项，仅在目标比对时允许这一规范化。
7. 按工作台相同的原生流程重建黄金模式的预设视图缓存，并逐槽核对。若仅界面同步失败，仍保留服务器保存成功的结果，明确提示重新进入黄金，不重复发送保存。服装名称来自客户端完整表，不限于持有服装或当前预设；输入框编辑不触发网络读取。

工具不调用更换当前出战阵容接口。回执超时或连接中断后不盲目重发；提示重新读取核对。已发送但结果不明的操作保留备份及诊断，读取恢复后可再次正常操作，不依赖删除状态文件。等待有期限，关闭可取消连接和后续动作。异常明细写入 `tools/golden-presets/logs`，标准诊断导出包含该目录；原始预设备份不属于阵容码。

## 开发位置

- 格式/规则：`src/Shared/GoldenFormation.cs`。
- 当前客户端结构绑定及预设事务：`src/Connection/GoldenPresetNative.cs`。
- 本地工具：`src/Desktop/GoldenPresetWindow.cs`、`GoldenPresetSession.cs`。
- 网页格式：上级私有仓库 `apps/simulator/src/bd2arena/web/shared/golden-code.js`。
- 互通回归：`GoldenCodeCases` 导出向量，Node 的 `test_golden_codes.mjs` 使用同一组向量验证。
