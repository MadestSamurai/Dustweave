适用于 BrownDust II Windows 客户端的独立连连看助手。实时读取连连看盘面，提供配对提示、单步执行和自动本局。

| 版本 | 运行环境 | 建议 |

## 快速开始

**升级前**：停止并关闭旧工具，按下方「连接与工具切换」说明操作；本批新版组件支持同进程交接。

1. 进入连连看的实际方块盘面。
2. 打开助手，点击「连接游戏」，等待盘面与配对提示出现；无需先手动消除。
3. 点击「执行下一对」或「自动本局」。可调整配对间隔，点击「应用间隔」或按回车。
4. 点击「立即停止」或关闭窗口可停止。重新打开不会自动恢复执行。

## 功能与设置

| 设置 | 行为 |
| --- | --- |
| 配对间隔 | 默认 1000 ms，可调 50–60000 ms；运行中可修改并保存 |
| 配对提示 | 优先显示下一对与连接路径，再尝试完整路线；手动操作和洗牌后更新 |
| 自动本局 | 逐对等待游戏确认，暂停、洗牌和输入锁解除后继续，清盘后停止 |
| 窗口置顶 | 保持助手可见 |

间隔指相邻两对开始之间的时间，不是同一对内两次点击的间隔；仍受游戏帧率和输入锁影响。静态求解路线不能保证游戏期间盘面不发生变化。

## 界面语言

在顶部 **语言 / Language** 中选择简体中文或 English。首次启动跟随系统：中文系统使用简体中文，其他系统使用英语；之后记住手动选择。切换语言不会重启任务或改变设置。游戏提供的名称和图片保持游戏语言，原始诊断保留原文。

维护翻译见 [翻译说明](docs/LOCALIZATION.md)。

## 兼容与限制

支持官方 Windows x64 PC 客户端，一次连接一个游戏进程；工具与游戏需使用相同权限。不支持手机或 Android 模拟器客户端。首次连接会解析本机接口并生成组件，可能需要数秒。无法可靠匹配接口时停止连接并显示原因；跨版本适配不保证所有未来更新都无需维护。

发行包不包含游戏 DLL、资源、账号库或私有采集文件。只自动完成当前局，不点击下一关菜单或消耗道具。

## 诊断与反馈

设置与诊断位于 `%LOCALAPPDATA%\BD2Sichuan`，盘面相关文件位于其中的 `sichuan` 子目录。

- **等待盘面**：确认已经连接，并进入实际方块盘面；过关菜单和加载画面没有可操作盘面。
- **提示已有其他组件**：先停止相关工具再连接；旧组件迁移要求见下方说明。
- **接口检查失败**：更新到最新版；反馈时提供提示文字及去除个人路径后的 `compatibility.json`。
- **图标未显示**：图标仅辅助展示，配对判断使用逻辑盘面。

反馈时请提供版本、提示文字和相关日志片段，先去除账号、个人路径等信息。不要上传游戏 DLL、完整库存或连接凭据。

## 开发与贡献

需要 Windows x64、PowerShell 和 .NET 8 SDK。普通构建与回归不需要安装游戏，也不会连接游戏。

```powershell
.\build.ps1 -Locked
.\package.ps1 -Locked
```

产物位于 `dist/v版本号/`。打包会核对 Portable／Lite 运行环境并执行界面检查。

## 连接与工具切换

从旧版首次升级到本版时，请关闭旧工具并重启游戏一次。之后，本批新版工具支持同进程更新和安全切换：等待已发出的游戏操作结算，再移交控制；已有配置和记录保留。实时通信使用本机命名管道。日常工具内部的协作由日常调度器单独管理。
