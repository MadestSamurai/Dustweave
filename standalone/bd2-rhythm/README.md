面向 Windows 版 BrownDust II 的独立音游助手。在游戏中开始曲目后，读取当前谱面并自动演奏，支持可调随机偏移和整体时间校准。

## 快速开始

1. 启动工具；升级时先停止并关闭旧工具，按下方连接与工具切换说明操作。
2. 启动 Windows 版 BrownDust II，只保留一个游戏实例。工具与游戏使用相同权限。
3. 点击 **连接游戏**，等待连接完成，再点击 **开启自动演奏**。
4. 在游戏中选择曲目、难度并开始。工具会显示曲目、进度、已操作和跳过的音符数量。
5. 游戏暂停时，工具同步等待。点击 **停止** 或关闭窗口可结束自动输入。

随机偏移默认 **±50ms**。若只想测试无随机偏移的效果，将它设为 `0`。参数修改在下一曲生效。

## 功能与设置

| 设置 / 功能 | 行为 |
| --- | --- |
| 随机偏移 | 每个音符独立取样；范围 ±0–200ms，默认 ±50ms；密集同轨音符会压缩偏移以保持按下／松开顺序 |
| 整体校准 | -500–500ms，默认 0；正数延后，负数提前 |
| 谱面读取 | 读取游戏当前加载的普通／困难谱面，无需导出谱面文件；新增歌曲只要使用已支持的谱面结构即可识别 |
| 输入类型 | 普通音符、长按、滑动、连打和 Fever |
| 暂停／重试 | 暂停保持时间轴；重新开始曲目时重新生成输入计划 |
| 中途开启 | 跳过已过去的音符，不会补发一串过期操作 |
| 停止 | 结束自动输入并释放长按；游戏暂停时持有的输入在恢复后释放 |

工具使用游戏原有输入回调，不修改分数、血量、谱面或歌曲时钟。不负责选曲、购买次数、点击结算或自动续局。随机偏移与游戏帧率都会影响判定，不保证全连或满分。

## 界面语言

首次启动跟随系统语言：中文系统使用简体中文，其他系统使用 English。右上角选择会独立保存；切换语言不会停止演奏、改变偏移或重置当前歌曲。曲目资源名、底层异常与诊断原文保持原样。

## 兼容与限制

支持 Windows x64 官方客户端，不支持安卓模拟器。连接时读取本机游戏接口并生成适配组件，不锁定某个发行日的客户端版本。接口、音符类型或谱面结构发生不兼容变化时会停止并显示原因，不能保证未来所有版本均兼容。

程序不包含游戏 DLL、谱面、音频、图片、账号资料或私人采集数据。源码可以在未安装游戏的电脑上构建；实际连接需要本机安装并运行游戏。

## 诊断与反馈

点击 **诊断目录**，或打开 `%LOCALAPPDATA%\BD2Rhythm`。设置、连接记录和运行日志均保存在本机，不上传。

反馈时请提供工具版本、系统、游戏版本、错误文字和复现步骤。仅在需要时分享相关日志；不要上传完整游戏资源、账号凭据或私人数据。

若另一工具持有控制权，先停止它再连接；不支持交接的旧组件按下方说明重启一次。保留连接原始错误以便诊断。
