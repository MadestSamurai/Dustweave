## 快速开始

操作流程：

1. 正常启动并登录游戏，进入 SECRET VISION 小游戏首页。
2. 打开助手，连接游戏，选择要挑战的关卡。
3. 选择 100% 或普通 80% 通关目标，以及失败是否自动重试。
4. 开始后自动选择接边方向、圈取有收益的道具、沿外围推进并闭合。
5. 自然结束且服务器确认成绩后才标记完成；成功结算停留 8 秒，再进入下一关或返回首页。期间仍可随时停止；失败重试速度保持不变。

开始新任务会通过游戏正常退出接口结束当前对局，并重新开始所选关卡。正常开局后直接行动，不主动暂停来等待规划；正常路线结束也不暂停。手动暂停或控制状态异常会结束当前任务，不当成失败无限重开。停止或关闭助手应释放持续输入并暂停当前对局，不自动续命。

## 功能与设置

规划核心已实现：

- 根据可达安全边界的真实路程选择四个方向中更快的入口。
- 依据当前攻击计时、怪物运动、碰撞范围和加速剩余时间选择路线。
- 闭环后的安全前移独立执行，不占用下一次画线的攻击窗口。
- 根据格子与原生边线检测残缺，提前闭合后立即重算；只有实际新增填格或边线才算进展。
- 闪电逼近时优先离开安全边线画短圈，检查返回位置；无法画线时寻找可行的沿边避让。
- 支持选定关卡顺序执行、失败重开、80%／100%目标、每关尝试次数上限；0表示不限制次数。
- 以当次对局身份和新服务器记录核对成功，旧通关记录不算本次完成。

## 兼容与限制

面向官方 Windows x64 PC 客户端，一次连接一个游戏进程。连接时解析本机接口结构，再根据本机程序集编译必要组件；不按固定客户端 SHA 放行，也不分发游戏 DLL。

混淆符号重命名、成员重排及无关成员增加由结构匹配处理。接口缺失、签名变化或多个候选无法唯一识别时停止连接，不猜测成员。跨版本适配不意味着所有未来更新都无需维护。

规划使用游戏正常输入、速度、道具和结算，不调整攻击、碰撞、速度、计时或分数。随机敌人组合仍可能失败；自动重试不等于保证每局通关。

## 诊断与反馈

展开窗口内「诊断与数据位置」可查看原始错误及可选中复制的数据路径。「来源与说明」提供可复制的仓库地址。程序不调用外部文件浏览器或浏览器。

升级按下方连接与工具切换说明操作。普通文件占用不需要提权。

独立数据目录为 `%LOCALAPPDATA%\BD2SecretVisionAssistant\`。设置、连接诊断和每次尝试分开保存。局内路线不会在重新启动程序后自动重放。

进程／组件会话变化或控制心跳过期应停止持续输入；网络结果不确定时保留现场，不盲目重复开局。错误详情保留路径、操作、错误码及原始堆栈，写入 `diagnostics.jsonl`。短暂文件占用会有限重试；持续无法续期则停止，不会悄悄失去心跳后继续发指令。诊断文件失败不会中断正常控制。

反馈时提供版本、提示文字及相关日志片段，先移除账号和个人路径。不要上传游戏 DLL、账号库或连接凭据。
