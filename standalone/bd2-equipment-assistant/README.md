## 快速开始

1. 正常启动游戏并进入主城，只保留一个游戏进程；工具与游戏使用相同的 Windows 权限。
2. 打开 EXE，点击「连接并读取库存」。仅启动工具不会自动连接或消费资源。
3. 在「制作 N 装刷粉」中设置强化等级、数量或预算，点击「计算计划」；或者在「批量精炼」中筛选并勾选具体装备，设置目标与预算后计算。
4. 核对金币、材料、天赋药、预计产粉或精炼预算，在确认窗口中确认后执行。
5. 「停止」阻止后续批次；已提交的游戏批次会先完成并核账，不会撤销已经消耗的资源。

从 0.3.1 或更早版本升级时，先停止并关闭旧工具。若旧装备助手已经连接当前游戏，正常重启游戏一次后再连接新版。历史计划和核账记录保留；执行新计划前重新读取库存、计算并确认。

## 功能与设置

| 功能／设置 | 行为 |
| --- | --- |
| 搓粉规划 | 根据现有金币、天赋药、材料和上限计算 N 装配方组合；先展示完整成本与预计产粉 |
| 强化后分解 | 默认 +7，支持 +1～+9；使用游戏原生一键制作、强化后分解 |
| 5 药装备 | 默认不勾选；开启后把更耗药的 N 装配方纳入规划 |
| 数量、金币与药上限 | 留空以当前库存为上限；不会购买天赋药、合成材料或动用付费资源补缺 |
| 制作批量 | 先小批核账，通过后按游戏实际容量连续批量制作，不固定为每批 100 件 |
| 装备选择 | 按名称、角色、实例 ID 搜索；按部位、类型、稀有度、品质、穿戴、锁定、保留、强化、精炼、主副词条筛选 |
| 同名装备 | 显示实例 ID、持有角色、主副词条及精炼分项；只处理明确勾选的实例 |
| 精炼目标 | 1～24，默认 24；只精炼已强化 +9 的装备，不自动强化其他装备 |
| 精炼预算 | 默认金币 100,000、粉末 10,000；为所选装备共用的总预算 |
| 原生批量精炼 | 默认每批上限 5,000 次；按剩余预算缩小批次 |
| 达标即停 | 默认模式：将游戏内目标设为所选等级，由游戏原生规则提前结束本批 |
| 争取更高结果 | 可选：游戏内目标设为 24，整批结算后达到所选目标或更高即停；可能多消耗资源 |

精炼是随机过程，预算并不保证达标。被锁定、保留或穿戴的装备仍可能被用户选中精炼；请核对实例信息。切换账号、库存改变、报价不符或结果无法确认时会停止。未知结果保留核账记录，不自动重发，不应通过删除记录强行重试。

## 界面语言

首次启动跟随系统语言，可在右上角切换简体中文／English。语言偏好会保存；切换保留计划、勾选和筛选条件，执行中禁用切换。角色和装备支持中英文搜索。底层诊断、接口名称和部分异常保留原始文字。

## 兼容与限制

支持官方 Windows 客户端，不支持安卓模拟器。连接时按接口结构、方法体特征及调用位置解析本机客户端，再编译连接组件；不锁定发布时的游戏 DLL 或数据包。每次读取库存和执行前，都会读取游戏当前加载的装备、配方及费用表。新增装备、费用调整和可识别的接口重命名不需要重发工具。

这不是对所有未来版本的保证。若游戏改变批量接口、费用结构，或出现多个无法区分的接口，会停止并给出诊断；不会猜测接口或使用旧费用继续执行。旧客户端若没有所需的原生批量功能也会提示不支持。详见 [跨版本适配](docs/COMPATIBILITY.md)。

仓库包含装备名称、词条及制作／精炼费用等静态元数据，不包含游戏 DLL、图片、账号库存、私人采集或其他模式的自动化程序。构建不需要安装游戏；实际连接需要本机游戏。

## 诊断与反馈

本地数据保存在 `%LOCALAPPDATA%\BD2EquipmentAssistant`，包括语言偏好、库存、计划、核账和连接诊断；工具不会上传这些数据。

反馈时提供版本、完整错误文字、操作步骤和相关诊断片段。不要提交账号凭据、完整库存或游戏资源。未确认的消费应先核对游戏余额与记录，避免重复执行。
