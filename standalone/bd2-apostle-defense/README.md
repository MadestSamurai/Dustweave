## 快速开始

**升级前**：暂停并关闭旧工具。已使用 0.3.4 或更新版组件时，游戏可以保持运行，再用新版连接；从 0.3.3 及更早组件迁移时，需要正常重启游戏一次。

1. 进入使徒运气防守大厅，打开助手，点击「连接游戏」。
2. 选择目标，核对账号与服务器进度，点击「开启自动化」。默认先争取第 50 波通关，再转向最高级使徒召唤。
3. 工具根据实时盘面操作，结算后退出并重新核对成就，再按设置续局。
4. 随时可以暂停，或勾选「本局结算后停止」。暂停助手不会暂停游戏计时。

## 功能与设置

- 已确认的对局结束状态保留到退出完成。游戏清空标记后，残留的结算弹窗仍能重试退出；进行中的结果菜单不会被误当作失败。
- 连接、状态读取和控制写入在后台执行。暂停立即撤销本地自动化，关窗取消未完成的连接准备并有限等待退出。

- 网络短暂波动时保留任务，等待连接与盘面恢复后继续；正常结束后的断线不会阻止结算退出。
- 旧指令未被接收或迟迟没有回读时，先与组件确认结束旧指令，再按当前界面继续。文件短暂占用会有限重试，诊断写入失败不再阻断状态同步。

- 68格盘面按真实位置绘制，显示属性与阶数、敌人、移动箭头；点击使徒查看属性、射程和路线覆盖。点击只查看信息，不操作游戏。方向键可选格，Esc取消。
- 英文格内使用 Wa／Fi／Wi／Li／Da 表示水／火／风／光／暗，后接阶数。完整名称在点选详情和悬停提示中显示。
- 普通波比较可执行移动／交换的净收益，并考虑升级、召唤和低风险重抽。出售成功后优先补回空位。
- 首个首领前先补足3名使徒；不足召唤费用时留钱，不抢先升级。基础阵容齐备后，升级按当前波实际所需攻击次数评估，不给过量伤害虚计清怪收益；金币不足下一抽时，还需能通过新增击杀更快赚回召唤费用。该模型用于决策估计，不是完整战斗模拟。
- 首领波根据实际敌人位置、速度与路线进行短时间预测，自动移动主力追击；支持多首领，计算交换对象的输出损失，并保留攻击进度。首领波暂停静态搬位与卖出重抽。
- 操作间隔100–3000ms，默认500ms；每条命令等待游戏回读确认，不堆积操作。首领追击另外校验目标存活、波次和快照时效。
- 自动完成原生退出／确认／返回大厅，回读服务器成就后决定是否续局。关闭自动续局仍会处理本局结算退出。

策略使用短时间收益估计，**不是完整战斗模拟器，也不保证通关50波或召唤到指定使徒**。动态追击已做离线对照，实机效果仍会受阵容、帧率与延迟影响。

## 界面语言

在顶部 **语言 / Language** 中选择简体中文或 English。首次启动跟随系统：中文系统使用简体中文，其他系统使用英语；之后记住手动选择。切换语言不会重启任务或改变设置。游戏提供的名称和图片保持游戏语言，原始诊断保留原文。

维护翻译见 [翻译说明](docs/LOCALIZATION.md)。

## 兼容与限制

支持官方 Windows x64 PC 客户端，一次连接一个游戏进程；工具与游戏需使用相同权限。不支持手机或 Android 模拟器客户端。首次连接会解析本机接口并生成组件，可能需要数秒。无法可靠匹配接口时停止连接并显示原因；跨版本适配不保证所有未来更新都无需维护。

发行包不包含游戏 DLL、资源、账号库或私有采集文件。策略使用短时间收益估计，不保证第 50 波通关或指定使徒；不会主动放弃尚未结束的对局。

## 诊断与反馈

设置、语言与诊断位于 `%LOCALAPPDATA%\BD2ApostleDefense`，点击「打开诊断目录」查看。原有目标与设置继续沿用。

| 文件 | 用途 |
| --- | --- |
| `connection.log` | 连接阶段、持续等待与失败原因；常规目录不可写时尝试 `%TEMP%\BD2ApostleDefense` |
| `decisions-日期.log` | 决策、回读、恢复与停止原因 |
| `flow-current.jsonl` / `flow-previous.jsonl` | 匹配、战斗、结算与弹窗阶段变化 |
| `network-current.jsonl` / `network-previous.jsonl` | 网络探测、连接恢复与等待原因 |
| `io-errors-进程号.log` | 文件读写失败的路径、错误码与堆栈；重复错误限频记录 |
| `last-action.json` | 最近操作的前后快照与结果 |
| `compatibility.json` / `runtime.json` | 组件接口与运行状态 |

短暂读不到状态时保持开启并等待心跳；可恢复的点击和回读超时会冷却后重新决策，失败换位不会堵住召唤。匹配返回大厅或失败页后接续；结算回到大厅即确认退出，再关闭可正常返回的活动弹窗。未知弹窗等待你处理，账号／进程变化与未分类组件错误仍会停止。

反馈时请提供版本、提示文字和相关日志片段，先去除账号、个人路径等信息。不要上传游戏 DLL、完整库存或连接凭据。
